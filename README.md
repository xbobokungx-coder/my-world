# 🌾 My World

เกมฟาร์มสบายๆ ออนไลน์ ปลูกผัก ตกปลา เลี้ยงไก่ เพื่อนกดลิงก์แล้วใส่ชื่อก็เล่นด้วยกันได้ทันที

## รัน

```bash
npm install
npm start
```

เปิด http://localhost:3000 — ปุ่ม "🔗 ชวนเพื่อน" ในเกมจะคัดลอกลิงก์ส่งให้เพื่อนได้เลย
ทุกคนเข้าโลกเดียวกัน (ล็อกห้องเดียว ชื่อ `main`, เปลี่ยนด้วยตัวแปร `ROOM`) บันทึกที่ `data/<ห้อง>.json` (ตั้งโฟลเดอร์ด้วย `DATA_DIR`, พอร์ตด้วย `PORT`)

## ให้เพื่อนเข้าจากอินเทอร์เน็ต
- ชั่วคราว: `cloudflared tunnel --url http://localhost:3000` (หรือ ngrok) แล้วส่งลิงก์ที่ได้
- ถาวร: deploy เป็น Node/Docker server (ต้องรองรับ WebSocket และมีดิสก์เก็บ `data/`)

## วิธีเล่น (สรุป)
- คลิก/แตะที่พื้น = เดินไปที่นั่น, คลิกที่ช่องที่ทำอะไรได้ (แปลงผัก น้ำ ร้านค้า สัตว์) = เดินไปแล้วทำให้เลย
- กด **B** (หรือปุ่ม 🎒) เปิดกระเป๋า / อาชีพ / เปลี่ยนสีชุด-หมวก
- 3 อาชีพมีเลเวลแยกกัน: ชาวนา (เมล็ด 8 ชนิดปลดล็อกตามเลเวล), ชาวประมง (ปลา 10 ชนิด, คันเบ็ด 3 ระดับ), คนเลี้ยงสัตว์ (ไก่/วัว)
- ร้านค้าแยกตามสาย อยู่ใกล้แปลงผัก / สระน้ำ / ทุ่งสัตว์ ขายของที่เกี่ยวกับสายนั้นและรับซื้อผลผลิตของสายนั้น (เลือกขายได้ทีละชนิด)
- เสียงแชท: ตอนนี้ได้ยินกันทั่วแมพ (ตั้ง `VOICE_GLOBAL = false` ใน `public/game.js` เพื่อกลับไปใช้ระยะ: เต็มที่ ≤3 ช่อง เบาลงจนเงียบที่ 7 ช่อง)
- แผนที่ย่อมุมขวาบน: กดที่แผนที่หรือปุ่ม 🔍 เพื่อขยาย/ย่อ, ปุ่ม ➖ ซ่อน (ปุ่ม M สลับ) เห็นตำแหน่งผู้เล่นทุกคนพร้อมชื่อ
- ปุ่ม 📊 (หรือ C) ดูสถานะตัวเอง: เหรียญ ของในกระเป๋า เลเวลอาชีพ ตำแหน่ง

- 🎮 **อาคารตู้เกม** (กลางแมพเหนือจุดเกิด): แต่ละเกมเป็นตู้ ตอนนี้เปิดแล้ว 1 ตู้คือ **XO** เดิมพันด้วยเหรียญได้ (0/10/50/100/500) หรือซ้อมกับบอท
  - เสียเหรียญเดิมพันไว้ล่วงหน้า (escrow) ผู้ชนะได้ของทั้งสองฝ่าย เสมอคืนเหรียญ ตาละ 30 วินาที ออกจากเกมหรือหมดเวลา = แพ้
  - ตู้ **UNO** เล่นได้ 2-4 คน (ผู้สร้างเลือกจำนวนคนและเดิมพัน, เริ่มเลยก่อนห้องเต็มได้ถ้ามี ≥2 คน) มีโหมดซ้อมกับบอท
  - เพิ่มเกมใหม่: ใส่ `game` ที่ตู้ใน `CABINETS` (`public/shared.js`) แล้วเขียนกติกาฝั่งเซิร์ฟเวอร์ (`server.js` ส่วน Arcade)

- 🐖 **หมู**: ซื้อที่ร้านปศุสัตว์ (เลเวลคนเลี้ยงสัตว์ 5) ให้อาหารหมู แล้วเก็บเห็ดทรัฟเฟิล 🍄 ขายได้ราคาสูง อยู่ในคอกหมูมุมขวาบนของฟาร์มสัตว์
- 💹 **เศรษฐกิจ**: ตลาดรับซื้อมีราคาขึ้นลง (ขายเยอะราคาตก 2% ต่อชิ้น ทิ้งไว้ราคาค่อยๆ กลับ ทุกวันในเกมมีข่าวราคาพุ่ง/ตก) • ตกปลาต้องใช้เหยื่อ 🪱 (ชิ้นละ 3) • ตู้เกมหักค่าบริการ 5% จากรางวัล
  - ปรับตัวเลขต่างๆ ได้ใน `public/shared.js` (`FISH`, `CROPS`, `ANIMALS`, `BAIT_PRICE`, `RAKE`, `MARKET`)
- 🔊 **เสียงเอฟเฟกต์**: ขุด/รดน้ำ/ปลูก/เก็บเกี่ยว/ตกปลา/ให้อาหารวัว-ไก่-หมู/ซื้อขาย/เลเวลอัป/ชนะแพ้ในตู้เกม (คนอื่นทำใกล้ๆ ก็ได้ยินเบาๆ) เปิด/ปิดได้ในแท็บสถานะ
- ⌨️ WASD/ปุ่มลัดใช้ได้แม้เปลี่ยนเป็นแป้นพิมพ์ภาษาไทย (อ้างอิงตำแหน่งปุ่ม)
- 🎮 ตู้เกมตอนนี้มี 6 ตู้: เป่ายิ้งฉุบ, XO, UNO, ใครกดเร็วกว่า, ไพ่ป๊อก, Connect 4 (ทุกเกมซ้อมกับบอทได้ ยกเว้นต้องมีคนจริงถึงจะเดิมพัน)

- 🍖 **ความหิว**: ผู้เล่นหิวลงเรื่อยๆ ขณะออนไลน์ (ต่ำกว่า 15 เดินช้าลง, 0 = ใช้เครื่องมือไม่ได้) กินที่ 🍜 ร้านอาหาร หรือกินผลผลิตของตัวเองในกระเป๋า
- 💀 **สัตว์หิวและตาย**: สัตว์ต้องให้อาหารเป็นระยะ ถ้าหิวจนหมดแล้วไม่มีใครให้อาหารภายใน 4 นาทีจะตาย (นับเฉพาะตอนมีคนออนไลน์) ต้องซื้อตัวใหม่
- 👕 **ร้านเสื้อผ้า**: ซื้อเสื้อ/กางเกง/หมวกหลายแบบด้วยเหรียญ สวมและเลือกสีได้ในแท็บ "ตัวละคร" มีตัวอย่างให้ดู (ซื้อของที่ `WEAR` ใน `public/shared.js`)
- 🗺️ **แมพ**: ตู้เกมเรียง 2 แถว แถวละ 4 ตู้ พร้อมป้ายใหญ่ ร้านค้าทุกร้านเป็นอาคารเล็ก (ประหยัดพื้นที่)

- 🪓 **ช่างไม้** (อาชีพที่ 4): ซื้อขวานที่ร้านช่างไม้ ตัดต้นไม้ได้ไม้ท่อน (ไม้เนื้อแข็งหายากราคาแพง) ขายได้ ต้นไม้งอกใหม่เองในที่โล่งห่างสิ่งปลูกสร้าง (ยังไม่มีงานฝีมืออื่น)
- 🔥 **ลานกองไฟกลางหมู่บ้าน**: มีม้านั่ง กองฟาง เก้าอี้ (กดที่ที่นั่งเพื่อนั่ง เดินเพื่อลุก) กลางคืนมืดมาก สว่างเฉพาะรอบกองไฟ • ซื้อ 🏮 ตะเกียงที่ร้านเฟอร์นิเจอร์ (กด L เปิด/ปิด) สว่างรอบตัว 5 ช่อง
- 🤒 **สัตว์ป่วย**: ป่วยทีละ 1 ตัวเท่านั้น สุ่มวันละครั้ง (1 วันในเกม = 12 นาทีที่มีคนออนไลน์) โอกาส 30% วันไหนไม่ป่วยก็ข้ามไปวันถัดไป (ปรับที่ `SICK` ใน `shared.js`) รักษาด้วยยา 💊 (ร้านปศุสัตว์ ใช้ผ่านช่องอาหารสัตว์ที่ hotbar) ถ้าไม่รักษาตายเร็วกว่าหิวปกติ
- ↩️ **ขายคืน**: เสื้อผ้า คันเบ็ด ขวาน ตะเกียง ขายคืนร้านได้ 70% ของราคาซื้อ
- 🎰 **คาสิโน** (ตู้บาคาร่า/แบล็คแจ็ค 2-3 คน เล่นกับเจ้ามือ): โชคของผู้เล่นแต่ละคนลดลงตามการเล่นต่อเนื่อง (ซ่อนไว้ ปรับที่ `CASINO` ใน `public/shared.js` และฟังก์ชัน `casinoBias` ใน `server.js`)
- 🚲 ร้านยานพาหนะ: เตรียมไว้ ยังไม่ขาย

## รายละเอียดปุ่ม
| ปุ่ม | ทำอะไร |
|---|---|
| WASD / ลูกศร | เดิน (มือถือใช้จอยสติ๊ก) |
| Space / คลิก / ปุ่ม A | ใช้เครื่องมือกับช่องที่หันหน้าไป |
| 1–7 | เลือกเครื่องมือ: จอบ, บัวรดน้ำ, เมล็ด 3 ชนิด, เบ็ด, อาหารไก่ |
| Enter | แชท |

- ปลูก: จอบขุดดินในแปลง → รดน้ำ → หยอดเมล็ด → รอโต (โตเฉพาะตอนดินเปียก) → กดเก็บเกี่ยว
- ตกปลา: ยืนริมบ่อหันหน้าหาน้ำ ใช้เบ็ด พอขึ้น ❗ ให้กดทันที
- ไก่: ให้อาหาร แล้วรอไข่ขึ้น 🥚 เดินไปกดเก็บ
- ร้านค้า: ยืนใต้เคาน์เตอร์แล้วกดหันหน้าหาเคาน์เตอร์ ซื้อเมล็ด/ขายของ

ปรับเวลาโตของพืช/ราคา/ปลาได้ใน `public/shared.js`
ตัวละครผูกกับชื่อ (ไม่มีรหัสผ่าน)

- 📉 **ลิมิตตลาด**: ขายของชนิดเดียวกันเยอะๆ ราคาจะตกต่อเนื่องทีละชิ้น (ต่ำสุด 20% ของราคา) ทิ้งไว้ราคาค่อยๆ กลับมา (ปรับที่ `MARKET` ใน `public/shared.js`)
- 🔧 **ความทนทานเครื่องมือ**: จอบ เบ็ด ขวาน สึกหรอเมื่อใช้ ถ้าพังต้องซ่อมที่ร้านของสายนั้น (ค่าซ่อมตามความเสียหาย) เป็นรายจ่ายประจำ (ปรับที่ `DURABILITY`)
- 🤝 **เทรด**: เมนู 👥 คนในแมพ → ปุ่ม 🤝 เทรด (ต้องอยู่ใกล้กัน 8 ช่อง) แลกของได้เท่านั้น ไม่มีเหรียญ มูลค่าฝั่งละไม่เกิน 1000 ต่อรอบ ทั้งสองฝ่ายกดยืนยัน (ปรับที่ `TRADE`)
- 🎬 **หนังกลางแปลง** (ลานใต้ตู้เกมฝั่งใต้): กดที่จอ วางลิงก์ YouTube หรือเลือกหนังฟรี ตั๋ว 🪙15 ทุกคนที่เข้าไปดู **ซิงก์กัน**: ใครกดเล่น/หยุด/เลื่อนเวลา ทุกคนตามทันที (มีปุ่ม 🔄 ซิงก์ใหม่) เสียงมาจากหน้าต่างของคนที่เข้าไปดูเท่านั้น คลิปที่ปิดการฝังจะเล่นไม่ได้ (ตั้งหนังฟรีที่ `MOVIES`)

- 🏠 **บ้าน/ตกแต่ง**: ที่ดินพื้นไม้ 6 แปลงแถวบนสุดของแมพ (ป้าย "ที่ดินว่าง") กดป้ายเพื่อซื้อ 🪙400 คนละ 1 แปลง คืนที่ดินได้ 70%
  - ซื้อเฟอร์นิเจอร์ 14 แบบที่ 🛋️ **ร้านเฟอร์นิเจอร์** (ริมถนนหลัก ข้างตู้เกม) แล้วกดปุ่ม 🏠 (หรือ H) เข้าโหมดตกแต่ง: เลือกของ → แตะช่องพื้นไม้เพื่อวาง, 🧹 เก็บคืน → แตะของเพื่อเก็บเข้ากระเป๋า
  - เจ้าของเท่านั้นที่วาง/เก็บได้ คนอื่นเดินเข้าชมได้ • เก้าอี้/โซฟานั่งได้ (แตะเพื่อนั่ง) • โคมไฟสว่างตอนกลางคืน • ของที่วางบันทึกไว้ใน `data/<ห้อง>.json` (`house`)
  - เพิ่มเฟอร์นิเจอร์ใหม่ที่ `FURN` ใน `public/shared.js`, ปรับราคาที่ดินที่ `HOUSING`

- 🎣 ตกปลา: โยนเหยื่อไปไกลแค่ไหนก็ได้ แต่ต้องยืนห่างจากสระไม่เกิน 2 ช่อง • 🪑 นั่งพักแล้วความหิวไม่ลดและค่อยๆ อิ่มขึ้น • 🔥 กองไฟสว่างไกลขึ้น (10.5 ช่อง) • 🎬 โรงหนังเล็กลง: จอเล็ก เก้าอี้ 4 ตัวแถวเดียวเรียงติดกัน

- 📰 **ข่าวเมือง**: กระดานข่าวที่ลานกองไฟ (หรือปุ่ม 📰 บนแถบบน) แสดงเหตุการณ์ 50 รายการล่าสุด เช่น คนเข้า/ออก เลเวลอัป เก็บของแพง/ปลาตัวใหญ่ ข่าวตลาด สัตว์ป่วย/ตาย ช่วยให้อาหารสัตว์ที่หิวมาก บันทึกไว้ในไฟล์เซฟ
- 🏦 **ตู้เซฟกองกลาง** (ลานกองไฟ ข้างกระดานข่าว): ทุกคนลงขันได้ (+10/+50/+100, ถอนไม่ได้) สัตว์ที่ป่วย/หิวจัดนานเกิน 1 นาทีโดยไม่มีใครช่วย เงินกองกลางจะจ่ายยา/อาหารให้เอง และชุบชีวิตสัตว์ที่ตายได้ในราคาครึ่งหนึ่งของราคาซื้อ (ปรับที่ `TOWN` ใน `public/shared.js`)
- 💤 **จำศีล**: ไม่มีผู้เล่นออนไลน์ = พืชไม่โต ตลาดไม่ขยับ ความหิว/ป่วยของสัตว์ไม่เดิน

- 📋 **เควสประจำวัน**: เมนู 🎒 → แท็บ "เควส" แต่ละคนได้ 3 เควสต่อวัน (สุ่มจาก 3 สายอาชีพ เควสไม้ต้องมีขวาน) ทำเสร็จได้ XP + เหรียญทันที สะสมจำนวนเควสเพื่อรับฉายา (แสดงเหนือหัวตัวละคร) ปรับที่ `QUESTS` / `TITLES` ใน `public/shared.js`
- 💛 **แต้มความดี**: ได้จากการช่วยงานที่จำเป็นจริง (ให้อาหารสัตว์ที่หิว +1/+2, รักษาสัตว์ป่วย +3, รดน้ำพืชที่แห้ง +1, ลงขันตู้เซฟ) จำกัด 30 แต้ม/วัน ใช้แลกบัฟส่วนตัว 15 นาที: 🏃 เดินเร็ว +10% / 🍖 หิวช้าลงครึ่งหนึ่ง (`BUFFS`, `POINTS`)
- 🏆 **อันดับประจำวัน**: ส่วน "อันดับวันนี้" ในหน้าข่าว แสดง 3 อันดับแรกของวันนี้ (เก็บเกี่ยว/รดน้ำ/ให้อาหารสัตว์/ตกปลา/โค่นไม้/เก็บผลผลิต) และข่าวเมืองจะประกาศผู้นำของเมื่อวานตอนขึ้นวันใหม่

- 💳 **ตู้ ATM** (ลานกองไฟ ระหว่างกระดานข่าวกับตู้เซฟ): ฝาก/ถอนเหรียญ เพดานเงินฝาก 1,000 ดอกเบี้ย 1% ต่อ 1 วันในเกม (12 นาที) **นับเฉพาะตอนผู้ฝากออนไลน์** ปรับที่ `BANK` ใน `public/shared.js`
- 🎉 **Happy Village**: งานของทุกคนวันนี้ (เก็บเกี่ยว รดน้ำพืชแห้ง ให้อาหารสัตว์ ตกปลา โค่นไม้ เก็บผลผลิต รักษาสัตว์ ลงขัน) นับรวมกัน ครบเป้า (30 + 20 × จำนวนคนออนไลน์สูงสุดของวัน) ทั้งเมืองได้บัฟ 20 นาที: ตกปลาไวขึ้น 25% และได้ไม้เนื้อแข็งง่ายขึ้น ดูความคืบหน้าที่ 📰 → ข่าว (`VILLAGE`)

- 🎮 **ตู้เกมวางสลับฟันปลา** 2 แถว แถวละ 4 ตู้ เว้นห่างตู้ละ 1 ช่อง เดินในแถวกลางใช้ได้ทั้งสองแถว

- 🛋️ **เศรษฐกิจเฟอร์นิเจอร์**: ราคาที่ร้านเฟอร์นิเจอร์สูงขึ้นราว 2.5–3 เท่า (เก้าอี้ 120, โซฟา 400, เตียง 600, เปียโน 1,200) เป็นของแต่งบ้านที่ต้องสะสมเงิน • ช่างไม้ทำเองได้ถูกกว่าราว 1 ใน 3 แต่ต้องใช้ไม้เยอะ (เก้าอี้ 8 ท่อน, โต๊ะ 16, ชั้นหนังสือ 22, เตียง 30 ท่อน + ไม้เนื้อแข็ง 3, กระท่อม ไม้กระดาน 24 + ไม้เนื้อแข็ง 6) • ร้านเฟอร์นิเจอร์รับซื้อคืนเพียง 35% ของราคา (ต่ำกว่ามูลค่าไม้ที่ใช้ทำ) จึงตัดไม้ → ทำเฟอร์นิเจอร์ → ขาย ไม่ได้กำไร ขายไม้กระดานตรงๆ ได้ท่อนละ 15 ดีกว่า ส่วนเฟอร์นิเจอร์หายากขายคืนไม่ได้ (ปรับที่ `FURN` / `FURN_SELL` / `CRAFT` ใน `shared.js`)

- 🌱 **ร้านเมล็ดพันธุ์ 2 แท็บ**: 🧰 อุปกรณ์ (บัวรดน้ำ + ซ่อม/ซื้อจอบใหม่) กับ 🌱 เมล็ดพันธุ์ (เรียงจากกำไรต่อนาทีดีสุด → แย่สุด ติดป้าย ⭐ ดี 3 อันดับแรก / ▼ ต่ำ 3 อันดับท้าย และมีช่องขายผลผลิต)
- 🎣 **ร้านตกปลา 2 แท็บ**: 🎣 อุปกรณ์ตกปลา (เหยื่อ/คันเบ็ด/ซ่อม) กับ 🐟 ขายปลา
- 🛠️ **ผู้ดูแลดู IP ผู้เล่น**: เมนูผู้ดูแลมีหัวข้อ "👥 ผู้เล่นและ IP" แสดงทุกห้อง (🟢 ออนไลน์ IP ตอนนี้ / ⚪ เข้าล่าสุดเมื่อไหร่) พร้อมประวัติ IP 5 ล่าสุดของแต่ละคน เก็บใน rec.ips ของไฟล์เซฟ และ log ที่คอนโซลตอนเข้าเกม (ถ้าอยู่หลัง Cloudflare/proxy อ่านจาก header cf-connecting-ip / x-forwarded-for)
- 🦶 **ปุ่มเตะ**: ในรายชื่อผู้เล่นของเมนูผู้ดูแล คนที่ออนไลน์มีปุ่ม "เตะ" (ถามยืนยันก่อน) ผู้ถูกเตะจะเห็นข้อความว่าถูกเตะ และกด "เชื่อมต่อใหม่" เข้ามาได้ทันที เตะผู้ดูแลไม่ได้

## 💹 ปรับเศรษฐกิจ (ต.ค. 2026)
- **ตลาดแยกต่อคน:** ราคาที่เห็น = ตลาดกลาง × ตลาดส่วนตัว × โบนัสความหลากหลาย ขายชนิดเดิมซ้ำๆ ตลาดส่วนตัวของคนนั้นตกหนักและฟื้นช้า (`PMARKET` ใน `public/shared.js`)
- **โบนัสขายหลายชนิดต่อวัน:** +5% ต่อชนิดที่ต่างกัน สูงสุด +40% (`VARIETY`)
- **ดอกเบี้ย ATM** นับเฉพาะตอนมีกิจกรรม (เดิน/ใช้เครื่องมือภายใน 3 นาที, `BANK.idleMs`) และโควตากำไรจากบอทลดเหลือ 500/วัน (`BOTBET.dailyWinCap`)
- **ปรับราคาพืช/ปลา:** พืชชนิดเลเวลสูงกำไรต่อนาทีสูงขึ้นตามเลเวล (10 → ~20/นาที) ปลาหายากถูกลง บีบช่องว่างรายได้ตกปลาต้น-ท้ายเกม
- **👨‍🍳 ห้องครัว (ร้านอาหาร):** ทำอาหารจากปลา + ผัก + ไข่/นม ขายได้แพงกว่าของดิบรวมกันหลายเท่า (`COOK` ใน `shared.js`) ต้องพึ่งวัตถุดิบหลายสายอาชีพ
- **🏗️ โครงการพัฒนาเมือง:** ลงขันที่ตู้เซฟกองกลาง (สะพาน → ประภาคาร → เกาะตกปลา → ลานเทศกาล) ปลดล็อกตามลำดับ ครบเป้าประกาศชื่อผู้ร่วมสร้าง (`PROJECTS`)
