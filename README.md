# 🌾 My World

เกมฟาร์มสบายๆ ออนไลน์ ปลูกผัก ตกปลา เลี้ยงไก่ เพื่อนกดลิงก์แล้วใส่ชื่อก็เล่นด้วยกันได้ทันที

## รัน

```bash
npm install
npm start
```

เปิด http://localhost:3000 — ปุ่ม "🔗 ชวนเพื่อน" ในเกมจะคัดลอกลิงก์ส่งให้เพื่อนได้เลย
ทุกคนเข้าโลกเดียวกัน (ล็อกห้องเดียว ชื่อ `main`, เปลี่ยนด้วยตัวแปร `ROOM`) บันทึกที่ `data/<ห้อง>.json` (ตั้งโฟลเดอร์ด้วย `DATA_DIR`, พอร์ตด้วย `PORT`)

## ให้เพื่อนเข้าจากอินเทอร์เน็ต
- ชั่วคราว: `cloudflared tunnel --url http://localhost:3000` (หรือ ngrok) แล้วส่งลิงก์ที่ได้
- ถาวร: deploy เป็น Node/Docker server (ต้องรองรับ WebSocket และมีดิสก์เก็บ `data/`)

## วิธีเล่น (สรุป)
- คลิก/แตะที่พื้น = เดินไปที่นั่น, คลิกที่ช่องที่ทำอะไรได้ (แปลงผัก น้ำ ร้านค้า สัตว์) = เดินไปแล้วทำให้เลย
- กด **B** (หรือปุ่ม 🎒) เปิดกระเป๋า / อาชีพ / เปลี่ยนสีชุด-หมวก
- 3 อาชีพมีเลเวลแยกกัน: ชาวนา (เมล็ด 8 ชนิดปลดล็อกตามเลเวล), ชาวประมง (ปลา 10 ชนิด, คันเบ็ด 3 ระดับ), คนเลี้ยงสัตว์ (ไก่/วัว)
- ร้านค้าแยกตามสาย อยู่ใกล้แปลงผัก / สระน้ำ / ทุ่งสัตว์ ขายของที่เกี่ยวกับสายนั้นและรับซื้อผลผลิตของสายนั้น (เลือกขายได้ทีละชนิด)
- เสียงแชท: ตอนนี้ได้ยินกันทั่วแมพ (ตั้ง `VOICE_GLOBAL = false` ใน `public/game.js` เพื่อกลับไปใช้ระยะ: เต็มที่ ≤3 ช่อง เบาลงจนเงียบที่ 7 ช่อง)
- แผนที่ย่อมุมขวาบน: กดที่แผนที่หรือปุ่ม 🔍 เพื่อขยาย/ย่อ, ปุ่ม ➖ ซ่อน (ปุ่ม M สลับ) เห็นตำแหน่งผู้เล่นทุกคนพร้อมชื่อ
- ปุ่ม 📊 (หรือ C) ดูสถานะตัวเอง: เหรียญ ของในกระเป๋า เลเวลอาชีพ ตำแหน่ง
- ปุ่ม 🐞 แจ้งบั๊ก: ผู้เล่นพิมพ์ปัญหา + แนบภาพ (PNG/JPG/WEBP/GIF ไม่เกิน 1MB) ส่งผ่าน `POST /api/bug` (ไม่ผ่าน WebSocket เพราะจำกัด 16KB) เก็บที่ `data/bugs/<id>.json` + ภาพ (ไม่ขึ้น git ไม่เปิดให้โหลดจากเว็บ) เก็บเฉพาะข้อความ + ภาพ (+ ชื่อตัวละคร/ห้อง/เวลา) ไม่เก็บ IP หรือข้อมูลอุปกรณ์ กันสแปม 5 ครั้ง/10 นาที/IP และ 100 ครั้ง/ชม. ทั้งเซิร์ฟเวอร์ ตรวจชนิดภาพจากไบต์จริง ผู้ดูแลอ่านได้ในเกมที่เมนู 🛠️ → แท็บ 🐞 บั๊ก แยก 🔴 ยังไม่แก้ / ✅ แก้แล้ว (กด "แก้แล้ว" ย้ายไปอีกฝั่ง กด "เปิดใหม่" ย้ายกลับ รายงานและภาพเก็บไว้ตลอด ไม่มีปุ่มลบในเกม มี toast แจ้งเมื่อมีรายงานใหม่) หรือใช้ `node tools/bugs.js` (`fix <id>` / `reopen <id>`) (`<id>` ดูรายละเอียด, `rm <id>` ลบเมื่อแก้แล้ว)

- 🎮 **อาคารตู้เกม** (กลางแมพเหนือจุดเกิด): แต่ละเกมเป็นตู้ ตอนนี้เปิดแล้ว 1 ตู้คือ **XO** เดิมพันด้วยเหรียญได้ (0/10/50/100/500) หรือซ้อมกับบอท
  - เสียเหรียญเดิมพันไว้ล่วงหน้า (escrow) ผู้ชนะได้ของทั้งสองฝ่าย เสมอคืนเหรียญ ตาละ 30 วินาที ออกจากเกมหรือหมดเวลา = แพ้
  - ตู้ **UNO** เล่นได้ 2-4 คน (ผู้สร้างเลือกจำนวนคนและเดิมพัน, เริ่มเลยก่อนห้องเต็มได้ถ้ามี ≥2 คน) มีโหมดซ้อมกับบอท
  - เพิ่มเกมใหม่: ใส่ `game` ที่ตู้ใน `CABINETS` (`public/shared.js`) แล้วเขียนกติกาฝั่งเซิร์ฟเวอร์ (`server.js` ส่วน Arcade)

- 🐖 **หมู**: ซื้อที่ร้านปศุสัตว์ (เลเวลคนเลี้ยงสัตว์ 5) ให้อาหารหมู แล้วเก็บเห็ดทรัฟเฟิล 🍄 ขายได้ราคาสูง อยู่ในคอกหมูมุมขวาบนของฟาร์มสัตว์
- 💹 **เศรษฐกิจ**: ตลาดรับซื้อมีราคาขึ้นลง (ขายเยอะราคาตก 2% ต่อชิ้น ทิ้งไว้ราคาค่อยๆ กลับ ทุกวันในเกมมีข่าวราคาพุ่ง/ตก) • ตกปลาต้องใช้เหยื่อ 🪱 (ชิ้นละ 2) • ตู้เกมหักค่าบริการ 5% จากรางวัล
  - ปรับตัวเลขต่างๆ ได้ใน `public/shared.js` (`FISH`, `CROPS`, `ANIMALS`, `BAIT_PRICE`, `RAKE`, `MARKET`)
- 🔊 **เสียงเอฟเฟกต์**: ขุด/รดน้ำ/ปลูก/เก็บเกี่ยว/ตกปลา/ให้อาหารวัว-ไก่-หมู/ซื้อขาย/เลเวลอัป/ชนะแพ้ในตู้เกม (คนอื่นทำใกล้ๆ ก็ได้ยินเบาๆ) เปิด/ปิดได้ในแท็บสถานะ
- ⌨️ WASD/ปุ่มลัดใช้ได้แม้เปลี่ยนเป็นแป้นพิมพ์ภาษาไทย (อ้างอิงตำแหน่งปุ่ม)
- 🎮 ตู้เกมตอนนี้มี 6 ตู้: เป่ายิ้งฉุบ, XO, UNO, ใครกดเร็วกว่า, ไพ่ป๊อก, Connect 4 (ทุกเกมซ้อมกับบอทได้ ยกเว้นต้องมีคนจริงถึงจะเดิมพัน)

- 🍖 **ความหิว**: ผู้เล่นหิวลงเรื่อยๆ ขณะออนไลน์ (ต่ำกว่า 15 เดินช้าลง, 0 = ใช้เครื่องมือไม่ได้) กินที่ 🍜 ร้านอาหาร หรือกินผลผลิตของตัวเองในกระเป๋า
- 💀 **สัตว์หิวและตาย**: สัตว์ต้องให้อาหารเป็นระยะ ถ้าหิวจนหมดแล้วไม่มีใครให้อาหารภายใน 4 นาทีจะตาย (นับเฉพาะตอนมีคนออนไลน์) ต้องซื้อตัวใหม่
- 👕 **ร้านเสื้อผ้า**: ซื้อเสื้อ/กางเกง/หมวกหลายแบบด้วยเหรียญ สวมและเลือกสีได้ในแท็บ "ตัวละคร" มีตัวอย่างให้ดู (ซื้อของที่ `WEAR` ใน `public/shared.js`)
- 🐾 **ร้านสัตว์เลี้ยง** (`pet` ใน `BUILDINGS`/`SHOPS` ที่ 36,10): ซื้อหมา 🐶 แมว 🐱 นก 🐦 ลิง 🐒 คาปิบาร่า 🦫 (`COMPANIONS` ใน `shared.js`) เป็นไอเทมชิ้นเดียว (`pet_<ชนิด>`) ขายคืน 70% + อาหาร `petfood` + ยา `medicine` • เซิร์ฟเวอร์เก็บตัวที่พาออก `rec.pet`, โหมด `rec.pmode` (follow/play), สถานะ `rec.pst` (ความอิ่ม/ป่วย ปรับที่ `PETCARE`) ข้อความ `pet` / `petcare` แล้ว broadcast • ฝั่งเว็บจำลองการเดินเอง (`drawCompanion` ใน `game.js`) เมนู 🐾 = `petPanelHtml`
  - 🤒 สัตว์เลี้ยงที่พาออกมาหิวจัดแล้วอาจป่วย ต้องรักษาด้วยยา 💊 จากร้านสัตว์เลี้ยง ถ้าป่วยนานเกิน 1 วันในเกม (นับเฉพาะตอนมีคนออนไลน์) สัตว์จะตาย และต้องซื้อตัวใหม่ (`PETCARE.sickDieMs`)
- 🗺️ **แมพ**: ตู้เกมเรียง 2 แถว แถวละ 4 ตู้ พร้อมป้ายใหญ่ ร้านค้าทุกร้านเป็นอาคารเล็ก (ประหยัดพื้นที่)

- 🪓 **ช่างไม้** (อาชีพที่ 4): ซื้อขวานที่ร้านช่างไม้ ตัดต้นไม้ได้ไม้ท่อน (ไม้เนื้อแข็งหายากราคาแพง) ขายได้ ต้นไม้งอกใหม่เองในที่โล่งห่างสิ่งปลูกสร้าง (ยังไม่มีงานฝีมืออื่น)
- 🔥 **ลานกองไฟกลางหมู่บ้าน**: มีม้านั่ง กองฟาง เก้าอี้ (กดที่ที่นั่งเพื่อนั่ง เดินเพื่อลุก) กลางคืนมืดมาก สว่างเฉพาะรอบกองไฟ • ซื้อ 🏮 ตะเกียงที่ร้านเฟอร์นิเจอร์ (กด L เปิด/ปิด) สว่างรอบตัว 5 ช่อง
- 🤒 **สัตว์ป่วย**: ป่วยทีละ 1 ตัวเท่านั้น สุ่มวันละครั้ง (1 วันในเกม = 12 นาทีที่มีคนออนไลน์) โอกาส 30% วันไหนไม่ป่วยก็ข้ามไปวันถัดไป (ปรับที่ `SICK` ใน `shared.js`) รักษาด้วยยา 💊 (ร้านปศุสัตว์ ใช้ผ่านช่องอาหารสัตว์ที่ hotbar) ถ้าไม่รักษาตายเร็วกว่าหิวปกติ
- ↩️ **ขายคืน**: เสื้อผ้า คันเบ็ด ขวาน ขายคืนร้านได้ 70% ของราคาซื้อ • ตะเกียง/ไฟฉายไม่มีขายในร้านและขายต่อไม่ได้ ได้จากรางวัลจบคู่มือเริ่มต้น
- 🎰 **คาสิโน** (ตู้บาคาร่า/แบล็คแจ็ค 2-3 คน เล่นกับเจ้ามือ): โชคของผู้เล่นแต่ละคนลดลงตามการเล่นต่อเนื่อง (ซ่อนไว้ ปรับที่ `CASINO` ใน `public/shared.js` และฟังก์ชัน `casinoBias` ใน `server.js`)
- 🚲 ร้านยานพาหนะ: เตรียมไว้ ยังไม่ขาย

## รายละเอียดปุ่ม
| ปุ่ม | ทำอะไร |
|---|---|
| WASD / ลูกศร | เดิน (มือถือใช้จอยสติ๊ก) |
| Space / คลิก / ปุ่ม A | ใช้เครื่องมือกับช่องที่หันหน้าไป |
| 1–4 / Q | ช่อง 1 = **เครื่องมือ** (จอบ บัวรดน้ำ เบ็ด ขวาน เลือกจากเมนูที่เด้งขึ้น หรือกด Q สลับ) • ช่อง 2 = เมล็ด • ช่อง 3 = อาหารสัตว์/ยา (เหยื่อตกปลาเลือกในเมนูเครื่องมือ) |
| 4 | ช่อง 4 = **มือเปล่า** (เก็บผลผลิต เปิดร้าน นั่ง) ไม่มีเมนู |
| Enter | แชท |

- ปลูก: จอบขุดดินในแปลง → รดน้ำ → หยอดเมล็ด → รอโต (โตเฉพาะตอนดินเปียก) → กดเก็บเกี่ยว
- แปลงว่างที่ไม่มีใครถาง/ปลูกเกิน 1 วันในเกม (`FARM_REGROW_MS` ใน `shared.js`) หญ้าจะขึ้นกลับ ต้องถางใหม่
- ตกปลา: ยืนริมบ่อหันหน้าหาน้ำ ใช้เบ็ด พอขึ้น ❗ ให้กดทันที
- ไก่: ให้อาหาร แล้วรอไข่ขึ้น 🥚 เดินไปกดเก็บ
- ร้านค้า: ยืนใต้เคาน์เตอร์แล้วกดหันหน้าหาเคาน์เตอร์ ซื้อเมล็ด/ขายของ

ปรับเวลาโตของพืช/ราคา/ปลาได้ใน `public/shared.js`
ตัวละครผูกกับชื่อ (ไม่มีรหัสผ่าน)

- 📉 **ลิมิตตลาด**: ขายของชนิดเดียวกันเยอะๆ ราคาจะตกต่อเนื่องทีละชิ้น (ต่ำสุด 20% ของราคา) ทิ้งไว้ราคาค่อยๆ กลับมา (ปรับที่ `MARKET` ใน `public/shared.js`)
- 🔧 **ความทนทานเครื่องมือ**: จอบ เบ็ด ขวาน สึกหรอเมื่อใช้ ถ้าพังต้องซ่อมที่ร้านของสายนั้น (ค่าซ่อมตามความเสียหาย) เป็นรายจ่ายประจำ (ปรับที่ `DURABILITY`)
- 🤝 **เทรด**: เมนู 👥 คนในแมพ → ปุ่ม 🤝 เทรด (ต้องอยู่ใกล้กัน 8 ช่อง) แลกของได้เท่านั้น ไม่มีเหรียญ มูลค่าฝั่งละไม่เกิน 1000 ต่อรอบ ทั้งสองฝ่ายกดยืนยัน (ปรับที่ `TRADE`)
- 🎬 **หนังกลางแปลง** (ลานใต้ตู้เกมฝั่งใต้): กดที่จอ วางลิงก์ YouTube หรือเลือกหนังฟรี ตั๋ว 🪙15 ทุกคนที่เข้าไปดู **ซิงก์กัน**: ใครกดเล่น/หยุด/เลื่อนเวลา ทุกคนตามทันที (มีปุ่ม 🔄 ซิงก์ใหม่) เสียงมาจากหน้าต่างของคนที่เข้าไปดูเท่านั้น คลิปที่ปิดการฝังจะเล่นไม่ได้ (ตั้งหนังฟรีที่ `MOVIES`)

- 🏠 **บ้านหลังใหญ่ของทุกคน**: ทุกคนมีบ้านของตัวเองหลังเดียว (ฟรี ไม่ต้องซื้อ) เป็นแมพแยกจากเมือง วาดเป็น **มุมมองไอโซเมตริก** (ห้องตัดผนังหน้า เห็นผนังหลัง 2 ด้าน หน้าต่างบานเกล็ด พื้นไม้กระดาน) กว้าง 22×15 ช่อง • **ทางเข้า:** บ้านหลังใหญ่ตั้งอยู่ทางเหนือของถนนบน (ประตูที่ช่อง 27,5) เดินเข้าไปยืนที่ประตู (หรือแตะตัวบ้าน) จะมีหน้าต่างให้เลือก **🏠 เข้าบ้านตัวเอง** หรือ **🏘️ เข้าบ้านเพื่อน** (เปิดลีดเดอร์บอร์ด) • หรือเข้าตัวเองลัดจากเมนู ☰ → 🏠 **บ้านฉัน** (คีย์ H) ตำแหน่งปรับที่ `HOUSE_DOOR`/`HOUSE_BLD` ใน `public/shared.js` • ออกด้วยปุ่ม 🚪 ออกจากบ้าน หรือเดิน/แตะพรมหน้าประตู แล้วกลับมายืนที่เดิมในเมือง
  - เดินในบ้าน: คลิก/แตะพื้นเพื่อเดิน (หาทางหลบเฟอร์นิเจอร์เอง) • WASD/ลูกศร/จอยสติ๊กเดินตามทิศบนจอ • แตะเก้าอี้/โซฟาเพื่อเดินไปนั่ง (เดินเพื่อลุก) • โคมไฟสว่างตอนกลางคืน
  - **กดค้างที่ของ** (มือถือ) = หยิบชิ้นนั้น เมนูตกแต่งเด้งขึ้นมาให้ลาก หมุน หรือเก็บได้ทันที เมนูเหมือนกันทั้งมือถือและคอม (มุมบนขวา)
