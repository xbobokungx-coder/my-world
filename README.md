# 🌾 My World

เกมฟาร์มสบายๆ ออนไลน์ ปลูกผัก ตกปลา เลี้ยงไก่ เพื่อนกดลิงก์แล้วใส่ชื่อก็เล่นด้วยกันได้ทันที

> 📘 กติกาและตัวเลขทั้งหมดตามโค้ดจริงอยู่ที่ [`GAME-DESIGN.md`](GAME-DESIGN.md) (แหล่งความจริงเดียว) • แผน/เหตุผลการปรับ: [`ECONOMY-PLAN.md`](ECONOMY-PLAN.md) [`docs/plans/GROWTH-PLAN.md`](docs/plans/GROWTH-PLAN.md) • วิธีเล่นสำหรับผู้เล่น: [`HOW-TO-PLAY.md`](HOW-TO-PLAY.md) • รายการฟีเจอร์ด้านล่างเป็นบันทึกเก่า บางข้อเปลี่ยนไปแล้ว

## รัน

```bash
npm install
npm start
```

เปิด http://localhost:3000 — ปุ่ม "🔗 ชวนเพื่อน" ในเกมจะคัดลอกลิงก์ส่งให้เพื่อนได้เลย
ทุกคนเข้าโลกเดียวกัน (ห้องหลักชื่อ `main` ผู้ดูแลสร้างห้องเพิ่มได้ ดูหัวข้อผู้ดูแล) บันทึกที่ `data/<ห้อง>.json` (ตั้งโฟลเดอร์ด้วย `DATA_DIR`, พอร์ตด้วย `PORT`)

ตัววัดเฟรมบนจอ (ดีบัก): เปิด `?perf=1` ท้าย URL หรือสวิตช์ใน ☰ → 🖥️ หน้าจอ (เก็บใน localStorage `mw_perf`) โค้ดอยู่ที่ `public/game.js` หัวข้อ "ความละเอียดแคนวาส + ตัววัดเฟรม" ส่วนโหมดความละเอียด `mw_res` ดูรายละเอียดใน `GAME-DESIGN.md` หัวข้อ 2 (แถว 🖼️ ความละเอียดแคนวาส)

## ให้เพื่อนเข้าจากอินเทอร์เน็ต
- ชั่วคราว: `cloudflared tunnel --url http://localhost:3000` (หรือ ngrok) แล้วส่งลิงก์ที่ได้
- ถาวร: deploy เป็น Node/Docker server (ต้องรองรับ WebSocket และมีดิสก์เก็บ `data/`)

## วิธีเล่น (สรุป)
- คลิก/แตะที่พื้น = เดินไปที่นั่น, คลิกที่ช่องที่ทำอะไรได้ (แปลงผัก น้ำ ร้านค้า สัตว์) = เดินไปแล้วทำให้เลย
- กด **B** (หรือปุ่ม 🎒) เปิดกระเป๋า / อาชีพ / เปลี่ยนสีชุด-หมวก
- 5 อาชีพมีเลเวลแยกกัน: ชาวนา (เมล็ด 20 ชนิดปลดล็อกตามเลเวล), ชาวประมง (ปลา 20 ชนิด, คันเบ็ด 7 ระดับ), คนเลี้ยงสัตว์ (สัตว์ 11 ชนิด ปลดตามเลเวล ดูตาราง GAME-DESIGN หัวข้อ 6)
- ร้านค้าแยกตามสาย อยู่ใกล้แปลงผัก / สระน้ำ / ทุ่งสัตว์ ขายของที่เกี่ยวกับสายนั้นและรับซื้อผลผลิตของสายนั้น (เลือกขายได้ทีละชนิด)
- เสียงแชท: ตอนนี้ได้ยินกันทั่วแมพ (ตั้ง `VOICE_GLOBAL = false` ใน `public/game.js` เพื่อกลับไปใช้ระยะ: เต็มที่ ≤3 ช่อง เบาลงจนเงียบที่ 7 ช่อง)
- แผนที่ย่อมุมขวาบน: กดที่แผนที่หรือปุ่ม 🔍 เพื่อขยาย/ย่อ, ปุ่ม ➖ ซ่อน (ปุ่ม M สลับ) เห็นตำแหน่งผู้เล่นทุกคนพร้อมชื่อ
- ปุ่ม 📊 (หรือ C) ดูสถานะตัวเอง: เหรียญ ของในกระเป๋า เลเวลอาชีพ ตำแหน่ง
- ปุ่ม 🐞 แจ้งบั๊ก: ผู้เล่นพิมพ์ปัญหา + แนบภาพ (PNG/JPG/WEBP/GIF ไม่เกิน 1MB) ส่งผ่าน `POST /api/bug` (ไม่ผ่าน WebSocket เพราะจำกัด 16KB) เก็บที่ `data/bugs/<id>.json` + ภาพ (ไม่ขึ้น git ไม่เปิดให้โหลดจากเว็บ) เก็บเฉพาะข้อความ + ภาพ (+ ชื่อตัวละคร/ห้อง/เวลา) ไม่เก็บ IP หรือข้อมูลอุปกรณ์ กันสแปม 5 ครั้ง/10 นาที/IP และ 100 ครั้ง/ชม. ทั้งเซิร์ฟเวอร์ ตรวจชนิดภาพจากไบต์จริง ผู้ดูแลอ่านได้ในเกมที่เมนู 🛠️ → แท็บ 🐞 บั๊ก แยก 🔴 ยังไม่แก้ / ✅ แก้แล้ว (กด "แก้แล้ว" ย้ายไปอีกฝั่ง กด "เปิดใหม่" ย้ายกลับ รายงานและภาพเก็บไว้ตลอด ไม่มีปุ่มลบในเกม มี toast แจ้งเมื่อมีรายงานใหม่) หรือใช้ `node tools/bugs.js` (`fix <id>` / `reopen <id>`) (`<id>` ดูรายละเอียด, `rm <id>` ลบเมื่อแก้แล้ว)

- 🎮 **อาคารตู้เกม** (กลางแมพเหนือจุดเกิด): แต่ละเกมเป็นตู้ ตอนนี้มี 6 ตู้ (ดูหัวข้อ 🎮 ตู้เกมด้านล่าง) เดิมพันด้วยเหรียญได้ (0/10/50/100/500) กับคนจริงเท่านั้น
