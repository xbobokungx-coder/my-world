# สารบัญเอกสาร (docs/)

เอกสารหลักที่ใช้ทุกวันอยู่ที่รากรีโป: `README.md`, `CLAUDE.md`, `GAME-DESIGN.md`, `HOW-TO-PLAY.md`, `STYLE_GUIDE.md`, `ECONOMY-PLAN.md`

| โฟลเดอร์/ไฟล์ | เก็บอะไร |
|---|---|
| `OPS.md` | VPS, deploy (`tools/deploy.sh`), สำรองข้อมูล |
| `SETUP-MACHINES.md` | ตั้งค่าเครื่อง dev ทั้ง 3 เครื่อง |
| `HANDOFF.md` | สถานะงานล่าสุด ส่งต่อระหว่างเครื่อง (อัปเดตด้วย `/handoff`) |
| `START-PROMPTS.md` | ข้อความเริ่มต้นสำหรับ Claude Code ทีละขั้น |
| `plans/` | แผนระบบและแผนงาน: `AGENTS-PLAN` `REFACTOR-PLAN` `ROADMAP` `GROWTH-PLAN` `LOTTO-PLAN` `MINING-PLAN` `SEA-PLAN` และแผนที่ `architect` เขียน |
| `tasks/` | ตั๋วงานรายชิ้น (แม่แบบ `_TEMPLATE.md`) |
| `reports/` | รายงานและบันทึกปัญหา เช่น `ISSUES-2026-10`, `ECONOMY-REVIEW` |
| `archive/` | เอกสารเก่าที่เก็บไว้อ้างอิง (`THEME-*`) |
| `assets/` | ไฟล์ประกอบเอกสาร เช่น `map-layout.svg` |

ตัวอย่างภาพธีมเก่า (เดิมอยู่ `public/_theme/`) ย้ายไป `art/theme-samples/` แล้ว ไม่ถูกเสิร์ฟให้ผู้เล่น
