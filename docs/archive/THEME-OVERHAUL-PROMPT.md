# เป้าหมาย
ปรับ "หน้าตา/ธีม" ของเกมทั้งระบบให้คุณภาพและโทนเดียวกับภาพอ้างอิงที่แนบ (ฉากลานกองไฟกลางเมือง: หญ้าเขียวสด มีดอกไม้ แมลงบิน ทางดินอุ่น ร้านไม้หลังคาสีชัด มีของแต่งหน้าร้าน ตัวละคร chibi พิกเซล ป้ายชื่อกระดาษ แสงแดดอุ่น) — ให้ทุกโซนในแมพ บ้าน ร้าน UI และไอคอน รู้สึกเป็นโลกเดียวกัน ไม่ใช่แค่ลานกลางสวยอย่างเดียว

# ห้ามทำ
- ห้ามเปลี่ยนกติกาเศรษฐกิจ ราคา เวลาโต XP อาชีพ WebSocket protocol หรือโครงสร้างข้อมูลผู้เล่น (`data/`)
- ห้ามเพิ่ม framework / build step / dependency ใหม่ฝั่งเว็บ (ต้องเป็น Canvas 2D + JS ล้วนเหมือนเดิม)
- ห้ามจัดรูปแบบไฟล์ทั้งไฟล์ใหม่ (diff ต้องเล็ก ตรงจุด)
- ห้ามเขียนความลับ / รหัสผ่าน / แตะ `admin.key` `data/` `.env`
- ห้ามทำให้ของเดิมใช้การไม่ได้: ร้านยังเปิดได้ แปลงยังปลูกได้ ตกปลายังได้ ตัดไม้ได้ บ้านแต่งได้ ไมค์/แชทยังใช้ได้

# สแต็กและไฟล์ที่แตะได้ (เฉพาะภาพ)
- `public/pixelart.js` — พื้น ต้นไม้ อาคาร รั้ว ทาง น้ำ

- `public/index.html` — CSS UI (กระดาษ/ปุ่ม/ฮอตบาร์) เท่านั้น ไม่ย้ายเลย์เอาต์ใหญ่โดยไม่จำเป็น
- `STYLE_GUIDE.md` — อัปเดตให้ตรงของใหม่เมื่อจบเฟส

# ข้อจำกัดเทคนิคที่ต้องคงไว้
- มุมกล้อง top-down orthographic ไม่หมุน ไม่ perspective
- 1 ช่อง = 32 px • แมพ 64×46 • สไปรต์วาดที่ 16 px แล้วสเกล ×2 แบบไม่เบลอ (`imageSmoothingEnabled = false`)
- ขอบพิกเซล 1 px สีประมาณ `#2a1b14` • แสงจากซ้ายบน • ทุกชิ้นมี 3 โทน (หลัก / เงา / ไฮไลต์)
- เงาใต้ตัว = วงรีดำโปร่ง ไม่ใช้เงาดำทึบ
- ลำดับวาดเรียงตามแกน y เหมือนเดิม
- UI ภาษาไทย น้ำเสียงสบายๆ ฟอนต์ Noto Sans Thai
- มือถือต้องเล่นได้ (ฮอตบาร์/ปุ่มเดิมใช้ได้)

# โทนเป้าหมายจากภาพอ้างอิง (สรุปให้ทำตาม)
1) พื้นโลก: หญ้าเขียวอิ่มตัว มีดอกไม้จุดเล็ก (เหลือง/ชมพู/ฟ้า) จุดแมลง/ผีเสื้อเบาๆ ไม่รกตา ทางเดินดินอุ่นมีเท็กซ์เจอร์ ไม่เรียบทึบ
2) น้ำ: โทนเทอร์ควอยส์ใส ริมฝั่งอ่อน เห็นทรายใต้ตื้น มีริ้วคลื่นช้า
3) อาคารร้าน: ไม้ครีม + หลังคาสีตามร้าน (หนึ่งร้านหนึ่งสี) มีรายละเอียดหน้าร้าน (ถัง ลัง ป้าย กระถาง กันสาดลายทาง) ไม่ใช่กล่องเรียบ
4) ของเมือง: กองไฟมีเปลว/แสงอุ่น กระดานข่าว ATM/ตู้ เสาไฟ ม้านั่ง — สไตล์ไม้พิกเซลเดียวกัน
5) ตัวละคร: chibi หัวโต แก้มชมพู อ่านอาวุธ/ชุดได้ชัดที่ขนาดจริง ป้ายชื่อ + ฉายาเป็นกล่องกระดาษขอบเข้ม
6) UI: กระดาษครีม `#fff8e7` ขอบไม้ `#d9b97a` ปุ่มส้มอุ่น มีเงา Soft แบบ "ของเล่นไม้" ไม่ใช้ธีมมืด/นีออน/ม่วงไซไฟ
7) แสง: กลางวันอุ่น มีไฮไลต์แดดบางๆ ได้ แต่ห้ามเลนส์แฟลร์แรงจนรก กลางคืนยังมืดตามระบบเดิม + แสงอุ่นรอบไฟ/ตะเกียง
8) อารมณ์รวม: cozy farming / social village (แนว Stardew อบอุ่น) สดใส อ่านง่าย ไม่มืด ไม่ไซเบอร์ ไม่ realistic 3D

เฟส D — UI ทั้งระบบ
- index.html CSS: แผงร้าน กระเป๋า เควส เมือง แชท ฮอตบาร์ ให้โทนกระดาษ/ไม้เดียวกับโลก
- ห้ามเปลี่ยนโครงสร้าง id ของ element ที่ `game.js` อ้างผ่าน `$('id')` โดยไม่จำเป็น (ถ้าต้องเพิ่ม id ใหม่ ต้องมีใน HTML)

เฟส E — เก็บกวาด
- อัปเดต `STYLE_GUIDE.md` ให้ตรงของใหม่
- อัปเดตสั้นๆ ใน `README.md` / `HOW-TO-PLAY.md` เฉพาะถ้าผู้เล่นเห็นความต่างที่ต้องอธิบาย
- รัน `node tools/check.js` ต้องผ่าน
- commit ข้อความไทยสั้นๆ ต่อเฟส แล้ว push
- แก้เฉพาะ `public/*` = ไม่ต้อง restart • ถ้าแตะ `server.js` = ดูคนออนไลน์ก่อน แล้ว `systemctl restart my-world` + `curl -s localhost:3000/healthz`
