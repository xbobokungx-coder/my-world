## 3. ส่งต่อ server-dev (ต้องมีโค้ด ผมแก้ได้เฉพาะตัวเลข)

### 3.1 ราคาอาหารตามวัตถุดิบที่ใช้ (แนะนำ B')
กฎราคา: ส่วนเกินของวัตถุดิบ "ผ่านตรง" ไม่ให้กำไรเพิ่ม มูลค่าเพิ่มคงเท่ากรณีของถูกสุด
`sell(ใช้ของ R) = sell_ฐาน + round((R − R_ถูกสุดของสูตร) / (1 − COOK_FEE))` (R = มูลค่าขายดิบรวมของช่องหมวดกว้างทุกช่อง)
- กรณีถูกสุดเท่าเดิม 100% (ซิมเชฟไม่ขยับ) • ใช้ของแพงขึ้น net = วัตถุดิบ + มูลค่าเพิ่มเดิม (ไม่ขาดทุน ไม่กำไรเกินฐาน)
- ตัวอย่าง ปลาเผาเกลือ: คาร์ป 14 → 20 • กะพง 22 → 31 • กุ้งมังกร 60 → 86 • ดาวทะเลทอง 800 → 1,143 (ตอนนี้ทุกตัว 20 หรือ 15)
- เก็บเป็นคีย์ระดับ (ห้ามใช้ `:`): `dish_saltfish` = ระดับ 0 (ของเดิม ราคาฐาน) และ `dish_saltfish_q1..` โดย Δ ตัวแทน = round(8 × 1.3^t) เลือกระดับที่ใกล้ Δ จริงที่สุด (คลาดเคลื่อน ±13% ของส่วนเกินเท่านั้น)
- เซฟเก่า: คีย์เดิมคงอยู่ ราคาฐาน ไม่ต้อง bump xpv เพิ่มแต่คีย์ใหม่เท่านั้น
- จุดที่ต้องไล่ (ทุกที่อ่านคีย์ inv): `itemInfo` (regex `^dish_(\w+)$` ต้องแปลง `_qN`), `sellCat`/`SELLABLE`/`FOOD`/สูตรกินอิ่ม, ขายระบบ, ตลาด/แผง (`tradeValue`), ใบสั่งซื้อ ORDERS, ตู้ฝาก HOME.store, `holdingsValue`, `tools/economy.js`, ตัวแสดงชื่อกระเป๋า/UI
- เทสต์ที่ควรมี: ทุกระดับ net ≥ วัตถุดิบ; ระดับ 0 = sell ฐาน; ซื้อ(แผง 0.5x)→ทำ→ขาย ไม่ได้กำไรมากกว่ามูลค่าเพิ่มฐาน; เซฟเก่าโหลดได้
- ทางสำรองถูกที่สุด (ถ้าไม่ทำ B'): เพิ่ม `max` ราคาต่อช่องในสูตรหมวดกว้าง (บล็อกปลาแพงออกจากสูตรถูก) แก้ขาดทุนได้ แต่ไม่ได้ผูกราคาตามปลา

### 3.2 ช่างไม้ (ต้องเจ้าของตัดสิน เพราะขัดหลักเดิม "เฟอร์นิเจอร์ไม่ใช่ช่องทางทำเงิน")
สภาพ: ราคารับซื้อคืนเฟอร์นิเจอร์ `FURN_SELL` 0.35 + ค่าโรงช่าง 20% ของราคา (เฉพาะแบบเลิกขายในร้าน) → ประดิษฐ์แล้วขายระบบได้ net 0.15 ของราคา ขณะวัตถุดิบดิบ ~0.5–0.6 (ขายไม้ดิบดีกว่า 3–4 เท่า) ช่องทางที่คุ้มคือแผงผู้เล่นเท่านั้น (ราคามาตรฐาน = ราคาเต็ม)
เสนอ: ค่าใหม่ `FURN_SELL_CRAFT` = 0.85 ใช้เฉพาะแบบ `noshop` (ร้านไม่ขาย จึงไม่มีทางปั๊ม ซื้อ→ขายคืน) แบบที่ร้านขายคง 0.35 • คิดค่าโรงช่าง 20% กับแบบที่ร้านขายด้วย (ตอนนี้ 0 ค่าตายตัว ขัด "ยิ่งแพงยิ่งแพง") • net = 0.65 × ราคา เทียบวัตถุดิบ 0.53–0.60 ได้กำไร +8–22%
สูตรที่ต้องปรับพร้อมกัน (ให้มาร์จิ้นอยู่ +8–26% ใช้ plank 44): ตัวเลข "วัตถุดิบ → ใหม่ (xp ใหม่)"
เก้าอี้ ไม่เปลี่ยน • โต๊ะ ไม่เปลี่ยน • ชั้น log 10→11 (18) • เตียง log 14→12 (28) • ฉากไผ่ bamboo 8→16 (40) • สตูล ไม่เปลี่ยน • อาร์มแชร์ ปาล์ม 3→4 (32) • ตู้เสื้อผ้า สัก 5→6 (85) • ตู้เครื่องแป้ง ราชพฤกษ์ 4→5 (81) • เตียงคิงไม่เปลี่ยน • โต๊ะข้างเตียง log 4→5 (24) • ฉากไม้ plank 2→3 (56) • โต๊ะกาแฟ bamboo 6→7 (26) • เตียงเดี่ยว สน 6→8 (56) • ตู้ข้าวของ ปาล์ม 5→6 (64) • โต๊ะทำงาน สัก 4→5 (66)
ความเสี่ยง: เป็น faucet ใหม่ (ไม้ → NPC +8–22%) ผูกกับการตัดไม้ที่ซิมคุมอยู่ (ช่างไม้ Lv11+ เหรียญ 68–75% ของชาวนา มีที่ว่าง) • ของแจกฟรีที่เป็นเฟอร์นิเจอร์ `noshop` จะขายได้ 0.85 • ต้องกัน `FURN.rare` (ไม่ขายอยู่แล้ว) • ยังไม่ได้ใส่ในโค้ด/ตัวเลข ถ้าเจ้าของไม่อนุมัติ ไม่ต้องแตะสูตร N

## 4. ทำไมไม่ลดราคาปลา
- ราคาปลา < 100 ผูก `fishClass` (20/60/120) และ `fishWeight` ฝังเลข 100 + ผู้เล่นถือสต็อก • ราคา ≥ 100 คือคันโยกเหรียญของชาวประมง (ปรับด้วย `RARE_CD.endMul` ให้ 88–120% ของชาวนา) ลดราคาต้องไล่ปรับซิมทั้งเส้นโดยไม่ได้แก้ปัญหา "ขาดทุนตอนทำอาหาร"
