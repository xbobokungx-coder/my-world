## 2) ความสบาย/บัฟ (ไม่แก้ค่า)
- ค่าอาหาร: หิว 7.2 แต้ม/นาทีตอนทำงาน × 0.4 เหรียญ/แต้ม (ขนมปัง) = 173 เหรียญ/ชม. (เท่า econsim)
- บัฟหลับสบาย ขั้น 3 + ห้องนอนครบ = 53 นาที คลุม 88% ของชั่วโมง ประหยัด ~38 เหรียญ/ชม. (22%) • ชุดครัว +20% อีก ≤22 เหรียญ/ชม. (เพดานทฤษฎี ต้องกินในบ้านล้วน) รวม ≤60 = 35% ของค่าอาหาร → ค่าอาหารไม่เป็นศูนย์
- บัฟร้าน "อิ่มทน" (8 เหรียญ/15 นาที ลด 50%) สุทธิ ~56 เหรียญ/ชม. ดีกว่าบัฟบ้าน → บัฟบ้านไม่เกินของเดิม
- ต้นทุนบ้านขั้น 3 + ชุดนอน/ครัว/นั่งเล่น (ซื้อถูกสุด) 27 ชิ้น 6,635 เหรียญ → คืนทุน ~110 ชม.เล่น (55 วันที่เล่น 2 ชม./วัน) ทำเองประมาณ 70–75% ของราคา ~80 ชม. • "คืนทุนใน 2–14 วัน" ทำไม่ได้: ต้องประหยัด ≥237/ชม. > ค่าอาหารทั้งหมด (173) = ขัดข้อกำหนดค่าอาหารไม่เป็นศูนย์ → ถือเป็นของตกแต่ง/ความสะดวก ไม่ใช่การลงทุน (ผลต่อเงินรวมไม่ถึง 2% ของรายได้)
- นั่งฟื้นอิ่มเร็ว (ขั้น 3 = 30 แต้ม/นาที) ไม่คุ้มเทียบทำงาน+ซื้อขนมปัง จึงไม่เป็นช่องโกง
