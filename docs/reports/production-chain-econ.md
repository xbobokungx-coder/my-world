## 3. ช่องปั๊มเงิน: วัสดุถูก + ซื้อ/ขายคืนอุปกรณ์ 70%
ต้นทุนซื้อ = P×(1 − s + s×q/shopMul) เทียบเงินคืน 0.70×P (q = ราคาวัสดุที่ผู้ซื้อได้ หน่วย std)
- s ที่เริ่มปั๊ม: q=0.5 (เสนอซื้อพื้นแผง): shopMul 1.3 → 0.49 • **1.5 → 0.45** • 2.0 → 0.40 • q=0.565 (ซื้อแร่พื้นแผงหลอมเอง) 0.53/0.48/0.42 • q=0.87 (แร่ตัวเองมูลค่าร้าน) 0.91/0.71/0.53
- **q=0 (วัสดุฟรี เช่นบัญชีสำรองที่ขุดเอง): s=0.30 = คุ้มทุนพอดี ไม่มีระยะเผื่อ ทุก shopMul** s=0.25 เผื่อ 5% ของ P
- **ข้อค้นพบใหม่ ปัดจำนวนชิ้น:** แผนใช้ `round` ทำให้ส่วนวัสดุจริง (เครดิต÷P) เกินค่าตั้ง: ตั้ง .25 → จริง 22.5–28.2% (shopMul 1.5) และ 30.1% (shopMul 2.0) • ตั้ง .30 → สูงสุด 34% (เกินเพดานแข็ง = ปั๊มได้กำไร ~4% ที่ q=0) • `floor` → จริงไม่เกินค่าตั้ง (.25 → 17.5–24.5%) **ต้องใช้ `Math.floor` และให้เทสต์ตรวจ "เครดิตจริง ÷ P ≤ 0.25" ทุกสาย×ระดับ ไม่ใช่ค่าตั้ง**
- ช่องอื่น: เทรดตรงไม่มีภาษีแต่ ≤1,000/ฝั่ง วัสดุไม่มี sell ไม่ออกเป็นเหรียญระบบ • หลอมขายร้านไม่ได้ • ซื้อวัสดุร้านแล้วใช้ซื้ออุปกรณ์ = จ่ายเท่า P เป๊ะ
- เงินที่ระบบสร้างเพิ่มต่อการซื้อที่ใช้วัสดุจากผู้เล่น = s×(1 − (1+0.07m)/shopMul)×P: (s .25, m 1.25) shopMul 1.3 → 4.1%P • **1.5 → 6.9%P (~450 เหรียญ)** • 2.0 → 11.4%P • ที่ X=4/วัน ≈ +2k/วัน เทียบรายได้ผู้เล่นจริง ~หมื่นต่อชม. เล็กน้อย

## 4. ราคาร้านวัสดุ 1.3 / 1.5 / 2.0
- ไม่ติดเมื่อไม่มีนักขุด: **ทุกค่าปลอดภัย** เพราะซื้ออุปกรณ์เติมเหรียญตามราคาร้านจ่ายรวม = P เดิม (คืนทุนแย่สุด 1.15 ชม. rod/axe ระดับ 10 เท่าวันนี้ ≤1.2) ทางผู้เล่นถูกกว่า ~4% (95.3–96.3% ของ P ที่ m=1.25) จึงไม่แย่ลงทุกสาย
- ผู้ซื้อประหยัด % ของ P (share .25) ที่ m=1.0 / 1.25: 1.3 → 5.8 / **1.0** • 1.5 → 8.3 / 4.2 • 2.0 → 12.5 / 9.4 • ช่วง m ที่ทั้งสองฝ่ายได้ (1.075–shopMul) กว้าง 17% / 28% / 46% ของราคาร้าน
  - **1.3 ตลาดผู้เล่นตายง่าย:** ที่ราคากลาง ผู้ซื้อประหยัด ≤ ~1% ของ P ไม่คุ้มลงแผง/เสนอซื้อ ทุกคนกดซื้อเหรียญเอง
  - **2.0:** ช่างไม้ซื้อวัสดุร้านแล้วประดิษฐ์ขาดทุนทุกชิ้น (−39…−281) เงินเพิ่ม 11.4%P ปั๊มเริ่มที่ s=0.40
  - **1.5 (แผน) ผ่าน:** ช่างไม้ยังเป็นบวกที่ร้าน (+23…+196) shopMul สูงสุดที่ช่างไม้ยังไม่ขาดทุน 1.68–1.83 [ใช้ราคาเฟอร์นิเจอร์ 2×]
- ข้อเสนอ: คง 1.5 (ถ้าอยากเผื่อช่างไม้เพิ่มไม่ควรเกิน 1.6)
