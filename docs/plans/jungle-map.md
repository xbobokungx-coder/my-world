# แผน "ป่าดงดิบ" — แมพต่อสู้เฟสแรก + ย้ายหอคอย 100 ชั้น (ร่าง 22 พ.ย. 2026 • ฐาน `ad994e1` xpv 8 • ยังไม่ลงโค้ด ตัวเลขทุกตัวรอ `economy-designer` ซิม)

## 1. เป้าหมาย / ไม่ใช่เป้าหมาย
- **เป้า:** ฉากใหม่ "ป่าดงดิบ" ต้นไม้ตัดไม่ได้ มีมอนสเตอร์ประปราย (ไม่ต้องสู้ตลอด) เป็นสนามฝึก "ระบบต่อสู้ขั้นต่ำ" ที่หอคอย 100 ชั้นจะใช้ต่อ • หอคอยย้ายมาอยู่ลานเหนือสุดของป่า (ยังป้าย "เร็วๆ นี้")
- **ไม่ใช่เป้า:** ชั้นดันเจี้ยน ปาร์ตี้ เกราะ หอก/ธนู ปุ่มสกิล บอส PvP • ไม่มีเหรียญจากป่า ไม่ตัดไม้ ไม่ปลูก ไม่ตกปลาในลำธาร (เฟสหลังค่อยดู)
- **ข้อสรุปสถาปัตยกรรม:** ป่า = ฉากแบบเดียวกับทะเลใหญ่ คือ "ชั้นพิเศษ" ในระบบฉากถ้ำ `p.scene = '@cave97'` (`JUNGLE.floor = 97` ต่อจาก OCEAN 98 / SEA 99) ได้ `floorOf` `changeScene` `sceneBroadcast` `blockedFor` การเดิน/กล้อง 64×46 และ AI สัตว์ถ้ำมาฟรี • **ไม่ใช้ `@dg`** (นั่นของห้องดันเจี้ยน) • ไม่สร้างคำนำหน้าฉากใหม่ (ทุกฉากที่ไม่ใช่ถ้ำถูกมองเป็นบ้านใน core.js:22–36, server.js:249 จะต้องแตกสาขาเยอะ)

## 2. ที่ตั้งและการเข้า-ออก
- **ประตูป่าแทนที่ฐานหอคอยเดิม** (shared.js:1978 x9–12 y2–4 บนที่ราบเหนือ) ใช้ช่อง LANDMARK เดิมเป๊ะ → **ผังเมืองไม่เปลี่ยนแม้แต่ช่องเดียว** (golden/test-town-ring/hash x≥45 ไม่ขยับ) ป่ารอบหอเดิม (GROVE) กลายเป็น "ชายป่า" ต่อไปตามเดิม
- เข้า: หันหาประตูกด **Action (Space/ปุ่ม A)** หรือแตะ → เว็บส่ง `act {tx,ty}` ของช่องประตู (แบบท่าเรือ game.js:2404) → server `act()` (server.js:393) เช็ก `S.jgateAt` **ก่อน** ด่านหิว/เหนื่อย (บรรทัด 411–412) → `jungleEnter(p)` • `p.ret` = ช่องหน้าประตู (ออกเกมในป่า เซฟตำแหน่งนี้ผ่าน `townPos` เดิม)
- ออก: เดินถึงช่อง `T.MOUTH` ขอบล่างค่าย (แบบปากถ้ำ server.js:262) **หรือ** หันหาป้าย "🏡 กลับหมู่บ้าน" กด Action • สวิตช์ `JUNGLE.open=false` = ประตูขึ้น toast "เร็วๆ นี้" ผู้ดูแลยังวาป `warpTo('jungle')` ได้
- **เขตปลอดภัย 3 จุด** (มอนสเตอร์ไม่เข้า ไม่ตี ฟื้น HP เร็ว): ค่ายหน้าป่า (จุดเกิด/จุดตื่น) • ศาลเจ้ากลางทาง • ลานหอคอย

## 12. คำถามให้เจ้าของตัดสิน (ค่าแนะนำ ★)
