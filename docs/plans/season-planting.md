## 3. ข้อมูลใหม่ใน shared.js (แหล่งความจริงเดียว)
- `SEASONS` เพิ่ม: `freeLv: 5` (พืช Lv≤5 ปลูกได้ทุกฤดู) • `lockCrops: true` `lockTrees: true` (สวิตช์ถอยด่วน) • `outGrow: 1.5 → 1` (ดู 4.3) • แต่ละฤดูเพิ่ม `trees: [...]` (ชนิดที่ไม่อยู่ในฤดูไหนเลย = งอกทุกฤดู)
- `canPlant(c, t)`: true ถ้า `!lockCrops` / ก่อน epoch / legacy / `lv<=freeLv` / ไม่อยู่ใน `crops` ของฤดูไหน • ไม่งั้น = อยู่ใน `crops` ของฤดูปัจจุบัน
- `canSpawnTree(kind, t)`: แบบเดียวกันกับ `trees`
- `plantWait(c|null, kind|null, t)` → `null` หรือ `{ s: ฤดูถัดไปที่ปลูกได้, ms }` • `seasonWaitText(ms)` → "1 วัน 4 ชม." (fmtLeft ฝั่งเว็บไม่มีหน่วยวัน) ใช้ทั้ง toast เซิร์ฟเวอร์และป้ายเว็บ ข้อความตรงกัน
- `treeQuota(id, cap, t?)` `pickTreeSpawn(..., t?)` `pickTreeTrim(..., t?)`: ไม่ส่ง `t` = พฤติกรรมเดิมเป๊ะ • ส่ง `t`: งอกเฉพาะ `canSpawnTree` และโควตาชนิดในฤดู = `pct / ผลรวม pct ชนิดที่งอกได้ตอนนี้ × cap` (ไม่งั้นแมพเต็มไม่ถึง 132) • ชนิดนอกฤดูใช้โควตาปกติ (ไม่ถูกถอนเพราะหมดฤดู)
- `cropSeason` ไม่แตะ: ราคาเป้าในฤดู ×1.15 / นอกฤดู ×0.9 คงเดิม (พืชฟรี Lv2–5 ยังมีแรงจูงใจราคาตามฤดู) → ตลาดและ golden ไม่ขยับ
  > **อัปเดต 13 พ.ย. 2026:** ตัวเลขนี้ถูกแทนที่แล้วตาม `season-planting-economy.md` → `inMul` 1.08 / `outMul` 1.0 (คำตัดสินของเจ้าของ) และ golden เปลี่ยนเฉพาะรายการต้นไม้

## 4. กติกาที่เสนอ (ค่าแนะนำ + เหตุผล)
1. **พืช Lv≤5 ปลูกได้ทุกฤดู** (แครอท กะหล่ำ ข้าวโพด มะเขือเทศ มะเขือม่วง) ถ้ายกเว้นแค่ Lv1: ฤดูหนาว Lv2–5 ปลูกได้แค่แครอท, ฤดูร้อน Lv2 ได้แค่แครอท, เควส `kinds2` (เก็บ 2 ชนิด) ทำไม่ได้ • คู่มือมือใหม่/เมล็ดฟรีใช้แครอทอยู่แล้ว
2. **ตารางพืชสูงสุดที่ปลูกได้ (freeLv 5) ร้อน/ฝน/หนาว**: Lv6 5/5/6 • Lv7 5/7/6 • Lv8 5/8/6 • Lv9 9/8/6 • Lv10 10/8/6 • Lv11 10/8/11 • Lv12 12/8/11 • Lv13 12/13/11 • Lv14 12/13/14 • Lv15 15/13/14 • Lv16 15/16/14 • Lv17 15/17/14 • Lv18 15/17/18 • Lv19 19/17/18 • Lv20 19/17/20 → ช่องว่างแย่สุด ถอยไป 4 เลเวล (ฝน Lv12, หนาว Lv10) • ผู้เล่น Lv1–5 ไม่ได้รับผลเลย, Lv5 ขึ้นไปมีพืช ≥5 ชนิดทุกฤดู • เวลาโตผูกกำไร ≈0.22 เหรียญ/วิ/ต้น (shared.js:285) รายได้ต่อแปลงต่อชั่วโมงแทบไม่ตก เสียแค่รอบสั้นลง (กดถี่ขึ้น) — economy-designer ยืนยันด้วยซิม
3. **พืชที่ปลูกไปแล้วตอนเปลี่ยนฤดู: โตต่อปกติ ไม่เหี่ยว** → `outGrow: 1` (แก้ตัวเลข ไม่แตะโค้ด farm.js:22) เหตุผล: พืชโตนานสุด 12 นาที ฤดูยาว 3.5 วัน ไม่มีช่องโกง และการเหี่ยว = ทำลายของผู้เล่น (ต้องรับเงินคืน/ข้อความ ซับซ้อนเกินคุ้ม)
4. **ร้านเมล็ดขายทุกชนิดตลอด** (ซื้อตุนไว้รอฤดูได้ เมล็ดไม่เสีย) แต่ติดป้ายฤดูชัด + toast ตอนซื้อเมล็ดนอกฤดู "เก็บไว้ปลูก🌧️ฤดูฝน (อีก …) นะ" • เมล็ดที่มีอยู่ในกระเป๋าไม่ถูกยึด
5. **ใบงาน NPC** (orders.js:13) สุ่มเฉพาะพืชที่ `canPlant` ตอนสุ่ม — กันใบงานขอสตรอว์เบอร์รีในฤดูที่ปลูกไม่ได้
6. **ต้นไม้**: ไม่มีระบบผู้เล่นปลูกต้นไม้ (มีแค่งอกเอง) • เสนอ 9 ชนิดตามฤดู สอดคล้องธรรมชาติไทย ที่เหลือ 11 ชนิดงอกทุกฤดู:
   ร้อน ☀️ `coconut` `gold`(ราชพฤกษ์บานหน้าร้อน) `padauk` • ฝน 🌧️ `bamboo`(หน่อไม้) `willow` `raintree` • หนาว ❄️ `maple` `ginkgo` `sakura` • ทุกฤดู: broad pine teak rose oak dipt takian makha ebony shingchan ancient
   ทุกขั้นขวาน (1–5) มีชนิดทุกฤดูให้ตัดเสมอ • ต้นที่งอกแล้ว **คงอยู่ ตัดได้ตลอด ภาพเดิม** (หิมะทับในฤดูหนาวมีอยู่แล้ว) • ต้นชนิดนอกฤดูที่ถูกตัดจะถูกแทนด้วยชนิดในฤดู แมพยังเต็ม 132 • ต้นที่โหลดจากเซฟ/ผู้ดูแลวาดแผนที่ (`pickTreeKind` server.js:112, map.js:15,30) ไม่ใช้ฤดู (ผูกตำแหน่ง คงที่)
