# แผน "สัตว์ในถ้ำเหมือง" — อุปสรรคเบาๆ ระหว่างขุดแร่ (ร่างให้เจ้าของอ่าน 15 พ.ย. 2026)

สถานะ: **ร่างแผน ยังไม่ลงโค้ด ยังไม่ได้จำลองตัวเลข** • ตัวเลขทุกตัวเป็น "เป้าตั้งต้น" ให้ซิมปรับก่อนใช้จริง
คำสั่งเจ้าของ: เฟสแรกให้มีสัตว์โจมตีผู้เล่นในถ้ำ ชั้นแรกถึงชั้นสุดท้าย จากง่ายไปยาก **ไม่ใช่ต้องสู้ตลอด เป็นอุปสรรคในการขุดแร่**

## คำตอบสั้น: ควรเพิ่มไหม?
**ควร แต่ต้องทำเป็น "อุปสรรค" ไม่ใช่ "ระบบต่อสู้"** เหตุผล
1. ตอนนี้ถ้ำเป็นงานที่ทำซ้ำได้ไม่มีแรงต้าน (เดินไป ฟาด เก็บ) สัตว์ช่วยให้ต้อง "เงยหน้ามองรอบตัว" โดยไม่เพิ่มงานให้ผู้เล่น
2. **ไม่มี HP ในเกมนี้** (มีแต่ความหิว) จึงไม่ควรเอา HP/ตายมาใส่ แค่ผูกกับระบบที่มีอยู่ (ความหิว ความทนอีเต้อ เวลา) ก็พอ
3. สร้าง **เฟรมเวิร์กสิ่งมีชีวิต (creatures)** ครั้งเดียว ใช้ต่อกับ **หอคอย 100 ชั้น** ได้ (`DUNGEON-100.md`) ลดงานซ้ำและเป็นสนามทดสอบความลื่น/เซิร์ฟเวอร์ก่อนทำของใหญ่
4. ข้อควรระวัง: แผนหอคอยเขียนว่า "ถ้ำเหมืองเดิมเป็นที่ทำมาหากินปลอดภัย" แผนนี้ **ขัดกับข้อนั้นบางส่วน** จึงต้องให้เจ้าของยืนยัน (ข้อ 9) และกันไม่ให้รายได้เหมืองลดเกิน ~15%

## 1. หลักการ (ห้ามหลุด)
- **ไม่ตาย ไม่เสียของ ไม่เสียเหรียญ** โดนแล้วเสียแค่ เวลา + ความหิวเล็กน้อย
- **หนีได้เสมอ**: สัตว์ไม่วิ่งเร็วกว่าผู้เล่น (ยกเว้นพุ่งสั้นๆ ที่เห็นท่าก่อน) และมี **ท่าง้าง 0.5 วิ + วงเตือน** ก่อนโจมตีทุกครั้ง
- **ไม่ต้องสู้ก็ขุดได้**: มีทางเลี่ยง (เดินหนี ใช้ตะเกียงไล่) และสู้กลับได้ด้วย **อีเต้อที่ถืออยู่** (ไม่ต้องมีอาวุธ/อาชีพใหม่)
- **ชั้น 1–2 ต้องเป็นมิตรกับมือใหม่ Lv1–2**: หนูเล็กอ่อน แทบไม่เจ็บ สอนว่า "มีของพวกนี้ในถ้ำ"
- **ปุ่ม Action ใช้ได้เสมอ**: Action = ฟาดอีเต้อใส่สัตว์ที่ยืนหันหน้าอยู่ (เหมือนฟาดแร่) ปุ่มมือถือ A ทำได้เหมือนกัน ไม่ต้องมีปุ่มใหม่
- **เซิร์ฟเวอร์ตัดสินทั้งหมด** (ตำแหน่ง ดาเมจ เวลาเกิด) เว็บแค่วาดและส่งทิศ/ฟาด
- **ปิดได้ด้วยสวิตช์เดียว** `MINE.creatures.on` (เหมือน `ENERGY.on`) ไว้ถอยเมื่อมีปัญหา

## 2. สัตว์ 5 ชนิด เรียงจากง่ายไปยาก (ครอบ 10 ชั้น)
| ชนิด | ชั้น | พฤติกรรม | ท่าโดน |
|---|---|---|---|
| 🐀 หนูถ้ำ | 1–3 | เดินช้าสุ่ม เห็นผู้เล่นใกล้ๆ ค่อยวิ่งมากัด | กัดเบา หิวลดนิดเดียว ไม่มีสตัน |
| 🦇 ค้างคาว | 2–5 | บินส่ายเร็ว เข้าแล้วถอย (เข้าทีละครั้ง) | ชนแล้วสะดุ้ง สตันสั้น |
| 🕷️ แมงมุมถ้ำ | 4–7 | เกาะเดินช้า พ่นใย (วงเตือนบนพื้น) | ติดใย เดินช้าลง 3 วิ |
| 🐍 งูหินปูน | 6–8 | นอนซุ่มข้างแร่ พุ่งใส่เมื่อเข้าใกล้ (ง้าง 0.5 วิ) | พุ่งแรง หิวลดเยอะกว่า ผลักถอย |
| 🗿 ยักษ์หินกรวด | 8–10 | ตัวใหญ่ช้า เดินตามไม่ลดละ ทุบพื้น (วงเตือนใหญ่) | หนักสุด ผลักไกล สตันนาน |
- **ชั้นสุดท้าย (ชั้น 10)** เฟสแรกใช้ยักษ์หินกรวดหลายตัว ไม่ทำบอส (เก็บบอสไว้เฟส 2 ร่วมกับหอคอย)
- 4 ทิศเท่านั้น (เดินใต้/เหนือ/ตะวันออก พลิกเป็นตะวันตก) ตามกฎงานศิลป์ของเกม

## 3. ผลเมื่อโดนโจมตี (ไม่มี HP)
1. **สะดุ้ง/ผลัก**: ผลักถอย 1–2 ช่อง + สตัน 0.3–1.0 วิ (ตามชนิด) ช่วงนั้นฟาดแร่ไม่ได้
2. **ความหิวลด** `H(f) = 1 + f` แต้ม (ชั้น 1 = 2, ชั้น 10 = 11) จากหิวเต็ม 100 • ใช้ระบบความหิวเดิม ถึง 0 = ใช้เครื่องมือไม่ได้ (กินอาหารแล้วทำต่อ) **ผลพลอยได้: อาหารที่เชฟทำมีที่ใช้จริงขึ้น**
3. **ช่วงอมตะ 1.5 วิ** หลังโดน กันโดนรัวจนหมดแรง
4. **สลบ (กันตายไม่ได้ ก็ไม่ตาย)**: ถ้าโดน 4 ครั้งภายใน 30 วินาที = "ล้มพักสั้น" 3 วิ แล้วลุก พร้อมวาร์ปกลับจุดลงบันไดของชั้นนั้น (ไม่เสียของ ไม่เสียเหรียญ) เป็นกลไกถอยที่ไม่ลงโทษหนัก
5. **อีเต้อสึกเพิ่มเมื่อใช้ฟาดสัตว์** (เท่าฟาดแร่ 1 ก้อนเล็ก) กันไม่ให้ "ไล่ฟาดสัตว์" เป็นทางเลือกที่ฟรีกว่าขุด

## 4. สู้กลับและทางเลี่ยง
- **ฟาดด้วยอีเต้อ**: ดาเมจต่อครั้งอิงระดับอีเต้อ (ใช้ `W(t)` เดียวกับขุด) HP สัตว์ = ตีให้ตายใน **2–6 ครั้ง** ไล่ขึ้นตามชั้น (ปรับตามระดับอีเต้อที่แนะนำของชั้นนั้น) อีเต้อต่ำกว่าชั้น = สู้ยากขึ้นตามสัดส่วนเดิม (`slow.dmg`)
- ตายแล้ว **เกิดใหม่** (ปรับ 20 พ.ย. 2026 จากราว 2.4 นาที เหลือ `DAY_MS/10` ราว 1.2 นาที) ที่จุดไกลผู้เล่น
- **ไม่ให้ XP ไม่ให้เหรียญ** เฟสแรก (เศรษฐกิจเป็นกลาง) ถ้าอยากให้รางวัลเล็กๆ ไว้เฟส 2 เป็นของสะสม/ชิ้นส่วนมูลค่าต่ำและมีเพดานต่อวัน
- **เขตปลอดภัย** รัศมี 5 ช่องรอบบันไดและทางลง/ขึ้น สัตว์ไม่เข้า (ยืนพักกินข้าวได้)
- **ตะเกียงไล่สัตว์ 🪔** (เฟส 1.5 ถ้าเจ้าของเห็นด้วย): ของสิ้นเปลือง 5 นาที สัตว์ชนิดอ่อนกว่าชั้นนั้นไม่เข้าใกล้ ราวไม่เกิน ~3% ของรายได้/ชม. ที่ชั้นนั้น เป็นก๊อกน้ำเหรียญเล็กๆ ที่ผู้เล่นเลือกเอง

## 5. ตัวเลขตั้งต้น (ให้ `economy-designer` ซิมปรับ)
| ตัวแปร | ชั้น 1 → ชั้น 10 |
|---|---|
| จำนวนสัตว์ต่อชั้น `cap(f)` | ~~2 + f = 3 → 12~~ ปรับ 20 พ.ย. 2026 เป็น round(3 + 1.5f) = 5 → 18 (ชั้นกว้าง ~50–63 ก้อนแร่ พื้นที่เดินได้ ~630 ช่อง) |
| รัศมีรับรู้ผู้เล่น | 3 + 0.3f ช่อง (3.3 → 6) |
| ความเร็วเทียบผู้เล่น | 0.5 → 0.95 (ไม่เกิน 1.0 ยกเว้นพุ่งสั้น) |
| ความหิวที่เสียต่อโดน | 2 → 11 |
| สตัน | 0 → 1.0 วิ |
| HP สัตว์ (จำนวนฟาด) | 2 → 6 |
- **เป้าสมดุลหลัก**: เวลาขุดจริงที่เสียไปจากสัตว์ต่อชั่วโมง ≤ **15%** สำหรับผู้เล่นที่มีอีเต้อพอดีชั้น (เกินกว่านั้นลดจำนวน/รัศมี) และรายได้/ชม. ของถ้ำ (ตั๋วลงชั้น `MINE.fee` ≈ 10% ของรายได้) **ไม่ลดเกิน ~15%**
- ซิมใหม่ `tools/cavesim.js` (ต่อยอดจาก `tools/dungeonsim.js` ถ้าใช้ร่วมได้) วัด: ครั้งที่โดน/ชม. หิวที่เสีย เวลาสตัน เวลาที่เสียไป ที่ชั้น 1/5/10 กับอีเต้อตรงชั้น/ต่ำกว่า 2 ระดับ

## 6. เทคนิค (ย่อ)
- ไฟล์ใหม่ `server/systems/creatures.js` (mixin ตามแบบ `mining.js`) เก็บสัตว์ใน `this.floors.get(f).creatures` **ในหน่วยความจำเท่านั้น ไม่ลงเซฟ** → ไม่ต้องย้ายเซฟ ไม่มีความเสี่ยงต่อไฟล์เซฟ
- อัปเดตเฉพาะชั้นที่มีคนอยู่ ที่ 4 ครั้ง/วินาที AI เรียบง่าย (สุ่มเดิน → เห็น → ง้าง → โจมตี → พัก) เพดานรวมทั้งเซิร์ฟเวอร์ ~200 ตัว ภาระ CPU/RAM น้อยมาก (VPS 961 MB)
- ส่งข้อมูลแบบเดียวกับแร่ (`oresPub`) เป็น `creaturesPub` + เดลต้าตำแหน่งเฉพาะคนที่อยู่ชั้นนั้น
- ค่าตัวเลขอยู่ใน `MINE.creatures` (shared) ไม่ฝังกระจาย • ข้อความเป็นภาษาไทยสบายๆ
- เว็บ: วาดสัตว์ในชั้นเรียง y กับผู้เล่น วงเตือนบนพื้น แถบสั้นเหนือสัตว์ที่ถูกฟาด เอฟเฟกต์สะดุ้ง/สั่นจอเบาๆ (ปิดได้ตามค่าลดการเคลื่อนไหวที่เกมมี)
- เทสต์ใหม่ `tools/test-creatures.js`: ไม่ตาย/ไม่เสียของ • หนีทัน • ปิดสวิตช์แล้วไม่มีสัตว์ • สลบแล้ววาร์ปถูกที่ • ฟาดแล้วอีเต้อสึก • สัตว์ไม่เข้าเขตปลอดภัย • ชั้นว่างคนไม่ทำงาน (ไม่กิน CPU)
- ปุ่ม Action: เพิ่มใน `contextAct()` ของ `public/game.js` ตามกฎโปรเจกต์ (ฟาดสัตว์ที่หันหน้าหา)

## 9. คำถามให้เจ้าของตัดสิน (พร้อมค่าที่แนะนำ)
1. **ผลเมื่อโดน** — แนะนำ: ผลัก + ความหิวลด + สตัน (ไม่ตาย ไม่เสียของ) • ทางเลือก: ทำอีเต้อสึกหนักขึ้น หรือทิ้งแร่ที่ถือไว้ (ไม่แนะนำ เจ็บเกินสำหรับอุปสรรคเบาๆ)
2. **สู้กลับได้ด้วยอีเต้อไหม** — แนะนำ: ได้ (ไม่ต้องมีอาวุธ) • ทางเลือก: สู้ไม่ได้ ทำได้แค่หนี/ใช้ตะเกียง
3. **ฆ่าสัตว์ได้ของไหม** — แนะนำ: เฟสแรกไม่ให้อะไรเลย เศรษฐกิจเป็นกลาง
4. **ตะเกียงไล่สัตว์** — แนะนำ: ทำเป็นเฟส 1.5 ถ้าผู้เล่นบ่นว่ารำคาญ
5. **ยอมให้ขัดกับแผนหอคอยข้อ "เหมืองปลอดภัย" ไหม** — แนะนำ: ยอม เพราะอุปสรรคนี้เบาและปิดได้ แล้วแก้แผนหอคอยให้ใช้เฟรมเวิร์กสัตว์ชุดเดียวกัน
6. **ถ้าเปิดแล้วผู้เล่นไม่ชอบ** — สวิตช์ `MINE.creatures.on` ปิดได้ทันทีโดยไม่กระทบเซฟ
