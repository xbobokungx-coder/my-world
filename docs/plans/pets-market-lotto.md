## 3. โปรโตคอลข้อความ (ทุกกติกาตัดสินที่เซิร์ฟเวอร์)
- `{t:'lotto', a:'claim'}` เว็บ→เซิร์ฟเวอร์: ต้อง `nearLucky(p)` และมี `rec.lottoPend` • ตอบด้วย `{t:'lotto', l}` เดิม แต่ `lottoPub` เพิ่ม `pend:[[round,k,amt],…]` **เฉพาะตอนมีของรอรับ** (golden ไม่เปลี่ยน แบบเดียวกับ `left`)
- `act` ที่ช่อง LUCKY (server.js:452): ถ้ามีรางวัลรอรับ ให้เรียก `lottoClaim` ก่อน แล้วค่อยส่ง `town` → แค่กด Action ที่ตู้ก็ได้เงิน
- `{t:'stall', a:'bid', item, n, price, fresh}` (fresh 0=รับเฉพาะของสด 1=รับถึงค้าง 2=รับทุกสภาพ) • `{a:'fill', id, n}` ขายให้คำเสนอซื้อ • `{a:'bcancel', id}` • ตรวจ: PIN, `isTradable`, ราคาอยู่ในกรอบ `STALL.min/max × tradeValue`, `n ≤ maxN`, โควตา `bidSlots`, จำนวนรวมทั้งตลาด `≤ maxAll`, ห้ามขายให้คำเสนอของตัวเอง
- `{t:'stall', l, b}` เซิร์ฟเวอร์→ทุกคน: `l[i]` เพิ่ม `fr:[สด,ค้าง,เก่า]` • `b[i] = {id,item,n,price,name,mine,fresh}` (ไม่ส่ง ip/coin)
- `act` ที่ช่อง FLEA → `{t:'town', w:'flea'}` → เว็บเปิดแท็บตลาดนัด (ปุ่ม Action ใช้ได้ผ่าน T.SHOP เหมือน ATM/Lotto)
- `{t:'petcare', a:'pat'}` ลูบหัว/เล่นด้วย: ต้องพาสัตว์ออกมา ไม่ป่วย และพ้นคูลดาวน์ (โหมด play ต้องอยู่ห่าง `pax/pay` ไม่เกิน `PETLV.patRange` ช่อง) • เว็บส่งเมื่อกด Action โดยหันหน้าหาสัตว์ของตัวเอง (`contextAct`) หรือกดปุ่มในเมนู 🐾
- `pubFull`/`p+`/`pet` เพิ่ม `plv` **เฉพาะเมื่อระดับ > 1** (ไม่ทำให้ golden เปลี่ยน) • `pst` ส่ง `b`/ระดับของตัวเองไปด้วยอยู่แล้วเพราะส่ง `rec.pst` ทั้งก้อน

## 4. สถานะ / รูปแบบเซฟ (xpv คงที่ 7: ทุกอย่างเป็นช่องเพิ่ม อ่านเซฟเก่าได้ด้วยค่าตั้งต้น)
- `rec.lottoPend = [[round, k, amt], …]` (ไม่มี = ว่าง เก็บไม่เกิน `LOTTO.pendMax` รายการ ถ้าเกินให้รวมรายการเก่าสุดเป็นก้อนเดียว) • `rec.lottoWins` เดิม (จ่ายไปแล้ว ใช้แค่แจ้ง) ยังอ่าน/แจ้งตามเดิม แต่ไม่สร้างเพิ่ม • กองกลางยังหักตอนออกผลเหมือนเดิม เงินรอรับจึงเป็นหนี้ค้างของระบบ ไม่ใช่เงินในกองกลาง • `LOTTO.claimMs: 0` = ไม่หมดอายุ (ถ้าตั้ง > 0 ของที่หมดอายุจะคืนกองกลาง)
- เซฟเมือง `d.bids = [{id, buyer, name, item, n, price, coin, fresh, ip, t}]` โดย `coin === n × price` เสมอ • `id` ใช้ตัวนับเดียวกับ `stallNext` (คำนวณจากค่าสูงสุดของทั้งสองรายการ) • บันทึกเฉพาะตอนไม่ว่าง (golden ไม่เปลี่ยน) • ตอนโหลดทิ้งรายการเสีย **แต่คืนเงิน `coin` ให้เจ้าของก่อนทิ้ง**
- `rec.pst[id]` เพิ่ม `b` (bond สะสม), `bd`/`bn` (วันที่/bond ที่ได้วันนี้), `gn` (ของขวัญวันนี้), `pat` (เวลาลูบหัวล่าสุด) ไม่เก็บค่าระดับ ใช้ `S.petLevel(b)` คำนวณ (ไม่มีวันไม่ตรงกัน) • ไม่มี `b` = 0 = ระดับ 1 (สัตว์เดิมเริ่มระดับ 1 ไม่นับย้อนหลัง) • `petSt` ทำให้ค่าเป็นปกติ (ตัวเลขจำกัด ≥ 0)
- สำรองข้อมูล: deploy แต่ละงานต้องสำรองด้วย `tools/deploy.sh` ตาม `docs/OPS.md` ก่อนรีสตาร์ต • ถ้าจะย้อนโค้ดกลับ ต้องรัน `tools/pml-rollback.js` **ก่อน** (ย้าย `lottoPend` เข้า coin + `lottoWins` และคืนเงิน `bids` ทุกรายการ) ไม่งั้นโค้ดเก่าจะไม่เห็นเงินเหล่านี้และเงินหาย

## 5. ตัวเลข (อยู่ใน shared ทั้งหมด economy-designer ยืนยันด้วย levelsim/econsim ก่อน P2)
- `PETLV = { need:[0,300,900,2000,4000], scale:[1,1.15,1.3,1.45,1.6], seaMax:1.2, statMul:[1,1.1,1.2,1.3,1.5], out:1, activeMs:180000, feed:6, pat:8, patCdMs:600000, patRange:3, dayCap:360, gift:{ perDay:[0,0,1,2,3], chance:0.03, table:[…ของซื้อจากร้าน มูลค่าต่ำ ขายคืนไม่ได้กำไร เช่น petfood/feed/bait] } }`
- ได้ bond ทุกครั้งที่ `petTick15` ทำงาน (+`out` × mood) **เฉพาะตอนเจ้าของมีกิจกรรมภายใน `activeMs`** (`p.activeAt` กันการทิ้งตัวละครไว้เฉยๆ) + ให้อาหาร + ลูบหัว ทั้งหมดรวมกันไม่เกิน `dayCap` ต่อตัวต่อวัน → ระดับ 2 ใช้ 1 วัน, ระดับ 3 ราว 3 วัน, ระดับ 4 ราว 6 วัน, ระดับ 5 ราว 12 วัน • ให้อาหารต้องซื้อ petfood จึงเป็นทางให้เหรียญออกจากระบบ
- เพดานโบนัสที่ระดับ 5: คาปิบาร่า 🏃8→12% 📚6→9% 🍀4→6% • แมว 🍀6→9% (รายได้ผลผลิตเพิ่มได้สูงสุดราว +3%) • ของขวัญมูลค่ารวมไม่เกิน ~30 เหรียญต่อวัน
- ตลาดนัด: `STALL += { bidSlots:4, maxAll:300, bidDays:3 }` ภาษี 7% เข้ากองกลางเหมือนเดิม คิดจากเงินที่คนขายได้ • ไม่มีค่าลงประกาศ
- กันโกง: (1) โอนเงินผ่านบัญชีสำรองถูกจำกัดด้วยกรอบราคา 0.5–2× ของราคามาตรฐาน (ไม่ผูกกับราคาตลาดที่ขึ้นลง) + ภาษี 7% + PIN (2) ขายให้คำเสนอของตัวเองไม่ได้ + บล็อก IP เดียวกันถ้าเจ้าของเกมเลือก (Q3) (3) เงินถูกกันไว้ตอนลงประกาศ จึงจ่ายซ้ำไม่ได้ และการจับคู่ทำครั้งเดียวในเธรดเดียว (4) ความสด: ของบนแผงยังเสื่อมตามเวลาจริง (แผงไม่ใช่ตู้เย็น) ส่งต่อด้วย `lots` เดิม ของเก่าออกก่อน • ตอน fill ถ้าของที่จะออกมีชิ้นไหนเก่ากว่า `bid.fresh` (ไม่นับตู้เย็น) ให้ปฏิเสธพร้อมข้อความ "ขายของเก่าก่อน"

- ขยายตัวสัตว์ด้วยค่าไม่เต็มจำนวนทำให้พิกเซลหนาไม่เท่ากัน → pixel-artist เลือกค่า scale ใหม่ได้ (ค่าอยู่ใน shared) • บนเรือ/ไอโซจำกัดที่ `seaMax`

## 8. คำถามค้าง (ค่าที่ใช้ถ้าไม่ตอบ)
Q1 ตลาดนัดคงกรอบราคา 0.5–2× ราคามาตรฐานไหม (ค่าตั้งต้น: คง เพราะราคาอิสระ = โอนเงินผ่านบัญชีสำรองได้ไม่จำกัด) • Q2 ต้องยืนใกล้ป้ายตอนซื้อ/ขาย/เสนอไหม และจะเอาแท็บ 🛒 ออกจากกระดานข่าวไหม (ค่าตั้งต้น: ต้องใกล้ป้าย ยกเว้นยกเลิกประกาศ • เอาแท็บออก) • Q3 บล็อกซื้อขายระหว่าง IP เดียวกันไหม (คนในบ้านเดียวกันจะโดนด้วย ค่าตั้งต้น: ไม่บล็อก แต่บันทึก ip ไว้ตรวจ) • Q4 สัตว์ตายแล้ว bond หายหมดเหมือนเดิมไหม (ค่าตั้งต้น: หาย) • Q5 ระดับ 5 ขยาย 1.6× ใหญ่ไปไหม • Q6 หวยรอรับไม่มีวันหมดอายุตามตั๋ว (`claimMs:0`) ใช่ไหม
