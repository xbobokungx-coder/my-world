# แผน: สัตว์เลี้ยงขึ้นเรือ + เรือลำใหญ่ + ท่าขับเรือ (pet-on-boat)
สถานะ: ออกแบบ (12 พ.ย. 2026) ยังไม่แก้โค้ด • ฐาน: main ใน My-World_Studio-fish

## 1. เป้าหมาย / ไม่ทำ
- ออกทะเลใหญ่ (ฉาก `@cave98` = `OCEAN.floor`) สัตว์ที่พาออกมานั่งบนเรือตลอดเวลา ไม่ลงไปเดินบนน้ำ กลับฝั่งแล้วเดินตามตามเดิม
- เรือใหญ่ขึ้นจนคน + สัตว์ (เผื่อ 3 ที่นั่ง) อยู่บนเรือได้พร้อมกัน • ผู้เล่นบนเรือ "ไม่มีท่าเดิน" ยืนนิ่งที่พวงมาลัย หันตามทิศเรือ ตัวเรือเป็นฝ่ายแล่น
- ไม่ทำ: พาสัตว์ออกหลายตัวพร้อมกัน (ต้องเปลี่ยนเซฟ `rec.pet` เป็นรายการ แยกเป็นงานใหม่) • ไม่แตะแพเก่า (ชั้น 99 เหลือแค่ผู้ดูแลวาป) • ไม่มีกลไกตกเรือ (ในโค้ดยังไม่มี)

## 2. ตอนนี้ทำงานยังไง (สำรวจแล้ว)
- เซิร์ฟเวอร์เก็บแค่ "ตัวไหน/โหมดไหน": `rec.pet` `rec.pmode` `rec.pst` `rec.pnames` (`server/systems/pets.js` setPet/petTick15) ส่งต่อใน `pubFull` (`core.js`) ฟิลด์ `pet pm pax pay psick pname` • **ตำแหน่งสัตว์จำลองฝั่งเว็บล้วน** (`game.js` ลูปอัปเดต `p.cp` ~บรรทัด 4343 + `drawCompanion`) เดินได้ทุกฉาก (เมือง ถ้ำ บ้าน ทะเล) ใช้ `blk()` กันชน
- ทะเลใหญ่ใช้ระบบฉากถ้ำ แมพแยก `makeOceanMap()` ช่องแล่นได้ = `T.CAVE` (วาดเป็นน้ำ) → `blk()` ถือว่าเดินได้ = **ต้นเหตุสัตว์เดินบนน้ำ** • เข้า: `seaGo` (fishing.js, ปุ่ม Action ที่ท่า `T.SHOP` 'sea' → ถาม → `{t:'sea'}`) • ออก: แล่นถึง `T.MOUTH` / เรือเช่าหมดเวลา (`tick`) → `seaLeave` → `leaveCave` • หลุด/ออกเกม: `leave()` เซฟ `townPos` = จุดกลับเกาะ เข้าใหม่อยู่เมือง
- เรือ = รูปวาดด้วยโค้ด `drawBoat` (game.js ~2736) ยาว ~76 px กว้าง ~25 px ตัวละครยืนกลาง • ฮิตบ็อกซ์ = จุดตัวละคร `blockedAt` รัศมี 8 px (shared.js ~1666) เรือจึงทับเกาะได้อยู่แล้ว • ตัวละครใช้ `PixelChar.draw` มีท่าเดินตาม `p.moving` และมีท่านั่ง `sit` 4 ทิศ (ตะวันตกพลิกจากตะวันออก)
- โบนัสสัตว์ตอนนี้ทำงานในทะเลอยู่แล้ว: หิวลด (petTick15) XP (+core.addXp) โชคได้ปลาเพิ่ม (fishing.js petLuck) ความเร็วคูณความเร็วเรือ (`petSpeedMul`)

## 3. ออกแบบพฤติกรรม
- ขึ้นเรือ: อัตโนมัติพร้อมเจ้าของตอน `seaGo` (ผ่านปุ่ม Action ที่ท่าเรือเดิม ไม่เพิ่มการโต้ตอบใหม่) • ไม่อยากพาไป = เก็บเข้าบ้านในเมนู 🐾 ก่อน • พาออก/สลับ/เก็บ/ให้อาหาร/รักษา ในทะเลได้ตามเดิม (`pet` `petcare` อยู่ใน HOUSE_MSG) ตัวใหม่โผล่ที่ที่นั่งทันที
- ตำแหน่ง: ที่นั่ง 0 = หัวเรือ (หมา แมว ลิง คาปิบาร่า) • นก = เกาะยอดเสากระโดง • ที่นั่ง 1–2 สำรองไว้งานหลายตัว • ท่า: `moving=false` (แมวนั่งอยู่แล้ว ตัวอื่นท่ายืนนิ่ง) ขยับขึ้นลงตามคลื่นเท่าตัวเรือ • หัน: เรือไปซ้าย/ขวา `dx` ตามเรือ เรือขึ้น/ลงคง `dx` เดิม (สัตว์มีแค่ภาพข้าง)
- ผู้เล่นบนเรือ: วาดด้วย `moving:false` เสมอ (ไม่มีขาก้าว) ยืนที่ช่องพวงมาลัย หันตามทิศเรือ 4 ทิศ ท่าตกปลา (PixelAction) ยังเล่นได้ • **ไม่ใช้ `p.sit` ฝั่งเซิร์ฟเวอร์** (sit = ความหิวไม่ลด จะกลายเป็นช่องโกง) เป็นแค่ท่าวาด
- ชนเกาะ/ขอบ: สัตว์ล็อกกับเรือ ไม่มี AI เดินเอง จึงไม่มีทางลงน้ำ • `tp` จากเซิร์ฟเวอร์ = ย้ายทั้งลำ
- กลับเข้าฝั่ง/หมดเวลาเช่า/หลุดเน็ต/เปลี่ยนห้อง: ทุกทางจบที่ฉากเมือง → ล้าง `me.cp` ใน `applyScene` (ตอนนี้ `me` ใช้ object เดิมข้ามฉาก `cp` ค้างพิกัดทะเล = บั๊กแฝง) สัตว์โผล่ข้างเจ้าของแล้วเดินตามปกติ
- โหมดปล่อยเล่น (`pm:'play'`) บนเรือ: ไม่สน ยังนั่งบนเรือ • ถ้าเลือกโหมดนี้กลางทะเล `pax/pay` จะเป็นพิกัดทะเล → `seaLeave` ตั้ง `pax/pay` = จุดกลับเกาะก่อนเปลี่ยนฉาก
- เช่าเรือ vs เรือตัวเอง: เหมือนกันทุกอย่าง (ทุกคนในทะเลวาดเรือลำเดียวกันอยู่แล้ว) • คนอื่นเห็น: ทุกเครื่องคำนวณที่นั่งจาก `pet` + ทิศ + ตำแหน่งที่ได้อยู่แล้ว **ไม่มีข้อความใหม่**

## 4. เรือใหญ่ + ฮิตบ็อกซ์
- ขนาดใหม่ (ข้อมูลอยู่ shared `BOAT.hull` พิกัดเรือ u = ตามหัวเรือ v = ด้านข้าง หน่วย px เกม): ยาว ~96 px (3 ช่อง) กว้าง ~44 px • `helm` (ผู้เล่น) = จุดศูนย์กลางเรือ = `p.x,p.y` เดิม (ระยะโยนเบ็ดไม่เปลี่ยน) • `seats` [หัวเรือ, ท้ายซ้าย, ท้ายขวา] • `mast` ยอดเสาให้นก
- ฮิตบ็อกซ์: สี่เหลี่ยมจัตุรัสไม่ขึ้นกับทิศ รัศมี `BOAT.hull.r` ≈ 22 px (เดิม 8) — ไม่ใช้กล่องหมุนตามทิศ เพราะหันเรือข้างเกาะแล้วติดได้ • หัว/ท้ายเรือยื่นเลยฮิตบ็อกซ์ ~26 px ยอมให้ทับขอบเกาะเล็กน้อย (ตอนนี้ก็ทับอยู่) • ต้อง r < 32 เพื่อให้แล่นเข้าช่อง MOUTH (x=1) ได้โดยไม่ต้องย้ายทางออก
- `blockedAt(m, x, y, r = 8)` เพิ่มพารามิเตอร์ (ค่าเดิม = พฤติกรรมเดิมทุกที่) • เซิร์ฟเวอร์ `core.blockedFor` ฉาก OCEAN ส่ง `BOAT.hull.r` • เว็บ `blk()` ฉาก OCEAN ส่งค่าเดียวกัน (ไม่งั้นเว็บเดินได้แต่เซิร์ฟเวอร์ `tp` ดึงกลับ = กระตุก) • เรือไม่ชนเรือคนอื่น (เหมือนเดิม)
- ลำดับวาด: เรือ + คน + สัตว์ของเจ้าของเดียวกันวาดเป็น 1 รายการ (คีย์ `p.y+12`): ท้องเรือ/ดาดฟ้า → สัตว์ที่อยู่ "หลัง" คนบนจอ → คน → สัตว์ "หน้า" → ชั้นหน้าเรือ (กราบ/พวงมาลัย) แบบ PixelVehicle back/front • สไปรต์: pixel-artist วาดเรือ 3 ทิศ ใต้/เหนือ/ตะวันออก ตะวันตกพลิก (ชั้น back + front) พวงมาลัยในชั้น front • ตัวละคร: ใช้ `PixelChar` ท่ายืนนิ่งที่มีอยู่ ไม่ต้องวาดเพิ่ม

## 5. รูปแบบเซฟ / โปรโตคอล
- ไม่เปลี่ยนเซฟ ไม่เพิ่มฟิลด์ ไม่ต้อง bump เวอร์ชัน • ไม่เพิ่มชนิดข้อความ • กติกา "สัตว์อยู่บนเรือ" มาจากสถานะที่เซิร์ฟเวอร์ตัดสินแล้ว (ฉาก + `pet`) ส่วนพิกัดเป็นการวาดล้วนแบบที่สัตว์เป็นอยู่ทุกฉาก

## 6. ขั้นงาน (ทีละขั้น ไฟล์ไม่ทับกันในขั้นเดียว)
1. **server-dev** `public/shared.js`: `BOAT.hull` + ฟังก์ชันบริสุทธิ์ `boatSeat(dir, slot)` / `boatHelm(dir)` คืนออฟเซ็ต px • `blockedAt` รับ r • `server/systems/core.js` blockedFor ใช้ r ในทะเลใหญ่ • `fishing.js` seaLeave ตั้ง pax/pay → เทสต์ใน `tools/test-sea.js`: จุดเกิดไม่ชนด้วย r ใหม่, จาก spawn แล่นตรงไปถึง MOUTH ได้, ที่นั่งหัวเรืออยู่ทางหัวเรือทั้ง 4 ทิศและอยู่ในตัวเรือ, `blockedAt` ไม่ส่ง r ผลเท่าเดิม, seaLeave โหมด play แล้ว pax อยู่บนบกเมือง
2. **client-dev** `public/game.js`: ย้ายส่วนคำนวณท่าเรือออกจาก `drawBoat` เป็น `boatPose(p, now)` (ย้ายไม่เขียนใหม่) • วาดเรือขยายตาม `BOAT.hull` ด้วยโค้ดชั่วคราว • `blk()` ใช้ r ในทะเล • ลูป `p.cp`: ในทะเลใหญ่ล็อกที่นั่ง ข้าม AI • `drawCaveWorld` วาดเป็นกลุ่มต่อเจ้าของ • คนในทะเลวาด `moving:false` • `applyScene` ล้าง `me.cp` → ทดสอบมือบนเครื่อง dev: สัตว์ทั้ง 5 ชนิด × 4 ทิศ, ชนเกาะ, เข้าท่า, `OCEAN.anytime`/วาปผู้ดูแล `ocean`, เปิด 2 เบราว์เซอร์ดูอีกฝั่ง
3. **pixel-artist** `public/pixelboat.js` (ใหม่) + แท็ก script ใน `public/index.html`: `PixelBoat.draw(ctx, p, now, layer)` 3 ทิศ+พลิก ตามขนาด/จุดยึดใน `BOAT.hull` ตาม STYLE_GUIDE • ดูชีตได้คล้าย `__mw.actionSheet()`
4. **client-dev** `drawBoat` เรียก PixelBoat ถ้าโหลดแล้ว ไม่งั้นใช้รูปวาดโค้ด (แบบ BikeAI)
5. **qa-tester** `node --check` + `tools/test-*.js` ครบ • **ux-reviewer** มือถือ/PC: ป้ายชื่อสัตว์ทับทุ่น/ป้ายโซน, จอยสติ๊กบังเรือไหม
6. **doc-writer** `GAME-DESIGN.md` `HOW-TO-PLAY.md` `README.md` (บรรทัดสัตว์เลี้ยง/ทะเล)

## 7. ความเสี่ยง / ถอยกลับ
- ฮิตบ็อกซ์ใหญ่ขึ้น: ร่องระหว่างเกาะแคบลง (เกาะห่างกัน ≥4 ช่อง ยังผ่านได้) • ตอน deploy ทุกคนหลุดแล้วเข้าใหม่ที่เมือง จึงไม่มีใครติดอยู่ในจุดที่ r ใหม่ชน
- หันเรือขึ้นเหนือ สัตว์หัวเรือถูกตัวคนบังบางส่วน → ปรับ `seats` ในข้อมูลได้โดยไม่แตะโค้ด
- ถอยกลับ: revert คอมมิตขั้น 2–4 ได้ทันที (ไม่มีเซฟเปลี่ยน) • ขั้น 1 revert ได้ถ้าไม่มีขั้นอื่นพึ่ง

## 8. ให้เจ้าของตัดสิน (คำแนะนำ)
1. สัตว์บนเรือยังหิว/ให้ XP/โชค/เร่งเรือไหม → **คงไว้ทั้งหมด** (เป็นแบบนี้อยู่แล้ว เปลี่ยน = กระทบเศรษฐกิจ ต้องผ่าน economy-designer)
2. พาไปเฉพาะเรือตัวเองไหม → **ทั้งเรือเช่าและเรือตัวเอง**
3. ขึ้นเรืออัตโนมัติไหม → **อัตโนมัติ** ไม่อยากพาไปให้เก็บในเมนู 🐾
4. นกเกาะเสาหรือหัวเรือ → **เสากระโดง**
5. คนยืนหรือนั่งขับ → **ยืนนิ่ง** (ท่าโยนเบ็ดเป็นท่ายืน นั่งแล้วสลับท่าไปมาดูแปลก)
6. พาออกหลายตัวพร้อมกัน → **แยกเป็นงานถัดไป** (เปลี่ยนเซฟ `rec.pet` → รายการ + migration + สำรองข้อมูล) เรือนี้เผื่อ 3 ที่นั่งไว้แล้ว
7. ท่านั่งเฉพาะของหมา/ลิง/คาปิบาร่า → **ทำทีหลัง** (pixel-artist ภาพข้างเท่านั้น พลิกซ้าย)

## 9. ปรับภายหลัง (12 พ.ย. 2026 เจ้าของสั่ง)
- สัตว์ปีก (นก) ไม่ต้องนั่งเกาะเสา: บินตามเรือเองด้วย AI ตามเจ้าของเดียวกับบนบก (บินข้ามน้ำได้ `free` = true) โหมดปล่อยเล่นกลางทะเลบินวนรอบเรือ (ใช้ตำแหน่งเรือเป็นศูนย์กลาง ไม่ใช่ pax/pay บนบก) • สัตว์เดินยังล็อกบนเรือเหมือนเดิม
