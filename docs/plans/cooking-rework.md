# แผนปรับเมนูอาหารเชฟ (ร่าง 11 พ.ย. 2026)

สถานะ: **แผน ยังไม่ได้แก้โค้ด** • ผู้ขอ: เจ้าของ • ผู้ทำ: เชฟ (อาชีพที่ 5) ที่ร้านอาหาร

## 1. ปัญหาที่เห็น (ตามโค้ดปัจจุบัน)
1. **วัตถุดิบเป็นแค่หมวด** `COOK_CATS` = 🐟ปลา/สัตว์น้ำ • 🥕ผัก/ผลไม้ • 🥚ไข่ (`public/shared.js:983`) ปลา 52 ชนิดกับผัก 25 ชนิดใช้แทนกันได้หมด เซิร์ฟเวอร์เลือก "ชนิดที่ถูกสุดก่อน" ให้เอง (`server/systems/crafting.js` `cook`) ผู้เล่นเลือกเองไม่ได้ และเอาปลาแพงมาทำก็ไม่ต่างจากปลาถูก
2. **จานเดียวต่อสูตร** ทำปลาอะไรก็ได้ `dish_grill` ตัวเดียวกัน ราคา 60 เท่ากันเสมอ ไม่มีเรื่องราวของจาน
3. **เมนูอ่านยาก** (`public/game.js` ~1480) 24 สูตรเรียงแถวยาวเป็นลิสต์เดียว ใต้ชื่อมีบรรทัดเล็กๆ บรรทัดเดียวยัด วัตถุดิบ+XP+เวลา+ค่าเตา+ราคาขาย+อิ่ม ไว้ด้วยกัน สูตรที่ยังล็อกปนกับสูตรที่ทำได้ ไม่เห็นว่า "ตอนนี้ทำอะไรได้บ้าง" และ "ขาดอะไรอยู่"
4. ชื่อสูตรหลายอันบอกวัตถุดิบที่ไม่มีจริง เช่น "สปาเกตตีกุ้ง" ใช้ปลาชนิดไหนก็ได้ ไม่ต้องมีกุ้ง

## 2. เป้าหมาย
- เปิดเมนูแล้ว **รู้ทันทีว่าทำอะไรได้ ขาดอะไร กำไรเท่าไร**
- มี **สูตรเฉพาะวัตถุดิบ** ที่ทำให้อยากหาปลา/ผักชนิดนั้นโดยเฉพาะ (เชื่อมเชฟกับชาวประมง/ชาวนา ตรงกับแนวคิด "ใช้ของข้ามสาย")
- ไม่ให้ครัวกลายเป็นช่องปั๊มเงิน (ค่าเตา 30% และราคาขาย ≈ มูลค่าวัตถุดิบ × ตัวคูณ ยังคงอยู่ ปรับด้วย `tools/econsim.js`)

## 3. ทำเป็น 3 ระยะ (ปล่อยแยกกันได้ ระยะ 1 คุ้มสุด)

### ระยะ 1 — ปรับหน้าเมนู (แก้เฉพาะ `public/game.js` + CSS ไม่แตะกติกา/เซฟ)
- **การ์ดสูตร** แทนแถวบรรทัดเดียว: ไอคอนใหญ่ + ชื่อ + ราคาขาย • ชิปวัตถุดิบเป็นรูป (🐟×2 🥕×1) เขียว = พอ แดง = ขาด (บอกจำนวนที่ขาด)
- **แท็บ/ตัวกรอง:** ✅ ทำได้ตอนนี้ • ทั้งหมด • 🐟ปลา • 🥕ผัก • 🥚ไข่ • 🔒 ยังไม่ปลดล็อก (ซ่อนรายละเอียด เหลือแค่ "ปลดที่เชฟ Lv N")
- **เรียงทำได้ก่อน** แล้วตามเลเวล สูตรที่ล็อกอยู่ท้ายสุด และสูตรถัดไปที่ใกล้ปลดไฮไลต์
- **รายละเอียดแยกชั้น:** บรรทัดหลักมีแค่ ชื่อ/วัตถุดิบ/ปุ่มทำ • แตะการ์ดค่อยขยายดู XP เวลา ค่าเตา กำไรสุทธิ (ราคาขาย − ค่าเตา) อิ่ม
- ปุ่ม "ทำ" บอกจำนวนที่ทำได้ เช่น **ทำ (×3)** และตัวเลขเวลาทำเป็นวงนับถอยหลังบนปุ่มตอนเตาร้อน
- มือถือ: การ์ดเดียวต่อแถว ปุ่มใหญ่ (ตาม `ux-reviewer`) • ตัวอักษรไม่เล็กกว่า 12px

### ระยะ 2 — สูตรเฉพาะวัตถุดิบ (แก้ข้อมูล `COOK` เป็นหลัก)
กลไกรองรับอยู่แล้ว: `in: [{ k: 'fish_shrimp', n: 1 }]` ใช้ของชนิดเจาะจงได้เลย (เซิร์ฟเวอร์ `cook` ตรวจ `need.k` ตรงๆ) ไม่ต้องเปลี่ยนเอนจิน ไม่เปลี่ยนเซฟ แค่เพิ่มสูตร/แก้สูตรเดิมให้ตรงชื่อ ตัวอย่างที่ชื่อตรงของจริง (id ปลา/ผักเช็กจาก `FISH_ALL`/`CROPS`):

| สูตร | วัตถุดิบเจาะจง | แนวเลเวล |
|---|---|---|
| ต้มยำกุ้ง | กุ้ง + พริก + มะเขือเทศ | 3–5 |
| ปูผัดผงกะหรี่ | ปู + ไข่ + พริก | 5–7 |
| ปลาหมึกย่างซอสพริก | หมึก + พริก | 6–8 |
| ปลาทูทอด+ผักสด | ปลาทู + แครอท | 1–3 (สูตรต้นเกม) |
| ฟักทองนึ่งนมสด | ฟักทอง + นมวัว | 7 |
| ผัดเผ็ดกะพงขาว | ปลากะพงขาว + พริก + ข้าวโพด | 8–10 |
| ซุปมะพร้าวกุ้งมังกร | กุ้งมังกร + มะพร้าวน้ำหอม | 14+ |
| สลัดอะโวคาโดทูน่า | ปลาทูน่า + อะโวคาโด | 15+ |
- สูตรหมวดกว้างเดิม (เช่น ปลาย่างผักสด) **เก็บไว้** เป็นเมนูพื้นฐานที่ใช้ปลา/ผักอะไรก็ได้ จึงไม่มีใครติด
- ตัวเลข (ราคา XP เวลา) ให้ `economy-designer` ตั้งตามกฎเดิม: ราคาขาย ≈ มูลค่าวัตถุดิบ × ตัวคูณ (ดูสูตรเดิมใน `COOK`) ผ่าน `tools/econsim.js` ก่อนปล่อย
- เสริมหน้าเมนู: ชิปวัตถุดิบเจาะจงแสดงชื่อ+อีโมจิจริง และถ้ายังไม่เคยตก/ปลูกให้ขึ้น "❓ ยังไม่เคยได้"

### ระยะ 3 — เลือกวัตถุดิบเอง + จานตามวัตถุดิบ (แตะเซฟ ต้องให้ `architect` ออกแบบก่อน)
- ผู้เล่นกด "เลือกวัตถุดิบ" แล้วเลือกปลา/ผักที่ใส่เอง (แสดงราคา ความสด) ปุ่มเดิม "อัตโนมัติ (ถูกสุด)" ยังอยู่
- จานเก็บชนิดวัตถุดิบหลักไว้ในกุญแจของไอเท็ม เช่น `dish_grill+fish_bass` (เดิม `dish_grill`) ชื่อในกระเป๋าเป็น "ปลาย่างผักสด (ปลากะพง)" และราคาขาย = ราคาฐานสูตร + สัดส่วนราคาวัตถุดิบหลัก (ปลาแพงได้จานแพง)
- ต้องแตะ: `itemInfo0` (regex `^dish_(\w+)$` ไม่รับ `+`), `sellCat`/ตลาดรายไอเท็ม, กินเพิ่มอิ่ม (`FOOD`), เทสต์ golden/persist • **เซฟเก่าไม่พัง** (กุญแจเดิม `dish_x` ยังเป็นจานมาตรฐาน) แต่รูปแบบกุญแจใหม่ต้องผ่าน `test-persist` และสำรองก่อน deploy
- ผูกกับ "สมุดสะสมเมนู": เพิ่มหมวดใน `BOOK` (เหมือนหมวดปลา/ผัก) ทำสูตรเจาะจงครบได้ของรางวัล = เหตุผลให้ลองทำทุกสูตร

## 5. ที่ต้องให้เจ้าของตัดสินใจ
1. เริ่มที่ **ระยะ 1 อย่างเดียว** ก่อนไหม (เห็นผลเร็ว ปล่อยได้ในรอบเดียว) แล้วค่อยดูระยะ 2–3
2. ระยะ 2: สูตรเฉพาะควร **เพิ่มเป็นสูตรใหม่** (ขายแพงกว่า เป็นเป้าให้หาวัตถุดิบ) หรือ **แทนที่สูตรเดิม** (เมนู 24 สูตรไม่บวม)
3. ระยะ 3: จะยอมให้ **ราคาจานขึ้นกับวัตถุดิบ** (ปลาแพงจานแพง) ไหม หรืออยากแค่ชื่อ/รูปแปลกตา ราคาเท่าเดิม (ปลอดภัยต่อเศรษฐกิจกว่ามาก)
4. อยากได้ **สมุดสะสมเมนู** เป็นรางวัลส่งท้ายไหม

## 6. เทสต์/เกณฑ์ว่าเสร็จ
- ระยะ 1: เปิดครัวบนมือถือ/PC แล้วเห็นแท็บ "ทำได้ตอนนี้" ถูกต้อง ขาดวัตถุดิบแล้วชิปแดงบอกจำนวน ไม่มีบรรทัดล้นจอ

- ระยะ 3: เทสต์โหลดเซฟเก่าแล้ว `dish_*` เดิมยังขาย/กินได้ • golden/persist ผ่าน
