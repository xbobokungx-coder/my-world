# แผนออกแบบกระเป๋าใหม่ (ช่องกริด + ช่องสวมใส่) — ร่างให้เจ้าของเลือก (15 พ.ย. 2026)

สถานะ: **ร่างดีไซน์ ยังไม่ลงโค้ด** • แรงบันดาลใจ: กระเป๋า Minecraft / Diablo (ช่องสี่เหลี่ยมเรียงกริด + ช่องสวมใส่ + แถบด่วน)

## ปัญหาของกระเป๋าปัจจุบัน (`renderBag` ใน `public/game.js` ~:1563)
- ของเก็บเป็น map `inv[key] = จำนวน` ไม่มีลำดับ/ตำแหน่ง → การ์ดเรียงตามลำดับ key ในไฟล์เซฟ หาของยาก
- แยกหมวกย่อยตามชนิดไอเทม (`BAG_SUBS`: เฟอร์ฯ ผัก ปลา ไม้ อุปกรณ์ อื่นๆ) ไม่ตรงกับสายอาชีพที่ผู้เล่นคิด (ตลาดนัดแก้เป็นกลุ่มอาชีพแล้ว `FLEA_GRPS`)
- เครื่องมือ/เสื้อผ้า/ความทนอยู่คนละแท็บ (เมนูเครื่องมือ ช่อง 1, ตู้เสื้อผ้า, แท็บอุปกรณ์) ต้องเปิดหลายหน้า

## เป้าหมาย
เห็นของทั้งหมดในจอเดียว หาเร็ว (ค้นหา+กรอง) เห็นของที่สวมอยู่ทันที จัดการของ (ขาย ปักหมุด ล็อก) ด้วยการกดสองครั้ง ใช้ได้ทั้งมือถือและ PC

## ดีไซน์ (ดูภาพร่างในแชต)
1. **คอลัมน์ซ้าย "สวมใส่"**: ช่องหมวก/เสื้อ/กางเกง/ของเสริม (ข้อมูลเดิม `me.wear`) • ช่องเครื่องมือ 6 ช่อง (จอบ บัว เบ็ด ขวาน อีเต้อ + ถัง/กระทะ แสดงระดับและแถบความทน) • แถบด่วน 1–4 (ตรงกับปุ่ม 1–4 ของเกม) กดช่องเครื่องมือ = เปลี่ยนระดับ/ซ่อมได้เลย
2. **ฝั่งขวา "กริดของ"**: ช่องสี่เหลี่ยมคงที่ ไอคอนพิกเซล + ตัวเลขจำนวนมุมขวาล่าง ขอบสีตามระดับ/ความหายาก (เทา/เขียว/ฟ้า/ทอง ใช้ตามตัวเลขระดับของไอเทม) ไม่มีช่องว่างคั่น (ของที่ไม่มีไม่แสดงช่อง เว้นโหมดจัดเอง)
3. **ค้นหา + ชิปกรองตามอาชีพ** (ใช้ `FLEA_GRPS` ชุดเดียวกับตลาดนัด: ชาวนา คนเลี้ยงสัตว์ ชาวประมง ช่างไม้ นักขุดแร่ เชฟ อื่นๆ) ชิปเลื่อนแนวนอนแถวเดียว สูง ≥44px บนมือถือ
4. **ปุ่ม "เรียงให้"**: เรียงตามอาชีพ → ระดับ → ชื่อ (เก็บ preference ใน localStorage)
5. **แผงรายละเอียดด้านล่าง**: กดช่อง = ดูชื่อ จำนวน ราคาขายตอนนี้ ความสด ปุ่ม ขาย/กิน/ใช้/ปักหมุด • Space/ปุ่ม A เปิด/ยืนยันได้ (ตามกฎปุ่ม Action)
6. **มือถือ**: คอลัมน์ซ้ายเป็นแถบเลื่อนแนวนอนด้านบน กริดลดเหลือ 6 คอลัมน์ ช่องสัมผัสไม่เล็กกว่า 44px (ที่ 360px = 6 คอลัมน์ ≈ 53px)
7. แท็บสถานะ/สกิล/สมุดเก็บ/ตู้เสื้อผ้า/กินอาหารเดิมคงไว้ (ไม่รื้อ) เปลี่ยนเฉพาะแท็บ "ของ"

## แบ่งเฟส
- **เฟส 1 (ฝั่งเว็บล้วน ไม่แตะเซฟ/server):** กริดช่อง + ค้นหา + ชิปอาชีพ + เรียงให้ + แผงรายละเอียด + คอลัมน์สวมใส่/เครื่องมือ/แถบด่วน (อ่านจากข้อมูลเดิม) • เสี่ยงต่ำ ย้อนง่าย
- **เฟส 2 (แตะเซฟ ต้องผ่าน `architect`):** จัดตำแหน่งช่องเองด้วยการลาก (`rec.bagPos` map key→ช่อง) • ปักหมุด/ล็อกไอเทมกันขายพลาด (`rec.bagLock`) • ขายทั้งกองอย่างเร็ว ต้องกำหนด migration (xpv) และเทสต์ใหม่

## ข้อตัดสินใจที่ต้องให้เจ้าของเลือก
1. **จำกัดช่องกระเป๋าไหม?** (Minecraft/Diablo มีจำกัด) ตอนนี้ไม่จำกัด แนะนำ **ไม่จำกัด** เพราะจะกระทบเศรษฐกิจ (ต้องมีที่เก็บ/ขยายช่อง) • ถ้าเลือกจำกัด ต้องออกแบบกล่อง/หีบเก็บของและส่งเข้าแผนเศรษฐกิจก่อน
2. **เฟส 2 ให้ลากจัดเองหรือเรียงอัตโนมัติพอ?** แนะนำ เริ่มเฟส 1 แล้วดูว่าผู้เล่นยังต้องการลากไหม
3. **ขอบสีตามความหายาก:** ตอนนี้เกมไม่มี "ระดับความหายาก" ของไอเทมทั่วไป (มีแต่ระดับอุปกรณ์/ปลาหายาก) แนะนำใช้ระดับอุปกรณ์ + ปลาหายากก่อน ของทั่วไปใช้ขอบกลาง
