# แผน: หน้าขายของแบบรายการ (แนว Vending ของ Ragnarok)

สถานะ: ร่างและตัวอย่างพร้อมให้เจ้าของดู ยังไม่ลงโค้ดจริง • ตัวอย่างโต้ตอบได้: `docs/mockups/sell-list-ui.html` (เปิดในเบราว์เซอร์ได้เลย สลับ PC/มือถือได้)

## เป้าหมาย
หน้าขายอ่านง่าย เห็นว่าขายอะไรได้ในพริบตา ไม่รก ใช้ได้ทั้ง PC และมือถือ ไม่ต้องพึ่งเมาส์

## การออกแบบ
- รายการ: แถวละ 1 ชนิด = ไอคอน • ชื่อ • ×จำนวน • 🪙ราคาต่อชิ้น ความสูงเท่ากันทุกแถว (ไม่ฝังช่องจำนวน/ปุ่มในแถว)
- แตะ/คลิกแถว = เลือก (ไฮไลต์) • PC: ↑↓ เลือกแถว Enter ขาย • มือถือ: แตะแถวแล้วใช้แถบล่าง
- แถบ "ที่เลือก" ด้านล่าง: ไอคอนใหญ่ ชื่อ จำนวนที่มี ราคาตลาด (▲▼ ปกติ) • ตัวปรับจำนวน −/ช่อง/+ • ยอดที่จะได้ • ปุ่ม "ขาย N ชิ้น" และ "ขายทั้งหมด (n)"
- ขั้นยืนยัน: กดขายแล้วขึ้นกล่อง "ขาย X ×n รับ 🪙T ยืนยัน?" [ขาย] [ยกเลิก] ก่อนส่งไปเซิร์ฟเวอร์
- ตัดจากแถวเดิม: ราคาตลาด ▲▼ คำเตือนตลาดอิ่มตัว ป้ายความสด → ย้ายไปแถบล่างตอนเลือก

## ขอบเขตโค้ด (ทำที่เดียวใช้ทุกร้าน)
- `public/game.js` ส่วนสร้างแถวขายใน `renderShop` (วนจาก `sellKeys` ราวบรรทัด 2118–2132) + ตัวผูกปุ่ม (`[data-sell]`, `[data-sq]` ราว 2185–2195) → ย้ายเป็นฟังก์ชัน `sellListHtml()` + `bindSellList()`
- `public/index.html` CSS: `.sellrow` เดิมแทนด้วย `.slist/.srow/.sbar` (เล็ก มินิมอล ตามสไตล์ HUD ใหม่)
- ไม่แตะเซิร์ฟเวอร์: ยังส่ง `{ t:'sell', item, n }` เดิม ราคา/ภาษี/ตลาดอิ่มตัวคำนวณที่เซิร์ฟเวอร์ตามเดิม
- ร้านที่ได้รับผล: ทุกร้านที่มีแท็บขาย (ตกปลา ฟาร์ม อาหาร สัตว์ ฯลฯ) เพราะใช้ตัวสร้างเดียวกัน

## ขั้นตอนทำจริง
1. แยกฟังก์ชันสร้างรายการขาย + เก็บ `sellSel`/`sellQty` ระดับโมดูล (วาดซ้ำแล้วไม่หาย)
2. HTML/CSS รายการ + แถบล่าง + ขั้นยืนยัน (ใช้ `ask()` เดิม ไม่ทำกล่องใหม่)
3. คีย์บอร์ด (PC) + ปุ่ม Action: Space/ปุ่ม A ที่ร้านเลือกแถวถัดไป/ยืนยันตามกฎ "ใช้ปุ่ม Action ได้เสมอ"
4. ทดสอบ: เล่นจริงบนเซิร์ฟเวอร์ dev ทั้ง PC + มือถือ (375px) • `tools/check-all.sh` • `ux-reviewer` เทียบ PC/มือถือ
5. อัปเดต `HOW-TO-PLAY.md` ส่วนร้านค้า

## ความเสี่ยง/ข้อสังเกต
- ผู้เล่นเคยพิมพ์จำนวนในแถว (ช่อง x1 ถูกเอาออกไปแล้ว) แบบใหม่ยังพิมพ์ได้ในแถบล่าง + ปุ่ม −/+
- ของที่ราคาต่อชิ้นลดลงเมื่อขายเยอะ: ยอดรวมในแถบล่างต้องตรงกับเซิร์ฟเวอร์ (`sellQuote`) ตัวอย่างใช้สูตรจำลอง
- ไอคอนใช้พิกเซลอาร์ตเดิมของเกม (`PixelArt`/`.pxe`) ไม่ใช่อีโมจิในตัวอย่าง
