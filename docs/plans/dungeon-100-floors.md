# ปราสาท 100 ชั้น: เงื่อนไขเปิดประตูรายชั้น + ของตกบอสทุก 10 ชั้น (ร่าง 15 พ.ย. 2026)

สถานะ: **ร่างออกแบบ ยังไม่ลงโค้ด ตัวเลขยังไม่ผ่านซิม** • ต่อจาก `DUNGEON-100.md` (แผนหลัก) และ `dungeon-100-spec.md` (สเปกเทคนิค)
หมายเหตุที่ผมตีความ: ข้อความล่าสุดของเจ้าของถูกตัดท้ายตรง "ดรอป Item พิเศ…" ผมตีความว่า **บอสทุกตัวดรอปไอเทมพิเศษเฉพาะตัว** และ "ประสาท" = **ปราสาท** ถ้าตีความผิดบอกได้

## 1. หลักการ "ประตูผนึก" (ทุกชั้นต้องทำเควสเปิดประตูก่อนลงชั้นถัดไป)
1. **ทุกชั้นมีประตูลงล็อกด้วยผนึก** ต้องทำเงื่อนไขของชั้นนั้นให้ครบจึงเปิด ต่างจากสเปกเดิมที่ชั้นปกติ "บันไดเปิดตั้งแต่ต้น" (**สเปกข้อ K4 ต้องแก้**)
2. **จำนวนผนึกเพิ่มตามความลึก:** อาณาจักร 1–3 = 1 ผนึก • 4–9 = 2 ผนึก (ต้องทำครบทั้งสอง คนละมุมแผนที่ ทำให้ชั้นลึกยาวขึ้นตามเป้า ~16 นาที) • 10 = 3 ผนึก
3. **เงื่อนไขกำหนดตายตัวรายชั้น** (ตารางข้อ 3) ไม่สุ่ม ผู้เล่นวางแผนล่วงหน้าได้ ส่วนผังชั้น/ตำแหน่งมอนสเตอร์ยังสุ่มจาก seed รายสัปดาห์ตามสเปก • ตารางเก็บเป็นข้อมูลใน shared (`DG_FLOORS[ชั้น] = ผนึก[]`) ปรับได้โดยไม่แก้โค้ด
4. **ประเภทผนึก (รหัสในตาราง):**

| รหัส | ชื่อ | ทำอะไร |
|---|---|---|
| K | ค่าย | ไม่มีมอนสเตอร์ ทำพิธีสั้นๆ ที่ค่าย (กองไฟ/หม้อยา/ตะเกียง ฯลฯ) ได้ฝึกกลไกใหม่ของอาณาจักร ทุกคนในปาร์ตี้ทำเองหนึ่งครั้ง |
| A | กวาดล้าง | ปราบมอนสเตอร์ให้ครบจำนวน (12–20 ตัวตามอาณาจักร) |
| B | กุญแจ | ปราบตัวถือกุญแจ ซึ่งอยู่ฝั่งเดียวกับประตูเสมอ (ข้อ K5 สเปก) |
| C | ป้องกันแท่น | แท่นมี HP รอดครบ 2–3 คลื่น |
| D | รอด | ทนสภาวะบังคับให้ครบเวลา (60–90 วินาที) |
| E | ล่าหัวโจก | ปราบอีลีท 1–2 ตัว |
| F | ปริศนา | สวิตช์/ลำดับ/กระจก/รูปสลัก (ผิดแล้วลองใหม่ได้ มีมอนสเตอร์ซ่อนโผล่แทนโทษหนัก) |
| G | บุกเร็ว | ปราบให้ทันเวลา ไม่ทันลองใหม่ได้ตามรอบ ไม่มีโทษ |
| H | เครื่องเซ่น | ใส่ของจากอาชีพอื่นลงแท่น (ผัก/ปลา/แร่/ไม้/อาหาร) **ทุกข้อ H มีทางสำรองแบบต่อสู้ ไม่ต้องมีของ** |
| I | กลไกอาณาจักร | ทำภารกิจของกลไกประจำอาณาจักรนั้น (ความมืด พิษ กระจก ฯลฯ) |
| L | ศาลเจ้า | เลือกพร 1 อย่างแลกคำสาป 1 อย่าง แล้วทำเป้าหมายภายใต้เงื่อนไขนั้น (ไม่เลือก = ปราบปกติมากกว่า) |

5. **กันตันและกันโกง (บังคับ):** กุญแจ/ของหาย/ตัวถือกุญแจหลุดแมพ = เกิดใหม่ในห้องเดิมอัตโนมัติ • ผนึกของชั้นที่ทีมล้มทั้งหมดแล้วกลับค่ายต้องทำใหม่ (ชั้นรีเซ็ต) • ผู้ดูแลมีคำสั่งแก้ชั้นตัน (`dg stuck` ตามสเปก) • ปาร์ตี้ผนึกครบแล้วทุกคนผ่านพร้อมกัน ไม่ต้องรอ • **ทางหนีทีไล่:** ออกจากหอคอยได้ทุกเมื่อที่ไม่มีมอนสเตอร์ไล่ 5 วินาที
6. **รางวัลเสริมทุกชั้น (เลือกทำ):** เงื่อนไขโบนัสหนึ่งข้อสุ่มต่อชั้น (ไม่โดนตีเกิน 3 ครั้ง / ผ่านก่อนเวลา / ปราบอีลีทเสริม) ได้หีบเสริมของตกเพิ่ม ไม่บังคับ เป็นแรงจูงใจให้เล่นดีขึ้น ไม่ใช่เส้นทางที่ต้องผ่าน
7. **จังหวะ:** x1 = ค่าย (หลังบอส) • x5 = มินิบอส + ค่ายท้ายชั้น (จุดเซฟ) • x0 = บอส • ชั้นอื่นผสมตามตาราง ไม่ให้ชั้นติดกันซ้ำแบบเดียวกัน

## 2. ย้ายเมืองใต้ดิน
แผนหลักเขียนว่าชั้น 50 = เมืองใต้ดิน แต่ชั้น 50 เป็นลานบอสเทพพฤกษา และตามสเปกจุดลงจริงคือ x1 (หลังบอส) → **ย้ายเมืองใต้ดิน "ลานพักใต้พิภพ" ไปเป็นชั้น 51** (ร้านค้า ช่างตี ผู้เฒ่าเล่าเรื่อง ตู้เก็บของ จุดเซฟใหญ่ครึ่งทาง)
