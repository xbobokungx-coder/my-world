## 3. แผนผังห่วงโซ่เฟสแรก
```
นักขุด ─แร่×3+ค่าเตา→ [🔥 เตาหลอม @ร้านช่างเหมือง] → วัสดุ bar_* ─แผง/เสนอซื้อ/เทรด→ ทุกอาชีพ Lv15+ (อุปกรณ์ 8–10)
                                                         └────────────────→ ช่างไม้ (เฟอร์นิเจอร์ชั้นดี) → แผง → ทุกคน (แต่งบ้าน)
ชาวนา ─แครอท/ข้าวโพด→ [🌾 อัดฟาง @ร้านเมล็ดพันธุ์] → hay ─แผง/เสนอซื้อ→ คนเลี้ยงสัตว์
ทางสำรอง: ร้านช่างเหมืองขายวัสดุ ราคา std×1.5 • ร้านปศุสัตว์ขาย hay 24 เท่าเดิม • ซื้ออุปกรณ์ไม่มีวัสดุ = เติมเหรียญอัตโนมัติ = ราคาเดิมเป๊ะ
```
สินค้าใหม่: วัสดุ 10 ชนิด (`bar_<แร่>`) + เฟอร์นิเจอร์ชั้นดี 6 ชิ้น • `hay` ใช้คีย์เดิม (ระบบสัตว์ไม่ต้องแก้)

## 9. ความเสี่ยงและทางโกง
- **ปั๊มขายคืน:** ซื้อวัสดุถูกจากบัญชีสำรอง (0.5×std = ⅓ ราคาร้าน) ซื้ออุปกรณ์ ขายคืน 70% → ต้นทุน (1−s+s/3)P = 0.83P > 0.7P ที่ s 0.25 • ปั๊มเริ่มที่ s > 0.45 → เทสต์ล็อก s ≤ 0.30 ทุกระดับ
- **หลอมแล้วขายวน:** วัสดุไม่มี `sell` ไม่อยู่ `SELLABLE`/ใบงาน → ไม่มีทางกลับเป็นเหรียญจากระบบ • เฟอร์นิเจอร์ร้านรับ 35% < วัตถุดิบ ~50% • ร้านวัสดุ > std เสมอ
- **คนเลี้ยงสัตว์เกินเป้า:** hay ถูก ตัดต้นทุนวัว (นม 55 vs hay 24) มากสุด → E1 ซิม ถ้าเกินปรับ `std` ของ hay (พื้นแผง) หรืออัตราอัดฟาง • **ผักเก่า → hay** กันด้วยตัวคูณความสด
- **ซื้อ XP ด้วยเหรียญ:** ช่างไม้ซื้อวัสดุร้านแล้วประดิษฐ์ → XP คิดจากไม้เท่านั้น
- **ดีมานด์อ่อน:** ใช้แค่อุปกรณ์ 8–10 ครั้งเดียว นักขุดได้เพิ่มน้อย → วัด `logEv make`/แผง 2 สัปดาห์ แล้วตัด O-9 • **สมุดรับซ้ำ** (ข้อ 2) → O-8
- **ถอยกลับ:** ไม่รันสคริปต์ = วัสดุ/เฟอร์นิเจอร์ค้างในเซฟ (ไม่หาย) แต่ใช้ไม่ได้ ต้องเช็กว่าบ้านที่มี furn id ไม่รู้จักไม่ทำเว็บเก่าพัง (Q2) • โค้ดพัง: `deploy.sh` ย้อนเอง
