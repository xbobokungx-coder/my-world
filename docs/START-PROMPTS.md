# Prompt เริ่มต้นสำหรับ Claude Code (My World)

ทำตามลำดับ ก๊อปข้อความในกรอบไปวางใน Claude Code ทีละอัน รอให้แต่ละขั้นเสร็จและตรวจผลก่อนไปต่อ
ขั้นที่มี ⚠️ ต้องอ่านผลเองก่อนตอบตกลง

---

## ขั้น 0 — ทำเองก่อนเปิด Claude Code (ไม่ต้องใช้ Claude)

1. **ยกเลิกคีย์ PixelLab เก่าที่หลุด** แล้วออกคีย์ใหม่ที่หน้าบัญชี PixelLab
2. ตั้งคีย์ใหม่เป็นตัวแปรระบบ (อย่าใส่ลงไฟล์ใดๆ ในรีโป)
   - Windows: `setx PIXELLAB_API_KEY "<คีย์ใหม่>"` แล้ว **ปิดและเปิดเทอร์มินัลใหม่**
   - Linux/macOS: เพิ่ม `export PIXELLAB_API_KEY="<คีย์ใหม่>"` ใน `~/.bashrc` หรือ `~/.zshrc`
3. อัปเดต Claude Code: `claude update` แล้วเช็ก `claude --version` (ควรใหม่กว่า 2.1.271)
4. ในโฟลเดอร์โปรเจคที่สร้างไว้ (ต้องว่าง):
   ```
   git clone https://github.com/xbobokungx-coder/my-world.git .
   ```
   (ตั้งคีย์ SSH แล้วค่อยเปลี่ยน remote เป็น `git@github.com:...` ภายหลังได้ ขั้น 2 จะเช็กให้)
5. แตก `my-world-studio.zip` ลงในโฟลเดอร์เดียวกัน (รากรีโป) ชุดนี้เพิ่มไฟล์ใหม่อย่างเดียว ไม่ทับไฟล์เดิม
6. เปิด `claude` ในโฟลเดอร์นั้น ครั้งแรกจะถามให้เชื่อถือโฟลเดอร์และยืนยันเซิร์ฟเวอร์ `pixellab` จาก `.mcp.json` ให้ตอบตกลง

---

## ขั้น 1 — ติดตั้งชุดไฟล์เข้ารีโป ⚠️

```
เพิ่งแตกชุดไฟล์ทีมงาน (my-world-studio) ลงรากรีโปนี้ อ่าน docs/plans/AGENTS-PLAN.md, docs/plans/REFACTOR-PLAN.md,
docs/SETUP-MACHINES.md และ docs/OPS.md ให้เข้าใจภาพรวมก่อน แล้วทำตามนี้ทีละข้อ ยังไม่ต้อง commit:

1. .gitignore: รวมกับ gitignore.proposed — เก็บบรรทัดเดิมที่ยังใช้อยู่ทั้งหมด ลบบรรทัด ".claude/"
   (เพราะทีม agent ต้องขึ้น git) และเพิ่มบรรทัดใหม่จาก proposed ที่ยังไม่มี
2. ลบไฟล์ "gitignore" (ไม่มีจุดนำหน้า) ที่ซ้ำกับ .gitignore
3. CLAUDE.md: เทียบของเดิมกับ proposed/CLAUDE.md และ docs/OPS.md แล้วสรุปให้ฉันดูว่า
   หัวข้อไหนย้ายไป OPS.md หัวข้อไหนตัดสั้นลง และมีข้อมูลสำคัญอะไรที่หายไปไหม
   ถ้าไม่มีอะไรหาย ให้แทนที่ CLAUDE.md ด้วย proposed/CLAUDE.md
4. ลบโฟลเดอร์ proposed/ และไฟล์ gitignore.proposed
5. ตั้งสิทธิ์รันให้สคริปต์ใน git: git update-index --chmod=+x tools/deploy.sh tools/pull-backup.sh
   (ถ้ายังไม่ได้ add ให้ add ก่อน)
6. รัน node --check กับ .claude/hooks/*.js และ tools/art-import.js และ bash -n tools/deploy.sh
7. แสดง git status แบบสรุป และบอกว่าจะแบ่ง commit อย่างไร (ข้อความ commit ภาษาไทย)

รอฉันตอบตกลงก่อน commit และ push
ส่วน .gitattributes: อย่าเพิ่งรัน git add --renormalize ให้บอกฉันก่อนว่าจะกระทบไฟล์กี่ไฟล์
```

หลังตกลงแล้ว พิมพ์ `ตกลง commit และ push ได้` จากนั้น **ปิดแล้วเปิด Claude Code ใหม่** เพื่อให้ agent, skill, hook โหลดครบ

## ขั้น 2 — ตรวจเครื่องนี้

```
ตรวจเครื่องนี้ตาม docs/SETUP-MACHINES.md หัวข้อ 2 ทีละข้อ:

npm install, ตัวแปร PIXELLAB_API_KEY ถูกตั้งไว้หรือไม่ (บอกแค่มี/ไม่มี ห้ามแสดงค่า),
/mcp เห็นเซิร์ฟเวอร์ pixellab เชื่อมต่อได้ไหม,
และตอนเปิด session เห็นบรรทัด [git] จาก hook หรือไม่
บอกเฉพาะข้อที่ยังไม่ผ่านพร้อมคำสั่งที่ฉันต้องรัน ยังไม่ต้องแก้อะไรเอง
```

## ขั้น 3 — ทดลองทีมทีละตำแหน่ง (งานเล็ก ไม่แก้โค้ด)

```
ทดลองทีม agent ทีละตัวด้วยงานอ่านอย่างเดียว ห้ามแก้ไฟล์ในขั้นนี้ แล้วสรุปเป็นตาราง
(agent / โมเดลที่รันจริงจาก /tasks / ผลสั้นๆ / ปัญหา):
1. Explore: ระบบล็อตโต้ออกรางวัลที่ไหน และเก็บข้อมูลใน state ตัวไหน
2. qa-tester: รันเทสต์ทั้งหมด รายงานเฉพาะที่พัง
3. code-reviewer: ตรวจ commit ล่าสุด (git diff HEAD~1)
4. economy-designer: รัน levelsim กับ econsim แล้วสรุปเคส 2 ใน docs/reports/ISSUES-2026-10.md ว่าตัวเลขตอนนี้เป็นยังไง (ห้ามแก้ค่า)
5. pixel-artist: แสดงรายชื่อเครื่องมือของ PixelLab ที่ใช้ได้ (ห้ามสร้างภาพ จะเสียเครดิต)
ถ้าตัวไหนไม่ถูกเรียก ทำงานผิดขอบเขต หรือรันผิดโมเดล ให้เสนอวิธีแก้ไฟล์ agent นั้น
```

## ขั้น 4 — เตรียม VPS ⚠️

```
ให้ ops ช่วยเตรียม VPS ตาม docs/SETUP-MACHINES.md หัวข้อ 3 และ docs/OPS.md:
1. ssh my-world แล้วดู git status ใน /root/my-world — ถ้ามีไฟล์แก้ค้างหรือ commit ที่ยังไม่ push
   ให้สรุปให้ฉันดูก่อน อย่าเพิ่ง commit อะไรบน VPS
2. หลังฉันตกลง: commit+push ของค้างจาก VPS (ถ้ามี) แล้ว git pull เพื่อให้ได้ tools/deploy.sh
3. เช็กว่า tools/deploy.sh มีสิทธิ์รัน, มี flock กับ curl, และ cron สำรองข้อมูล
   (/etc/cron.d/my-world-backup) ยังทำงาน ดูไฟล์ล่าสุดใน backup/auto/daily
4. รัน ./tools/deploy.sh --check (ห้ามรันแบบ -y ในขั้นนี้)
รายงานผลแต่ละข้อสั้นๆ
```

แล้วทดสอบสำรองข้อมูลนอก VPS (บนเครื่องที่จะเก็บสำรอง แนะนำคอมบ้าน):

```
รัน tools/pull-backup.ps1 (หรือ pull-backup.sh ถ้าไม่ใช่ Windows) หนึ่งครั้งเพื่อดึงไฟล์สำรองล่าสุดจาก VPS
ถ้าสำเร็จ ให้บอกคำสั่ง schtasks (หรือ crontab) สำหรับตั้งเวลาทุกวัน 21:00 ให้ฉันรันเอง
```
