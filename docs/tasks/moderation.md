## โปรโตคอล (server-dev เขียน)
ค่าคงที่ฝั่งเว็บอ่านจาก `Shared.MODERATION` (`reportWhy` = รายการ `{id,name}` สำหรับเมนูเหตุผล, `reportTextMax` 100, `blockMax` 50, `muteMs` คีย์ `10m/1h/1d`, `banMs` คีย์ `1d/7d`, `chatlogDays` 14 สำหรับข้อความประกาศ)

**client -> server (ผู้เล่นทุกคน ใช้ในบ้านได้ด้วย)**
- `{t:'block', id, on}` id = id ผู้เล่นในห้อง (จำนวนเต็ม) on = boolean เท่านั้น • เลิกบล็อกคนออฟไลน์: `{t:'block', name, on:false}` (ชื่อจากรายการ `blocks`) • บล็อกตัวเอง/ซ้ำ = ไม่มีผล เกิน 50 ได้ toast
- `{t:'report', id | name, why, text}` why ต้องเป็น id ใน `reportWhy` (`abuse|cheat|other`) text ≤ 100 ไม่บังคับ • ผลตอบเป็น toast `msg` เสมอ (สำเร็จ/ถี่เกิน 30 วิ/ครบ 10 ครั้งต่อชม./รายงานตัวเอง-ผู้ดูแลไม่ได้) และ `{t:'reportres', ok:true}` เมื่อสำเร็จ

**server -> client**
- `{t:'blocks', list:[{key,name}], ids:[id ที่ออนไลน์และถูกบล็อก]}` ส่งตอนเข้าเกม (เฉพาะเมื่อมีรายการ ไม่เคยส่ง = ว่าง) และส่งใหม่ทุกครั้งที่บล็อก/เลิกบล็อก • `key` = ชื่อตัวพิมพ์เล็ก (จับคู่ผู้เล่นออนไลน์ด้วย `name.toLowerCase()`) • ตอนบล็อก เซิร์ฟเวอร์ส่ง `{t:'pcall', from, k:'end'}` ให้ทั้งสองฝั่ง ฝั่งเว็บควรตัดการเชื่อมต่อเสียง (WebRTC) กับ `ids` ที่เพิ่งบล็อกด้วย
- `{t:'muted', until}` ถูกผู้ดูแลปิดเสียง (until = ms, 0 = เปิดเสียงแล้ว) ควรหยุดไมค์ตัวเอง • มี toast `msg` ด้วย • แชตที่พิมพ์ตอนถูกปิดเสียงถูกทิ้ง + toast แจ้ง
- `chat` ที่ได้รับผ่านกรองคำแล้ว (`***`) และไม่มีของคนที่บล็อกกัน • `chatlog` ตอนเข้าเกมตัดคนที่บล็อกไว้ออกแล้ว

**admin (ส่ง `{t:'admin', a, ...}` ตอบ `{t:'admin', ...}` เฉพาะผู้ดูแล)**
- `a:'reports'` -> `{reports:[{id,time,room,by,target,targetKey,why,text,closed,closedBy,closedAt}]}` ใหม่สุดก่อน ไม่รวมแชตแนบ
- `a:'reportget', id` -> `{report:{...ทั้งใบ มี chat:[{name,text,t}] 10 บรรทัด}}` หรือ `{err, reports}`
- `a:'reportclose'|'reportopen', id` -> `{reports}` หรือ `{err, reports}`
- `a:'chatlog', name?, day?('YYYY-MM-DD' ค่าเริ่มต้นวันนี้), room?` -> `{chatlog:{day, days:[วันที่มีไฟล์], rows:[{t,room,name,text}] ≤200 แถวท้ายสุด, total}}` name ค้นแบบมีส่วนนี้อยู่ในชื่อ
- `a:'mute', room, name, dur:'10m'|'1h'|'1d'|'off'` -> `{muted:key, until, users, bans}` หรือ `{err, users, bans}` • `users[i].mute` = เวลาหมดโทษปิดเสียง (0 = ไม่ถูกปิด)
- `a:'ban', room, name, dur?:'1d'|'7d'` ไม่ใส่ dur = ถาวรเหมือนเดิม -> `{banned:key, until (0 = ถาวร), users, bans}` • `bans[i]` มี `until` เมื่อเป็นแบนชั่วคราว (ถาวรไม่มีฟิลด์นี้) • `a:'unban'` ล้างทั้งสองแบบ • คนติดแบนชั่วคราวเข้าเกมได้ `err` "พักการเล่นชั่วคราว" จนหมดเวลา
- non-admin ส่ง admin ไม่มีผล/ไม่มีตอบ (เซิร์ฟเวอร์ตรวจ `p.admin`) • แบน/ปิดเสียงผู้ดูแลไม่ได้ ตอบ `{err}` • มีรายงานใหม่ ผู้ดูแลในห้องได้ toast `msg` ขึ้นต้น 🚩
