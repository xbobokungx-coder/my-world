# ตั๋วชุด A: งานฝั่งเซิร์ฟเวอร์ (ไม่แตะรูปแบบเซฟ)

ไฟล์ที่แก้ได้: `server.js`, `server/systems/*`, `public/shared.js` (เฉพาะค่าคงที่ที่เกี่ยว), `tools/test-*.js`
ห้ามแตะ `public/game.js` `public/index.html` (ชุด B ทำอยู่) ห้าม commit/push

1. **ฤดู:** เปลี่ยนให้ฤดูเปลี่ยน 1 ฤดูต่อ 1 วันจริง (ตอนนี้ `SEASONS.days: 3.5` ใน `shared.js:326` มี 3 ฤดู) อัตราฝน (`RAIN`) คงเดิม ตรวจจุดที่พึ่งค่า 3.5 (ข้อความบอกเวลา, เทสต์ `tools/test-seasons.js`, เอกสารตัวเลข) ให้สอดคล้อง
2. **ให้อาหารสัตว์เพื่อน:** ให้อาหารสัตว์ตัวเอง = ผลผลิตล็อก 1 วันเกม (เหมือนเดิม) • ให้อาหารสัตว์ของคนอื่น = ล็อกแค่ 3 นาทีจริง (ค่าคงที่ใน shared) เพื่อไม่ให้ผลผลิตเพื่อนค้างนานและสัตว์เพื่อนไม่ตายเปล่า ดู `server/systems/animals.js` (`fed` `feeder` `fn` `pm`) เพิ่มเทสต์
3. **แอดมิน (ฝั่งเซิร์ฟเวอร์):** ข้อความสั่งเปิด/ปิดความหิว • สั่งเพิ่มเงินทีละ 1,000 • ส่งสถานะ On Develop = เวลาที่แอดมินออนเกม (วินาทีนับจากเข้าเกม) ในข้อมูลที่ฝั่งเว็บเรียกดู ตรวจสิทธิ์แอดมินที่เซิร์ฟเวอร์เท่านั้น เพิ่มเทสต์ว่าผู้เล่นทั่วไปสั่งไม่ได้ ห้ามเขียนรหัสแอดมินลงที่ไหน
4. **ขับยานพาหนะ:** ระหว่างขับ ถ้าส่งการกระทำอื่น (ปลูก ตัดไม้ ขุด ตกปลา ฯลฯ ที่ไม่ใช่การขับ) ให้เซิร์ฟเวอร์สั่งลงจากรถทันทีและแจ้งฝั่งเว็บ (ข้อความที่ฝั่งเว็บมีอยู่แล้วถ้ามี) ไม่ทำการกระทำนั้นในครั้งนั้น ดูโค้ดยานพาหนะที่มีอยู่ก่อนว่าลงจากรถทำอย่างไร

## รายงาน
สั้น: ไฟล์:บรรทัดที่แก้ + เทสต์ที่เพิ่ม + ผลรัน `node --check` และ `tools/test-*.js` ที่เกี่ยว + ข้อความ/ฟิลด์ใหม่ที่ฝั่งเว็บต้องรู้ (ชื่อข้อความ รูปแบบ)
