## สัญญา (server ↔ web) — ทั้งสองฝั่งต้องตรงกัน
พิกัดเป็นพิกเซลโลก • ทิศ dir 0 ใต้ 1 เหนือ 2 ตะวันตก 3 ตะวันออก • state `st`: 0 เดินเล่น 1 ไล่ 2 ง้าง(telegraph) 3 โจมตี 4 พัก/ตกใจ • id สัตว์เป็นเลขจำนวนเต็มต่อเซิร์ฟเวอร์
**server → client (ส่งเฉพาะคนที่อยู่ชั้นนั้น `sceneBroadcast(CAVE + f, …)`):**
- `{t:'crs', list:[[id,k,x,y,dir,st,hp,hpMax],…]}` รายการเต็ม ส่งให้ผู้เล่นทันทีหลังเข้าชั้นถ้ำ (หลัง `changeScene`) และเมื่อเปลี่ยนชั้น
- `{t:'crm', u:[[id,x,y,dir,st,hp],…]}` เดลต้า ทุก `CREATURE.tickMs` เฉพาะตัวที่ขยับ/เปลี่ยนสถานะ
- `{t:'crn', c:[id,k,x,y,dir,st,hp,hpMax]}` เกิดใหม่ • `{t:'crd', id}` หายไป (ตาย)
- `{t:'cra', id, x, y, r, ms}` วงเตือนบนพื้น (จุดศูนย์กลาง x,y รัศมี r พิกเซล ยาว ms) ส่งตอนเริ่มง้างทุกครั้ง
- `{t:'crh', id, hp}` สัตว์ถูกผู้เล่นฟาด (ให้ทุกคนในชั้นเห็นแถบ HP/สะดุ้ง)
**server → ผู้เล่นที่โดน (ส่วนตัว):** `{t:'hurt', k, h, stun, x, y}` k=ชนิด h=หิวที่เสีย stun=ms ที่ห้ามขยับ/ฟาด x,y=ตำแหน่งหลังถูกผลัก (เซิร์ฟเวอร์ย้าย p.x/p.y แล้วส่ง `tp` ตามกลไกเดิมถ้าจำเป็น) • `{t:'web', ms}` ติดใย (เดินช้า) • `{t:'faint', ms}` สลบพัก (แล้ววาร์ปไปจุดลงบันไดของชั้น)
**client → server:** ไม่มีข้อความใหม่ — ฟาดสัตว์ใช้ `act` เดิม (`pickAct` ตรวจสัตว์ก่อนแร่)

## กติกาฝั่งเซิร์ฟเวอร์ (`server-dev`)
ไฟล์ใหม่ `server/systems/creatures.js` (mixin ตาม `mining.js`) + ต่อเข้า `server.js` (`mix` + `initCave` เรียก init + tick) + แก้ `pickAct` ใน `mining.js` + เทสต์ `tools/test-creatures.js`
1. สัตว์เก็บใน `this.floors.get(f).creatures` (Map id → obj) **ในหน่วยความจำ ไม่ลงเซฟ** • สร้างตอนมีคนอยู่ชั้นนั้น (`sceneMates(CAVE+f).length>0`) จำนวน `creatureCap(f)` ชนิดสุ่มด้วย `creaturePick` จุดเกิดบนช่อง `S.caveOpen` อยู่ห่างผู้เล่นทุกคน ≥ 8 ช่อง และ **นอกเขตปลอดภัย** `CREATURE.safe` ช่องรอบจุดเกิดชั้น (`S.CAVE.spawn`) และรอบบันไดลง/ขึ้น (`T.DOWN`/ช่องลงจอด `caveLanding`) • ชั้นที่ไม่มีคนเลิกอัปเดต (ไม่กิน CPU) และเคลียร์ทิ้งเมื่อว่างคน 60 วินาที • เพดานรวมทั้งเซิร์ฟเวอร์ `CREATURE.maxTotal`
2. อัปเดตทุก `CREATURE.tickMs` เฉพาะชั้นที่มีคน: เดินเล่นสุ่ม → เห็นผู้เล่นภายใน `aggro` ช่อง (เส้นตรงไม่ถูกผนังบัง ใช้ blockedAt/`S.caveOpen`) → ไล่ด้วย `creatureSpeed` (ห้ามเกินความเร็วผู้เล่น ยกเว้นโหมด dart/lunge พุ่งสั้นๆ ต้องผ่านท่าง้าง) → ง้าง `wind` ms (ส่ง `cra`) → โจมตี → พัก 1 วินาที → วนใหม่ • สัตว์เดินได้เฉพาะช่องโล่ง ไม่ทะลุผนัง/แร่ ไม่เข้าเขตปลอดภัย (เดินวนออกถ้าถูกต้อน) ผู้เล่นที่ยืนในเขตปลอดภัยไม่ถูกตี
3. โหมด (`CREATURES[k].mode`): `chase` ไล่กัดธรรมดา • `dart` ค้างคาวบินส่ายเข้าแล้วถอยทีละรอบ • `web` แมงมุมพ่นใยวงเตือนที่พื้นภายใน `reach` ช่อง ถ้าผู้เล่นยังอยู่ในวงตอนจบ = `web` เดินช้า `CREATURE.webSlow` + ความหิวลดครึ่งของ `creatureHunger` • `lunge` งูซุ่มนิ่งจนผู้เล่นเข้าใกล้ `aggro` แล้วพุ่งตรง `reach` ช่อง • `smash` ยักษ์ทุบวงกว้างใต้ตัว (r ≈ `reach` ช่อง)
4. ผลเมื่อโดน (ต่อผู้เล่น): ช่วงอมตะ `invulnMs` หลังโดน • หิวลด `creatureHunger(f)` (ไม่ต่ำกว่า 0) • สตัน `stun` ms (ผู้เล่นขยับ/ฟาดไม่ได้ ตรวจฝั่งเซิร์ฟเวอร์ใน `pickAct` และการเดิน ถ้าการเดินมี guard เดิมให้ใช้ร่วม) • ผลักถอย `knock` ช่อง (ห่างจากสัตว์ ไม่ทะลุผนัง) • โดน `CREATURE.faint.hits` ครั้งภายใน `faint.ms` = สลบ: ห้ามเสียของ/เหรียญ ผู้เล่นพัก `restMs` แล้ววาร์ปไป `caveLanding(f)` (ชั้น 1 ใช้ `S.CAVE.spawn`) ส่ง `faint` • **ห้ามตาย ห้ามเสียของ/เหรียญ/อีเต้อ**
5. ฟาดสัตว์: ใน `pickAct` ก่อนมองหาแร่ ตรวจสัตว์ที่อยู่ในจุดหน้า (`S.facing`) ในรัศมี ~0.8 ช่อง (รองรับคลิกช่อง `cx,cy` ด้วย) • ดาเมจ 1 ต่อครั้งตามความทนของสัตว์ `creatureHp` คือ "จำนวนฟาด" (อีเต้อต่ำกว่าชั้นก็ยังตีได้ 1 ต่อครั้งเหมือนเดิม ไม่ซับซ้อน) • อีเต้อสึกเท่าฟาดแร่ก้อนเล็ก 1 ครั้ง (ใช้ `durUse` ตามแบบเดิม) • ถูกฟาด: สัตว์สะดุ้ง ผลักถอย 1 ช่อง เข้าสถานะ 4 (พัก) ครึ่งวินาที • ตาย: ส่ง `crd` เกิดใหม่หลัง `respawnMs` ที่จุดห่างผู้เล่น • **ไม่ให้ XP ไม่ให้เหรียญ ไม่ให้ของ** (`logEv` บันทึกเหตุการณ์ `creature_hit`/`creature_faint` ให้ `tools/stats.js`)
6. เทสต์ `tools/test-creatures.js` (ต้องผ่านใน `tools/check-all.sh`): สัตว์เกิดตามชั้น/เพดาน/ชนิดตามชั้น • ไม่เกิดในเขตปลอดภัย • ชั้นว่างคนไม่อัปเดต • โดนแล้วหิวลดตามชั้น ไม่ต่ำกว่า 0 ไม่ตาย ไม่เสียของ/เหรียญ • อมตะหลังโดน • โดนครบ 4 ครั้งสลบแล้ววาร์ปถูกที่ • ฟาดสัตว์ตายตามจำนวนฟาด อีเต้อสึก • เกิดใหม่หลัง respawnMs • `CREATURE.on=false` แล้วไม่มีสัตว์/ไม่มีข้อความ • ผู้เล่นออกชั้นแล้วไม่ถูกตีต่อ • ไม่ลงเซฟ (ไม่มี creatures ใน rec)
ข้อห้าม: ไม่แตะรูปแบบไฟล์เซฟ • ไม่ commit • ไม่แตะ `public/*` (ฝั่งเว็บเป็นของ client-dev) ยกเว้นไม่มี • รายงานสั้น (ไฟล์:บรรทัด + ผล)

## ฝั่งเว็บ (`client-dev`) — `public/game.js` + `public/index.html` (เพิ่ม `<script src="pixelcreature.js">` ก่อน `game.js`)
1. เก็บสัตว์ใน Map ตาม `crs/crn/crm/crd/crh` ล้างทิ้งเมื่อออกชั้น/เปลี่ยนชั้น (`scene` ใหม่) • ขยับลื่นด้วย interpolation จากเดลต้า
2. วาดในชั้นถ้ำเรียง y รวมกับผู้เล่น (ตามโครงสร้างวาดของถ้ำเดิม) โดยเรียก `PixelCreature.draw(ctx, c, now)` ถ้าได้ `false` ให้ใช้อีโมจิ `CREATURES[k].emoji` ขนาด ~22px (ฟอลแบ็ก) • แถบ HP เล็กเหนือหัวสัตว์เฉพาะตอนถูกฟาดไม่เต็ม • เงาใต้ตัว
3. วงเตือน `cra`: วงกลมแดงโปร่งบนพื้นรัศมี r ค่อยๆ เข้มขึ้นตลอด ms แล้วหาย • เอฟเฟกต์ `hurt`: จอแดงวาบสั้นๆ + สั่นเล็กน้อย (เคารพค่าลดการเคลื่อนไหวของเกมถ้ามี) + ตัวเลข/ไอคอน "🍗 −N" ลอยขึ้น • `web`: ไอคอนใยใต้เท้า + เดินช้าลงฝั่งเว็บให้ตรง `CREATURE.webSlow.mul` (เซิร์ฟเวอร์ยังเป็นผู้ตัดสิน) • `faint`: ข้อความตรงกลาง "😵 สลบไปครู่ แล้วตื่นที่บันได" • ระหว่าง `stun` ms ล็อก input เดิน/ฟาด
4. ปุ่ม Action: ถ้าหันหน้าหาสัตว์ในระยะ ให้ `act` เดิมส่งไปตามปกติ (เซิร์ฟเวอร์ตัดสิน) • ตรวจว่า **ปุ่ม A บนมือถือ/Space ฟาดสัตว์ได้** และแตะที่สัตว์ก็ฟาดได้ (เหมือนแตะแร่) • ข้อความผู้เล่นไทยสบายๆ
5. ข้อความ/ป้ายเมื่อเจอสัตว์ชนิดแรกของชั้น: toast สั้นๆ ครั้งเดียวต่อชนิดต่อเซสชัน เช่น "🐀 หนูถ้ำ! ฟาดไล่ได้ด้วยอีเต้อ หรือเดินหนีก็ได้"
6. ห้ามฝังตัวเลขสมดุลใน game.js (ใช้ `Shared.CREATURE*`) • ไม่ commit • รายงานสั้น
