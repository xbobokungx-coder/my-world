# ตั๋ว: วาดสไปรต์อุปกรณ์ที่ยังไม่มีภาพ (บัว/จอบ/ถัง/กระทะ ระดับสูง)

ผู้เล่นรายงาน (ภาพแนบ): ถือบัวรดน้ำทับทิมแล้วในมือเป็นกล่องสี่เหลี่ยมดำ ไม่มีรูป อุปกรณ์หลายชิ้นเป็นแบบนี้

## สาเหตุ (ตรวจแล้ว)
`public/pixelui.js` มีไอคอนพิกเซลครบแค่ ขวาน 10, เบ็ด 10, อีเต้อ 10, บัว ระดับ 1–3, จอบระดับ 1 (`⛏`) ส่วนที่เหลือมีแค่คีย์อีโมจิใน `public/shared.js` แต่ **ไม่มีภาพ**:
- บัว ระดับ 4–10 (`CANS[t].emoji`: 🔔 🔕 🔖 🔘 🔙 🔚 🔛) • ในมือ: `drawHeldTool` (`public/game.js` ~:3691) แถว `isCan` ใช้ตาราง `pal` แค่ T=1..3 ระดับ 4+ ได้ `undefined` → โยน error กลางทาง เหลือกรอบดำ (OUT) ที่วาดไปแล้ว
- จอบ ระดับ 2–10 (`HOE_EMOJI`: 🔬 🔭 🔮 🔯 🔰 🔹 🔺 🔻 🔽) • ในมือ: `isHoe = e === '⛏'` เท่านั้น ระดับ 2+ ตกไปวาดไอคอนเล็กไม่มีภาพ
- ถัง/ตะกร้า ระดับ 1–10 (`PAIL_EMOJI`: 🧺 🧳 🧴 🧷 🧻 🧼 🧽 🧯 🧪 🧫) • ไอคอนเท่านั้น (ไม่ถือในมือ)
- กระทะ/อุปกรณ์ครัว ระดับ 1–10 (`PAN_EMOJI`: 🥄 🥫 🥌 🥎 🥏 🥅 🥋 🥊 🥃 🥨) • ไอคอนเท่านั้น
ชื่อระดับอยู่ `HOE_NAMES`/`PAIL_NAMES`/`PAN_NAMES` และ `CANS[t].name` ใน shared.js ให้วัสดุ/สีตรงกับชื่อ (หยก คริสตัล ไพลิน ทับทิม มรกต เพชร สายรุ้ง ฯลฯ)

## ที่ต้องทำ
1. ไอคอนพิกเซล 13×13 (รูปแบบเดียวกับ `can()`/`axe()`/`pick()` ใน pixelui.js) ลงทะเบียนด้วยคีย์อีโมจิเดิม (ห้ามเปลี่ยนคีย์ใน shared.js — test-gear สงวน 🧪 🧺 🔔 ให้ของเหล่านี้):
   - บัว 4–10: ทรงเดียวกับ `can()` เปลี่ยนวัสดุ/ลวดลาย ระดับสูงมีประกายตามแนวระดับ 3 (สายรุ้งไล่สีได้ แต่ต้องไม่เกินจำนวนสีตาม STYLE_GUIDE)
   - จอบ 2–10: ทรงเดียวกับ `⛏` (หัวเหล็กด้ามไม้) เปลี่ยนหัว/ด้ามตามวัสดุ แยกกันออกด้วยตาแม้ขนาดเล็ก
   - ถัง/ตะกร้า 1–10: ตะกร้าสาน (1–2) → ถังไม้ → โลหะ → อัญมณี ทรงถังมีหูหิ้ว
   - กระทะ 1–10: ทรงกระทะมีด้าม วัสดุไล่ตามชื่อใน `PAN_NAMES`
2. ถือในมือ (`drawHeldTool`): บัว ใช้ตารางสีครบ 10 ระดับ (แก้ที่ `pal` เป็น map ตามระดับ ห้าม undefined) • จอบ ทุกระดับใช้ท่าจอบเดิมแต่สีหัว/ด้ามตามระดับ (ทำ `HOE_PAL` ใน pixelui.js แบบ `AXE_PAL`) ใช้ `HOE_E = new Set(Object.values(Shared.HOE_EMOJI))` แทน `e === '⛏'` ให้ตรวจ `isHoe` และ `drawActionBurst` (`hoe` ที่ ~:3890) ด้วย
3. สีเฉพาะระดับสูงทำกระพริบประกายได้ตามแบบเดิม (`Math.floor(now/280)%2`)
4. ตรวจทุกที่ที่แสดงไอคอน: กระเป๋า ร้านค้า การ์ดอุปกรณ์ ตลาดนัด (ตัวอย่างฟังก์ชันที่เรียก `PixelUI` icon) ต้องไม่เห็นอีโมจิระบบหรือกล่องดำเหลืออีก
5. ทำให้ไม่โยน error อีกถ้าเจอระดับที่ไม่มีสี: ใส่ค่าสำรอง (fallback) ใน `isCan` ถ้า `pal` ไม่มี
6. เพิ่มเทสต์เล็กๆ ใน `tools/` (ตรวจว่าทุกอีโมจิใน CANS/HOE_EMOJI/PAIL_EMOJI/PAN_EMOJI มีคีย์ใน PixelUI ที่ลงทะเบียนไว้ และ `HOE_PAL` ครบ 10) ผ่านพร้อม `tools/test-gear.js` เดิม
7. เปิดเกมใน dev (`preview_start dev`) ถ่ายภาพเทียบ: ตัวละครถือบัวระดับ 4,7,10 / จอบ 2,6,10 และตาราง icon ทุกระดับ แปะ path ภาพในรายงาน
