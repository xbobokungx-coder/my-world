# ลุงสมชายตกปลา (NPC ประกอบฉาก)

- ประเภท: feature (ภาพอย่างเดียว)
- ผู้ขอ: เจ้าของ   วันที่: 2026-11-11

## ต้องการอะไร (มุมผู้เล่น)
ลุงสมชายเดินเล่นสลับกับเดินไปริมสระใหญ่ ยืนหันหน้าสระ ถือคันเบ็ด ทุ่นลอยในน้ำ 10–30 วินาที (ช่วงท้ายปลากินเบ็ดแวบหนึ่ง แล้วดึงเบ็ด) แล้วกลับไปเดินเล่น
น้องมิ้นท์/ป้าแก้วไม่แตะในรอบนี้

## เกณฑ์ว่าเสร็จ
- [ ] ไม่แตะปลา/ตลาด/แปลง/เซฟ/เหรียญ (NPC ไม่มี inventory)
- [ ] ยืนบนช่องเดินได้ติดน้ำใหญ่ ทุ่นตกบนช่องน้ำจริง
- [ ] NPC ยังหยุดพักเมื่อไม่มีผู้เล่น • ไม่เพิ่มข้อความใหม่ (ต่อท้ายอาร์เรย์ n เดิม)
- [ ] เทสต์ผ่านทั้งหมด + มีเทสต์ใหม่
