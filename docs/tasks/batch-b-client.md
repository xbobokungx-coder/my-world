# ตั๋วชุด B: งานหน้าเว็บ (ไม่ต้องรอเซิร์ฟเวอร์)

ไฟล์ที่แก้ได้: `public/game.js`, `public/index.html`, `public/client/*` (ถ้ามี)
ห้ามแตะ `server.js` `server/` `public/shared.js` (ชุด A ทำอยู่) ห้าม commit/push
ทุกอย่างต้องใช้ได้ทั้ง PC และมือถือ/แท็บเล็ต และตามกฎ: ของที่โต้ตอบได้ต้องใช้ปุ่ม Action ได้

1. **เมนูสถานะ:** ทุกครั้งที่คลิกสถานะไหน ให้แสดงรายละเอียดโดยไม่ปิดหน้าต่างสถานะ เปลี่ยนไปดูอันอื่นต่อได้
2. **เอาปุ่มกลับบ้านออกจาก HUD** (ถ้ามีทางกลับบ้านทางอื่นอยู่แล้วให้คงไว้ ถ้าไม่มีให้บอกในรายงาน)
3. **เมนูเสียง:** แถบเลื่อนเพิ่ม/ลดเสียงเกม (เสียงเอฟเฟกต์) และแถบเสียงดนตรีเกมเตรียมไว้ (ยังไม่มีเพลงก็ให้มีแถบและเก็บค่าไว้) เก็บค่าใน localStorage ครอบคลุมทุกจุดที่เล่นเสียง
4. **เมนูอาหาร:** ปักหมุด (Pin) สูตรได้ สูตรที่ปักขึ้นบนสุด เก็บใน localStorage
5. **เกจ EXP กับเกจตกปลา:** ปรับตำแหน่ง/ขนาดไม่ให้ทับกัน ตรวจทั้ง PC แนวตั้ง/แนวนอนของมือถือ และแท็บเล็ต (ใช้ in-app browser + `resize_window`)
6. **ข้อความคูลดาวการทำอาหาร:** ถ้ามีข้อมูลคูลดาวฝั่งเว็บอยู่แล้ว ให้แสดงเป็นข้อความในเมนูว่า "ยังทำไม่ได้ รออีก X" ถ้าข้อมูลมาจากเซิร์ฟเวอร์อย่างเดียว ไม่ต้องทำ แต่รายงานว่าต้องเพิ่มอะไรฝั่งเซิร์ฟเวอร์

## รายงาน
สั้น: ไฟล์:บรรทัดที่แก้ + ที่ตรวจบนมือถือ/แท็บเล็ต/PC ผ่านอะไรบ้าง + อะไรที่ทำไม่ได้เพราะต้องพึ่งเซิร์ฟเวอร์
