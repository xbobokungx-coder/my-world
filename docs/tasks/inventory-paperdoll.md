# ตั๋ว: ช่องสวมใส่ตามร่างตัวละคร (ระดับ A) ในกระเป๋า

ต่อจาก `docs/tasks/inventory-phase1.md` (commit `bcac4cd`) • ดีไซน์: `docs/plans/inventory-redesign.md` • เจ้าของอนุมัติ 15 พ.ย. 2026: ระดับ A ก่อน (ใช้ข้อมูลเดิมทั้งหมด **ไม่แตะ server/เซฟ/shared.js**) มือซ้าย = โล่ป้องกัน (ยังไม่มีของ ให้เป็นช่องสำรอง)

## ที่ต้องทำ (เฉพาะแท็บ "ของ" ใน `public/game.js` ส่วน `bagWearHtml` + CSS `.bwear/.bw` ใน `public/index.html`)
เปลี่ยนคอลัมน์ "สวมใส่" (ตอนนี้อ่านอย่างเดียว) เป็นแผงช่องตามร่างตัวละคร:
1. **ร่างตัวละครตรงกลาง**: วาดตัวละครของผู้เล่นด้วย `drawPlayer` แบบเดียวกับพรีวิวในแท็บตู้เสื้อผ้า (canvas `#preview` ~:1640, ขยาย 3–4 เท่า) ไม่ต้องใหม่ ใช้ `me.wear/color/hat/pc` ปัจจุบัน
2. **ช่องรอบตัว**: หัว = หมวก (`WEAR.hat`) • ตัว = เสื้อ (`shirt`) • ขา = กางเกง (`pants`) • มือขวา = เครื่องมือที่ถืออยู่ตอนนี้ (`selTool` + ไอคอนระดับปัจจุบัน + แถบความทน) • มือซ้าย = **โล่** ช่องสำรอง ล็อก แสดงขอบประ + ข้อความ "โล่ (เปิดตอนหอคอย)" ยังกดสวมไม่ได้ ห้ามสร้างไอเทมโล่/ค่าป้องกันในรอบนี้ • ช่องที่ห้า "เสริม" (`acc` แว่น ฯลฯ) วางข้างตัวละคร
3. **กดช่อง = เปลี่ยนในที่เดียว**: กดหัว/ตัว/ขา/เสริม เปิดตัวเลือกย่อยเป็นแถบเลื่อนแนวนอนใต้ร่าง (ใช้ข้อมูล `WEAR[cat]` และ `have()` เหมือนตู้เสื้อผ้า ปุ่มเปลี่ยนใช้ข้อความ/ฟังก์ชันเดิมที่ตู้เสื้อผ้าใช้ ห้ามเพิ่มข้อความใหม่ไปเซิร์ฟเวอร์) ของที่ยังไม่มีแสดงล็อก+ราคา กดมือขวา = เปลี่ยนเครื่องมือเหมือนเมนูช่อง 1 (ใช้ฟังก์ชันเดิม) หรือเลื่อนไปส่วนความทน ถ้าเปลี่ยนไม่ได้ในจังหวะนั้น (เช่นกำลังขับรถ) ให้ข้อความบอกเหมือนที่เกมเดิมทำ
4. **สีเสื้อ/กางเกง/หมวก**: คงไว้ที่แท็บตู้เสื้อผ้าเดิม (ลิงก์ "เลือกสีที่ตู้เสื้อผ้า" ใต้แผง) ไม่ย้าย
5. **มือถือ** (360–375px): ร่างตัวละคร + 6 ช่องรอบตัวต้องไม่ดันกริดของลงไปเกินครึ่งจอ ให้แผงนี้พับ/เปิดได้ (หัวข้อ "🧍 สวมใส่ ▾/▴" เก็บสถานะไว้ใน localStorage `mw_bag_doll`, ค่าเริ่มต้น = เปิดบนจอสูง ≥700px พับบนจอเตี้ย) ช่อง ≥44px • แนวนอน 812x375 วางร่างไว้ซ้ายของกริด
6. แป้นพิมพ์: ทุกช่อง `tabindex=0 role=button` Enter/Space เปิดตัวเลือก (ตามกฎปุ่ม Action) • ไม่ใช้อีโมจิสงวนของ test-gear • ข้อความไทยสบายๆ ตาม STYLE_GUIDE
7. ข้อมูลผิดรูป (ไม่มี `me.wear`, id หมวกที่ไม่รู้จัก) ต้องไม่พัง
