# เมนูเฉพาะวัตถุดิบ (ปลาทู + ไข่ไก่ ฯลฯ) — ระยะ 2

- ประเภท: feature + balance • ผู้ขอ: เจ้าของ • 2026-11-11
- แผน: `docs/plans/cooking-rework.md` ระยะ 2 • ผู้ขอสั่งตรงๆ: "ระบุในเมนูเลยว่าปลาอะไร เช่น ปลาทู + ไข่ไก่ เพิ่มเมนูได้หลากหลาย" → **เพิ่มเป็นสูตรใหม่** (เก็บสูตรหมวดกว้างเดิมไว้ ไม่ลบ)

## ต้องการอะไร
เมนูอาหารที่ระบุปลา/ผัก/ไข่ชนิดเจาะจง ชื่อตรงกับวัตถุดิบ เพื่อให้มีเมนูหลากหลายและอยากหาของชนิดนั้น

## เกณฑ์ว่าเสร็จ
- [ ] เพิ่ม ~20 สูตรใน `COOK` (`public/shared.js` ~986) ใช้ `in: [{ k: 'fish_mackerel', n: 1 }, { k: 'egg', n: 1 }]` (ใช้ของชนิดนั้นจริง ไม่ใช้ของอื่นแทน) • id ต้องขึ้นต้น `dish_` ไม่ซ้ำ
- [ ] ทุก `k` ต้องมีจริง (`itemInfo(k)` ไม่ null) ปลา = `fish_<id>` จาก `FISH_ALL` (ห้ามใช้ id ซ้ำ turtle/seal) ผัก = `crop_<id>` จาก `CROPS` ไข่ = `egg` / `duck_egg` นม = `milk`
- [ ] เลเวลสูตรสัมพันธ์กับของที่หาได้ (ผักที่ปลูกได้ที่เลเวลชาวนาสูง → สูตรเชฟสูง) กระจาย Lv1–20 ให้มีเมนูใหม่ทุกช่วง
- [ ] ตัวเลข (sell xp time food) ตามกติกาเดิมของตาราง: ราคาขาย ≈ มูลค่าวัตถุดิบ × ตัวคูณ ใกล้เคียงสูตรเดิมเลเวลเท่ากัน • ค่าเตา 30% เหมือนเดิม • ตรวจ `tools/econsim.js` ว่า G2/G3/G5 ไม่แย่ลงกว่าก่อนแก้ และ `tools/economy.js` ไม่พัง
- [ ] ไม่แตะ server/เอนจิน (`cook` รองรับ `need.k` อยู่แล้ว) ไม่แตะรูปแบบเซฟ
- [ ] เทสต์ใหม่ `tools/test-cook-signature.js`: ทุกสูตร `in` มีของจริง • ทำสูตรเจาะจงแล้วใช้ของชนิดนั้น (ไม่กินปลาอื่น) • ขาดชนิดนั้นแล้วทำไม่ได้แม้มีปลาอื่น
- [ ] เทสต์ผ่านทั้งหมด (golden ต้องไม่เปลี่ยน ถ้าเปลี่ยนต้องรู้สาเหตุ)

## ไอเดียสูตร (economy-designer ปรับชื่อ/วัตถุดิบ/เลเวลได้ แต่ต้องคงแนว "ระบุชนิดชัด")
ปลาทูทอด+ไข่ดาว (ปลาทู+ไข่ไก่) • ไข่เจียวเป็ดพริก (ไข่เป็ด×2+พริก) • ปลาซาร์ดีนย่างมะเขือเทศ • ปลาดุกผัดเผ็ด (ดุก+พริก) • ต้มยำกุ้ง (กุ้ง+พริก+มะเขือเทศ) • ปูผัดผงกะหรี่ (ปู+ไข่ไก่+พริก) • หอยนางรมทอด (หอยนางรม+ไข่ไก่) • หมึกย่างซอสพริก • ปลากะพงขาวทอดน้ำปลา • สลัดทูน่าข้าวโพด (ทูน่า+ข้าวโพด+มะเขือเทศ) • ปลาโอเผาผักรวม • ฟักทองนึ่งนมสด (ฟักทอง+นมวัว) • กุ้งมังกรอบนม • ซุปมะพร้าวกุ้งมังกร • ไข่เจียวทรัฟเฟิล (ไข่×2+เห็ดทรัฟเฟิล) • ปลาปักเป้าซาชิมิ • มันฝรั่งอบไข่ (มันฝรั่ง+ไข่ไก่) • แกงกบ/กบผัดพริก
