## เป้าหมาย (รอบที่ 1 + 2 ทำต่อเนื่อง)
**รอบ 1 — เมนู ☰ + หน้าต่างตั้งค่า ⚙️**
1. เมนู ☰ เหลือเป็น "ทางไปหน้าต่างอย่างเดียว" **ไม่เกิน 8 ปุ่มใหญ่** เห็นครบในจอเดียวไม่ต้องเลื่อนที่ 360x640: 🧍 ตัวละคร, 📋 เควส, 📰 ข่าวเมือง, 🏠 บ้านฉัน, 👥 บ้านเพื่อน (`friendsBtn`), 🐾 สัตว์เลี้ยง (ซ่อนตามเงื่อนไขเดิม), 👥 เพื่อน (รวม ออนไลน์/ชวนเพื่อน หรือเปิดหน้าต่างคนในแมพเดิม), ⚙️ ตั้งค่า ปุ่มใหญ่ ไอคอน + ชื่อไทยเต็ม (ไม่พึ่ง `data-lbl` อย่างเดียว) ≥44px ตัวแดง badge เควส/สัตว์เลี้ยงที่มีอยู่ต้องไม่หาย
2. หน้าต่างใหม่ `#settings` (ทำตามแบบ panel อื่น: เพิ่ม id ในรายการ CSS panel ~:107-113 ฯลฯ, ปุ่มปิด, Esc ปิด, `closeOthers`): 🎚️ เสียงเกม (ย้าย `#sndPanel` มาทั้งก้อน รักษา id/ฟังก์ชัน `syncSndUi` `onVolInput`), เสียงเพื่อน (`spkBtn`), ไมค์ (ถ้าไม่ซ้ำ HUD), 🖥️ หน้าจอ (ซูมเข้า/ออก เต็มจอ), **ขั้นสูง** (พับไว้เริ่มต้น: ความละเอียด `resBtn`, ตัววัดเฟรม `perfBtn`, `perfCopy`), 🐞 แจ้งบั๊ก, 🛠️ ผู้ดูแล (เฉพาะแอดมิน เหมือนเงื่อนไขเดิม) คง id ปุ่มเดิมทั้งหมดไว้ (โค้ด/เทสต์อ้าง id) แค่ย้ายตำแหน่ง ฟังก์ชัน `fitMenu` ยังใช้ได้ ถ้าไม่จำเป็นแล้วให้ลดการใช้งาน แต่ห้ามทำให้พัง
3. HUD แถบบน (`menuBtn` `bagBtn` `chatBtn` `micBtn`) ไม่เปลี่ยน ปุ่ม `mtouch` ที่ซ้ำ (bagMenu chatMenu micMenu onlineMenu) เอาออกจากเมนูได้เมื่อไม่มีใครอ้าง (grep ก่อน)

**รอบ 2 — แยกหน้าต่าง 🧍 ตัวละคร ออกจากกระเป๋า**
4. กระเป๋า (ปุ่ม B / 🎒) เหลือแท็บ: **ของ** (กริด + แผงสวมใส่เดิม) กินอาหารเป็นตัวกรอง/ปุ่มในกริด (หรือคงแท็บ eat ไว้ถ้าย้ายยาก ให้ตัดสินใจเลือกวิธีที่เปลี่ยนน้อยสุดและรายงาน)
5. หน้าต่าง 🧍 ตัวละคร (ปุ่ม C `statBtn` + เมนู): แท็บ **สถานะ** (ข้อมูลเดิม + ตั้งสถานะ `myStatusBtn` ถ้าเหมาะ) **สกิล** **สมุด** และลิงก์/ปุ่มไป **ฉายา** (`#ach` เดิม) **ตู้เสื้อผ้า/สี** (แท็บ `look` เดิมเก็บไว้ที่นี่ เพื่อเลือกสีและซื้อชุด; การเปลี่ยนชุดในแผงสวมใส่ของกระเป๋ายังอยู่เหมือนเดิม) วิธีที่เปลี่ยนน้อยสุด: ใช้ container `#bag` เดิมแต่แสดง "ชุดแท็บ" และหัวข้อคนละแบบตามจุดเปิด (`openBag('items')` vs `openChar('status')`) ปุ่มลัด B/C/H และ `bagShown()/closeBag()` ที่โค้ดอื่นเรียกต้องยังทำงาน
6. ตรวจทุกที่ที่เรียก `openBag(` ด้วยแท็บ status/skills/look/book/eat (grep `openBag\(`) ให้ไปเปิดหน้าต่างที่ถูก ห้ามมีทางเข้าหาแท็บที่ไม่อยู่ในชุดแล้ว
