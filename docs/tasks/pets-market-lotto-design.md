# ตั๋วออกแบบ: สัตว์เลี้ยงโต 5 ระดับ + ตลาดนัด + หวยรับที่ตู้

ขั้นนี้ = ออกแบบอย่างเดียว เขียนผลที่ `docs/plans/pets-market-lotto.md` ห้ามแก้โค้ด

## 1. สัตว์เลี้ยงตัวตาม (`server/systems/pets.js`, `PETSTAT` ใน `public/shared.js`)
เป้า: สัตว์เลี้ยงมีพัฒนาการ 5 ระดับ (ขยายใหญ่ขึ้นตามลำดับ) และมีแรงจูงใจให้เลี้ยง ไม่ใช่แค่ให้อาหาร
- ออกแบบเงื่อนไขขึ้นระดับ (เช่น แต้มความผูกพัน/อาหาร/เวลาที่อยู่ด้วย) และสิ่งที่ได้ในแต่ละระดับ (ขนาด สกิน ท่าทาง ของที่เก็บมาให้ โบนัสเล็กน้อย)
- โบนัสต้องไม่ทำลายสมดุลเศรษฐกิจ (ดู `ECONOMY-PLAN.md`) เสนอตัวเลขเข้า shared data
- ระบุการเปลี่ยนรูปแบบเซฟ ตัวแปร `xpv`/migration ถ้าจำเป็น และการอ่านเซฟเก่า (สัตว์เดิมเริ่มระดับ 1)
- ภาพ 5 ระดับ: เสนอวิธีที่ใช้เครดิต PixelLab น้อยที่สุด (เหลือ 2 generations) เช่น ย่อ/ขยายสไปรต์เดิม
- ต้องใช้ปุ่ม Action ได้

## 2. ตลาดนัด (ป้ายใหม่ แยกจากตลาดกลาง)
ผู้เล่นตั้งประกาศเสนอซื้อ/เสนอขาย ราคาตามที่ตั้ง ไม่อิงราคาตลาดผันผวน ทุกคนเข้าซื้อขายได้
- ออกแบบโครงสร้างข้อมูล escrow (กันเงิน/ของซ้ำและโกง) ขีดจำกัดจำนวนประกาศ ค่าธรรมเนียม (ถ้ามี) หมดอายุประกาศ
- ตรวจความสดของสินค้า (`lots`) ว่าจะส่งต่อให้ผู้ซื้ออย่างไร
- ดูของเดิมที่คล้ายกัน: `server/systems/stall.js`, `trade.js`, `market.js` เสนอว่าใช้ซ้ำหรือแยก
- ป้องกัน exploit (ตั้งราคาเสียเปล่าเพื่อโอนเงินหลบกฎ ฯลฯ) และต้องใช้ปุ่ม Action ได้

## 3. หวยรับรางวัลที่ตู้ (`server/systems/lotto.js`)
ตอนนี้จ่ายอัตโนมัติ (`lotto.js:50`) เปลี่ยนเป็นสถานะ "รอรับ" แล้วกด Action ที่ตู้เพื่อรับ
- เก็บรางวัลรอรับใน rec (ไม่หมดอายุเป็นค่าตั้งต้น) ผู้เล่นออฟไลน์ตอนออกรางวัลก็ยังรับได้
- ข้อความแจ้งผู้ถูกรางวัล + การรับซ้ำต้องไม่ได้เงินสองครั้ง
- ผลต่อเทสต์หวยเดิมและ `tools/economy.js`
