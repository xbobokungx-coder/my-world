# ผังเมืองรอบสอง: ลานต้นไม้ + ย้ายกองไฟ + ร้านอาวุธ (ปิดปรับปรุง) + ทางขอบหิน

- ประเภท: feature (ผังเมือง + ศิลป์ + ร้านใหม่)
- ผู้ขอ: ผู้ดูแล   วันที่: 2026-11-12
- แบบอ้างอิงที่ผู้ดูแลให้: ภาพแนวคิด (ทางแคบขอบหินวนลูป โคมไฟตามทาง ลานวงกลมขอบหินมีต้นไม้กลางลาน กระถางดอกไม้หน้าร้าน ม้านั่ง) — ภาพไม่ใช่สเปค

## ต้องการอะไร (มุมผู้เล่น)
เมืองดูเป็นหมู่บ้านสนามหญ้าที่ใช้ง่าย ไม่เหลี่ยม มีธีมของตัวเอง:
1. **ลานกลางเมืองเป็นวงกลมขอบหิน มีต้นไม้ใหญ่กลางลาน** แทนกองไฟเดิม — **ปรับ 12 พ.ย. รอบ 2:** ภาพตัวอย่างไม่มีกองไฟ → เลิกมีกองไฟ ไม่ย้าย ใช้พิกัดเดิมเป็นศูนย์กลางลาน ต้นไม้กลางลานคือต้นไม้แห่งโซ่เดิม (ดูหัวแผน)
2. **ร้านอาวุธ ร้านที่ 11** (kind `weapon`) ตั้งข้างบ้านหลังใหญ่ ตัวอาคารมีป้าย "ปิดปรับปรุงชั่วคราว" กดแล้วขึ้นข้อความแจ้ง เปิดร้านจริงไม่ได้ (ไว้ทำภายหลัง)
3. **ทางเดินใหม่:** แคบ 1–2 ช่อง ขอบหินเทา เป็นเครือข่ายที่อ่านออกว่าเป็นเส้นทาง ต่อประตูทุกร้านและประตูสวน/เล้า วนลูปรอบกลุ่มร้าน ไม่เป็นก้อนหรือหย่อมลอย
4. โคมไฟเรียงตามทาง (กลางคืนมีแสง) กระถางดอกไม้หน้าร้าน ม้านั่งใกล้ร้านและลาน
5. **แปลงผักคงเรียบเหมือนเดิม** (ไม่ลงร่องดิน/ต้นพืช) • เล้าสัตว์ **ไม่แตะผังและไม่เพิ่มของตกแต่งในงานนี้**

## เกณฑ์ว่าเสร็จ
- [ ] ผู้ดูแลอนุมัติ "ผังร่าง" (แผนผังเปรียบเทียบก่อน/หลังบนกริดจริง + ภาพจำลอง) ก่อนแก้ผังจริง
- [ ] ที่ตั้งกองไฟใหม่ + ทุกระบบที่ผูกกับกองไฟ (ที่นั่ง คอมโบ/โซ่ แสงกลางคืน NPC เสียง เทสต์) ทำงานครบที่ตั้งใหม่
- [ ] ร้านอาวุธ: เห็นบนแมพ มีป้าย ชื่อ ไอคอน แผนที่ย่อ กดเข้าแล้วขึ้น "ปิดปรับปรุงชั่วคราว" ไม่เปิดหน้าร้าน ไม่มีสินค้า/ราคา/XP/เหรียญเปลี่ยน
- [ ] ประตูทุกร้าน (11) เดินถึงและต่อทางถึงลานกลาง ไม่ทับเขตห้าม ประตูร้านห่างกัน ≥4 ช่อง (ใช้ tools/test-town-ring.js ที่มีอยู่)
- [ ] ผู้เล่นเดิมที่ยืนในช่องที่กลายเป็นสิ่งกีดขวาง (ต้นไม้ลาน ร้านใหม่) ไม่ติดค้าง
- [ ] golden อัปเดตแบบตั้งใจ ไม่มีเหรียญ/ของ/XP เปลี่ยน • เทสต์ `tools/test-*.js` ผ่านทั้งหมด
- [ ] ไม่เปลี่ยนรูปแบบเซฟ • เอกสาร GAME-DESIGN/HOW-TO-PLAY อัปเดต
