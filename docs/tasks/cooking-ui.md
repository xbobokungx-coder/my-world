## เกณฑ์ว่าเสร็จ
- [ ] การ์ดสูตร: อีโมจิจานใหญ่ + ชื่อ + ราคาขาย • ชิปวัตถุดิบเป็นอีโมจิ (🐟×2) เขียว = พอ แดง = ขาด พร้อม "(มี N)"
- [ ] ตัวกรอง (chip): ✅ ทำได้ตอนนี้ (ค่าเริ่มต้นถ้ามีสูตรทำได้ ไม่งั้น "ทั้งหมด") • ทั้งหมด • 🐟 ปลา • 🥕 ผัก • 🥚 ไข่ • 🔒 ยังไม่ปลดล็อก
- [ ] เรียง: ทำได้ก่อน → ยังขาดของ → ล็อก (ในกลุ่มเดียวกันตามเลเวลสูตร)
- [ ] สูตรที่ล็อก: โชว์แค่ชื่อ + "ปลดที่เชฟ Lv N" (ไม่โชว์วัตถุดิบ ลดความรก)
- [ ] รายละเอียดพับ: แตะการ์ดขยายดู XP • เวลาทำ • ค่าเตา • กำไรสุทธิ (ขาย − ค่าเตา) • กินอิ่ม
- [ ] ปุ่มทำบอกจำนวนที่ทำได้ "ทำ (×N)" (N = min จากวัตถุดิบ และเหรียญค่าเตา) ปุ่มยังส่ง `{t:'cook', id}` เหมือนเดิม ทีละจาน
- [ ] มือถือ/แท็บเล็ต: การ์ดเดียวต่อแถว ปุ่มสูงพอกด ตัวอักษร ≥ 12px ไม่ล้นจอ (body.touch)
- [ ] ไม่แตะ shared.js / server / รูปแบบเซฟ • ข้อความไทย • ใช้ esc() กับสตริงที่มาจากข้อมูล ไม่เพิ่ม innerHTML จากข้อมูลผู้เล่น
- [ ] ส่วนขายอาหารด้านล่างของแท็บเดิมใช้ได้เหมือนเดิม
