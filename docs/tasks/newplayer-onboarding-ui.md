## ข้อ 3 แถบเครื่องมือล่าง (#hotbar) ทับ
- แผงสกิล/EXP ตอนตกปลา (#skillbar, #fgauge, #ffight) และป้าย "ออกทะเล" ที่ท่าเรือเกาะกลางสระ (วาดใน canvas ที่ game.js ~บรรทัด 3448–3460 ใกล้ `fillText('ออกทะเล'`)
- หาว่าทับตอนจอขนาดไหน (PC กว้าง/เตี้ย, มือถือแนวตั้ง/นอน) แล้วแก้ให้ไม่ทับ (เช่นยกแผง ขยับป้าย/ให้ป้ายอยู่เหนือ hotbar)

## ข้อ 4 บัง HUD
- ข้อความ toast ยาวพับ 3 บรรทัดบนสุด (#toast top:8px) บัง HUD ตอนเข้าเกม (เช่น ข้อความต้อนรับ/ประกาศ) → ทำให้ไม่บัง HUD (เลื่อนลงใต้ HUD, จำกัดบรรทัด หรือเก็บเป็น 1–2 บรรทัด)
- มินิแมปตอนขยาย (`setMini` 'big') บัง HUD มุมขวาบน → จำกัดขนาด/ตำแหน่งให้ไม่ทับปุ่ม HUD (เมนู/เหรียญ ฯลฯ)
