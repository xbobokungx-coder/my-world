## ต้องการอะไร
เพิ่ม **ป้ายอันดับ** ในลานเมืองถัดจากป้ายข่าวเมือง (`BOARD` (29,21)) แล้วขยับตู้ ATM ไปทางขวาให้แถวสมดุล: `BOARD` 29 • **ป้ายอันดับ 31** • `ATM` 31→**33** • `LUCKY` 36 เหมือนเดิม (ถ้าช่องไหนชนอะไรอยู่ให้เลือกช่องใกล้เคียงที่สมดุลและรายงาน) ผู้เล่นแตะหรือกดปุ่ม Action (Space / A) ที่ป้าย → เปิดแผงอันดับ

### แผงอันดับ: 4 แท็บ แต่ละแท็บ Top 10 + แถว "คุณอยู่อันดับที่ N" (ไฮไลต์ชื่อตัวเอง)
1. **⭐ เลเวล**: อันดับรวม (ผลรวมเลเวลทุกอาชีพ) + ตัวเลือกรายอาชีพ (ชาวนา ชาวประมง นักตัดไม้ นักขุดแร่ ฯลฯ ตาม `SKILLS`) เรียงตามเลเวลแล้วตาม XP
2. **📅 สัปดาห์นี้**: XP ที่ได้ในสัปดาห์นี้ (รีเซ็ตตามสัปดาห์ ใช้ `weekKey` ของที่มีอยู่) ให้ผู้เล่นใหม่มีโอกาสขึ้นอันดับ
3. **💰 เศรษฐี**: เหรียญที่มีอยู่ (โชว์จำนวนเหรียญ)
4. **🎮 ตู้เกม**: แต้มตู้เกมสะสม + สัปดาห์นี้ ใช้ข้อมูลเดิมของ `sendLeaderboard` (Arcade Hub ยังคงใช้ของเดิม ไม่ต้องแก้)

### กติกาข้อมูล
- **นับเฉพาะผู้เล่นจริง**: ตัดชื่อสงวน `Sira` (`ADMIN_NAME` ใน `server/consts.js`) และบัญชีทดสอบ/บอทตามหลักเดียวกับ `tools/realplayers.js` (ดูว่าเรียกใช้ซ้ำหรือเขียนกฎเทียบเท่าได้ที่ฝั่งเซิร์ฟเวอร์ ห้ามเอาข้อมูลดิบหลุดออกไปเกินชื่อ/ตัวเลขที่โชว์)
- ส่งเฉพาะ **ชื่อตัวละคร** และตัวเลขของแท็บนั้น ห้ามส่งคีย์เซฟ/PIN/ไอพี/อินเวนทอรีอื่น
- เซิร์ฟเวอร์ **แคช** ผลคำนวณ (เช่น 30–60 วินาที) กันคำนวณจากเซฟทุกคนทุกครั้งที่เปิด
- XP รายสัปดาห์: เก็บเพิ่มใน `rec` (additive ไม่ต้องย้ายเซฟ ผู้เล่นเก่าเริ่มที่ 0) เช่น `rec.wkx = { k: weekKey, xp }` เพิ่มใน `addXp` ฝั่งเซิร์ฟเวอร์ (รวม XP ทุกชนิดที่นับเลเวล) รีเซ็ตเมื่อ weekKey เปลี่ยน ห้ามเปลี่ยนรูปแบบเซฟเดิม (ข้อห้ามก่อนขั้น 4 ของ refactor)

## สัญญา (contract) ระหว่างเซิร์ฟเวอร์กับเว็บ
- ผู้เล่นส่ง `{ t: 'rank' }` → เซิร์ฟเวอร์ตอบ `{ t: 'rank', lv: { all: [..], farm: [..], fish: [..], wood: [..], mine: [..] /* ตามคีย์ใน SKILLS */ }, wk: [..], rich: [..], arc: { total: [..], wk: [..] }, me: { lv: { all: n, farm: n, ... }, wk: n, rich: n, arc: n } }`
- แต่ละลิสต์ Top 10 เรียงอันดับแล้ว (อันดับ = ลำดับ+1) แต่ละแถว: `lv.*` = `{ n: ชื่อ, lv, xp }` (all = `{ n, lv: ผลรวมเลเวล }`), `wk` = `{ n, xp }`, `rich` = `{ n, coin }`, `arc.*` = `{ n, total }` / `{ n, wk }` • `me.*` = อันดับของผู้ขอ (0 = ยังไม่ติดอันดับ/ไม่มีข้อมูล) • ผู้ขอที่เป็นผู้ดูแล/บัญชีที่ถูกตัดออก ได้ `me` เป็น 0 ทั้งหมด
