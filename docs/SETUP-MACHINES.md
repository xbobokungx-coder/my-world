# ทำงานจาก 3 เครื่อง + VPS ให้ Claude "จำงานร่วมกัน"

เครื่อง: คอมที่ทำงาน • คอมที่บ้าน • โน้ตบุ๊ก • VPS (เกมจริง ไม่ใช้ dev)

## 1. ต้องเป็น session เดียวกันไหม → ไม่จำเป็น

session ของ Claude Code (ประวัติแชท) เก็บอยู่ในโฟลเดอร์ `~/.claude` ของแต่ละเครื่อง ไม่ซิงก์ข้ามเครื่องเอง
และการให้ Claude "จำทุกการกระทำ" ไม่ใช่สิ่งที่ต้องการจริง: ประวัติยิ่งยาว ยิ่งกิน token ทุกครั้งที่ทำงาน
สิ่งที่ต้องการคือให้ **ทุกเครื่องรู้สถานะงานและคำตัดสินใจล่าสุดเหมือนกัน** ทำได้ด้วยการให้รีโปเป็น "สมองกลาง":

| สิ่งที่ต้องจำ | เก็บที่ | ซิงก์ด้วย |
|---|---|---|
| การกระทำกับโค้ดทั้งหมด | ประวัติ git | push / pull |
| กติกาโปรเจกต์ | `CLAUDE.md` | git |
| กำลังทำอะไร ค้างอะไร ตัดสินใจอะไร | `docs/HANDOFF.md` (อัปเดตด้วย `/handoff`) | git |
| รายละเอียดงานแต่ละชิ้น | `docs/tasks/`, `docs/plans/` | git |
| สิ่งที่ agent เรียนรู้ (แผนที่โค้ด บทเรียนการปรับสมดุล) | `.claude/agent-memory/` | git |
| ทีม agent, skill, hook | `.claude/` | git |

ตอนเปิด Claude Code ทุกครั้ง hook `session-start.js` จะบอก Claude เองว่าเครื่องนี้ตามหลัง GitHub ไหม และแปะส่วนต้นของ `HANDOFF.md` ให้ จึงเริ่มต่อจากเครื่องอื่นได้โดยไม่ต้องเล่าใหม่

สิ่งที่ **ไม่** ซิงก์ (ตั้งใจ): ประวัติแชทแต่ละเครื่อง, ความจำอัตโนมัติส่วนตัวใน `~/.claude`, `data-dev/`, คีย์ SSH

### ทางเลือกเสริม ถ้าอยากคุย "session เดียว" จริงๆ
- **Remote Control** (`/remote-control` หรือ `/rc`): session รันบนเครื่องหนึ่ง แล้วเครื่องอื่นหรือมือถือเปิดคุยต่อผ่าน claude.ai/code ได้ เครื่องต้นทางต้องเปิดอยู่ และ session จบเมื่อปิดโปรแกรมที่เครื่องนั้น เหมาะกับ "สั่งงานคอมบ้านจากโน้ตบุ๊ก/มือถือ" ชั่วคราว
- **Claude Code on the web**: session รันบนคลาวด์ของ Anthropic กับรีโป GitHub เปิดจากเครื่องไหนก็ได้ แต่ไม่มีไฟล์ในเครื่องและรันเซิร์ฟเวอร์เกมทดสอบแบบเครื่องจริงไม่ได้ ดึง session ลงเครื่องได้ด้วย `/teleport`
- ทั้งสองแบบใช้ร่วมกับวิธีหลักได้ แต่ **ไม่แทน** `HANDOFF.md` เพราะ session จบแล้วความรู้ต้องยังอยู่ในรีโป

## 2. เตรียมทุกเครื่อง dev (ทำครั้งเดียวต่อเครื่อง)

- [ ] **Git** ติดตั้งแล้ว และตั้งค่า:
  ```
  git config --global user.name "xbobokungx-coder"
  git config --global user.email "<อีเมลของคุณ>"
  git config --global pull.rebase true
  ```
- [ ] **Node.js** เวอร์ชันหลักเดียวกับ VPS (ดูบน VPS ด้วย `node -v`)
- [ ] **Claude Code** ติดตั้งและล็อกอินบัญชีเดียวกันทุกเครื่อง
- [ ] **คีย์ SSH แยกต่อเครื่อง** (ห้ามก๊อปคีย์ลับข้ามเครื่อง ถ้าเครื่องหายจะถอนคีย์เครื่องนั้นได้ตัวเดียว)
  ```
  ssh-keygen -t ed25519 -C "my-world-<ชื่อเครื่อง>"
  ```
  - เพิ่มกุญแจสาธารณะ (`.pub`) ใน GitHub → Settings → SSH keys
  - เพิ่มกุญแจเดียวกันใน VPS ที่ `/root/.ssh/authorized_keys`
- [ ] **ชื่อลัด SSH** ในไฟล์ `~/.ssh/config` (Windows: `C:\Users\<ชื่อ>\.ssh\config`):
  ```
  Host my-world
    HostName 165.101.64.106
    User root
    IdentityFile ~/.ssh/id_ed25519
  ```
  ทดสอบ: `ssh my-world true` ต้องไม่ถามรหัสผ่าน
- [ ] **โคลนและติดตั้ง:**
  ```
  git clone git@github.com:xbobokungx-coder/my-world.git
  cd my-world && npm install
  ```
- [ ] **ข้อมูลทดสอบของเครื่องนี้:** ใช้ `DATA_DIR=./data-dev` เสมอ ถ้าต้องการข้อมูลจริงมาทดสอบ ดึงไฟล์สำรองลงมาเก็บเฉพาะในเครื่อง (ในเซฟมี IP ผู้เล่น ห้าม commit)
- [ ] **ทดสอบ:** เปิด `claude` ในโฟลเดอร์รีโป ต้องเห็นบรรทัด `[git] branch main: ...` จาก hook

## 3. เตรียม VPS (ครั้งเดียว)

- [ ] ถ้ายังมีงานค้างบน VPS: `git status` แล้ว commit + push ให้หมดก่อน (deploy.sh จะไม่ยอมทำงานถ้ามีไฟล์ค้าง)
- [ ] `git pull` ให้ได้ `tools/deploy.sh` แล้วเช็กสิทธิ์รัน: `ls -l tools/deploy.sh` ต้องมี `x`
  ถ้าไม่มี (commit มาจาก Windows): ที่เครื่อง dev รัน `git update-index --chmod=+x tools/deploy.sh` แล้ว commit + push
- [ ] มี `flock` และ `curl` (Ubuntu มีมาให้): `which flock curl`
- [ ] ลองแบบไม่แตะเกมจริง: `./tools/deploy.sh --check`

## 4. กิจวัตรประจำวัน

1. เปิดเครื่อง → `claude` ในโฟลเดอร์รีโป → hook บอกสถานะ + HANDOFF
2. ถ้าตามหลัง: ให้ Claude `git pull` ก่อนแก้อะไร
3. ทำงาน (ใช้ `/feature`, `/bugfix` ตามแผนทีม)
4. ก่อนเลิกหรือย้ายเครื่อง: **`/handoff`** (บันทึกสถานะ + push; งานไม่เสร็จไปอยู่ branch `wip/...`)
5. ขึ้นเกมจริง: `/ship`

กติกาเดียวที่ต้องยึด: **ทำงานบน branch เดียวกันทีละเครื่อง** ถ้าจะสลับเครื่องกลางงาน ต้อง `/handoff` ก่อนทุกครั้ง

## 5. ข้อความเริ่มต้นสำหรับ Claude Code (ครั้งแรกในแต่ละเครื่อง)

```
(git config, node -v เทียบกับ VPS, ssh my-world true, npm install, hook SessionStart)
บอกเฉพาะข้อที่ยังไม่ผ่านและคำสั่งที่ต้องรัน ยังไม่ต้องแก้อะไรเอง
```
